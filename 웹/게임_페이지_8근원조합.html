8근원 조합 체계

살란은 소모품이 아니다 — 그 밑에 소모형 근원 한 층을 파서, 랜덤디펜스처럼 매턴 쌓아 무한히 조합해 올린다.
2026-07-23 · 진행 중 · 라이브 설계 · 검수용
푼 문제: 살란(낱말)은 지식이라 소모품이 아니라 랜덤디펜스의 "생산→누적→소모" 경제를 못 얹었다. → 살란 밑에 근원 한 층을 판다. 소모되는 건 근원, 살란은 소모 안 되는 레시피. 설정 하나 안 깨고 자원 경제가 생긴다.

1최하위 = 8근원 (언령+문자 통합)

하나의 통합 풀. 소리(언령)든 새김(문양·회로)이든 같은 8근원에서 나온다. 획기가 섞이면 새김 쪽으로 기운다. 화면 아래 고정 카운터 줄로 표시 — 쌓여도 손패가 안 늘어난다.

근원느낌씨앗이 되는 살란
불기열·타오름자르(불)·실란(빛)
찬기식음·가라앉음시스(서리)·루(고요)
물기흐름·스밈마이(물)·후르(바람)
땅기굳음·무게·버팀켈(돌)·옴(무게)·두르(벽)
울기떨림·퍼짐잔(소리)·카르(깨짐)
엮기잇고 묶음람(묶음)·코르(닫힘)
빔기비움·열림·없앰오르(열림)·무네(어둠)·니르(아묾)
획기새김·회로 씨진·문양·룬의 관문

2구조 — 원랜디식 조합 로스터 (★정정)

정정(2026-07-23 밤): 처음엔 8원소 화학식(불+물=증기)으로 짰는데 — 그건 기술 수를 수십 개로 쪼그라뜨린다. 랜덤디펜스(원랜디)의 핵은 수백~수천 유닛의 스프롤이고, 그게 우리 캐논 "기술 수천 개"와 맞다. 그래서 구조를 원랜디식으로 재편한다 — 8근원은 재료층으로 두고, 그 위는 거대 로스터.

원랜디 실제 구조: 흔함 랜덤 뽑기 → 3~6개 조합 → 희귀→전설→초월→불멸→영원, 2차 자원(목재)이 큰 조합 게이트, 히든 조합은 해금. 우리 대응:

우리 등급원랜디조합 재료
근원(재료)매턴 생산 (8근원)
낱말흔함근원 2~3
겹말희귀낱말 3~4
큰말전설겹말 3~4 + 전리
비전초월큰말 3~5 + 전리
절기불멸·영원비전 3~6 + 전리 대량 + 히든 해금
  • 조합 = 3~6개 (2개 화학식 아님) — 재료 여러 개 부어 한 단 위로.
  • 2차 자원 = 전리(戰利) — 전투 중 뜯는 마력(기존 설계 재사용, 마나통 아님). 원랜디 목재 자리, 고등급 게이트.
  • 히든 조합 = 파먹기·스토리 해금 — 네가 원래 원한 "클리어 수 해금" 그 자리.
  • 로스터 = 기존 도감 350+ 그대로 재편(새 창작 0) → 목표 수천. 8근원은 "왜 되나"의 문법일 뿐, 수를 제한 안 함.

3조합 트리 — 계보별 climb

근원에서 대주문까지 실제로 쌓이는 줄기들. 효과는 스토리 아니라 직관 값(불화살 꽂힘·판 동결).

🔥 불 계보
  • 자르(불)=불기 · 불화살 꽂힘 60
  • → 증기(자르+마이) · 용암(자르+켈) · 불폭풍(자르+후르)
  • → 화산(용암+켈) · 겁화(불폭풍+자르)
  • → 분연대화(화산+겁화) · 판 전체 불바다 400+
❄ 서리 계보
  • 시스(서리)=찬기+물기 · 얼어붙음 30+둔화
  • → 눈보라(시스+후르) · 얼음벽(시스+두르) · 우박(시스+옴)
  • → 빙하(눈보라+켈) · 혹한(눈보라+루)
  • → 빙하기(빙하+혹한) · 판 동결 피날레
◈ 추상 계보 (엮기·빔기 — 근원이 진짜임의 증거)
  • 람(묶음)=엮기 · 무네(어둠)=빔기+찬기 · 니르(아묾)=빔기+물기
  • → 암막(무네+후르) · 올가미(람+두르)
  • → 봉인(람+코르) → 결계(봉인+두르+획기)
아까 5근원으론 안 쪼개지던 어둠·묶음·열림·아묾이 억지 없이 다 나온다.

5한 턴

매턴 → 8근원 몇 개 생산돼 아래 카운터에 누적 → 근원 끌어 낱말/겹말 조합(획기 섞으면 문양·진) → 꼴·맺음 붙여 발현. 판 갈수록 근원 쌓여 위 티어 조합 = 랜덤디펜스 스노볼.
