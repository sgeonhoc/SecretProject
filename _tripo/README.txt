==========================================================
  _tripo 폴더 안내  (Tripo AI 캐릭터 생성 작업 폴더)
==========================================================

[폴더 구조]
  _tripo\
   ├─ INBOX\                         ← ★여기에 새 참고 이미지(일러스트)를 넣어주세요
   ├─ prev_inputs_2026-06-04\        ← 내가 예전에 Tripo에 먹였던 입력(벤치마크용, 보관)
   │    ├─ multiview_4view\  front/back/left/right.png  (앞뒤좌우 4면 렌더)
   │    └─ portrait_single\  portrait_front.png         (얼굴 포트레이트)
   └─ README.txt (이 파일)

[중요 - 예전 입력이 왜 별로였나]
  prev_inputs 들은 "기성 3D 모델(하네카와)을 플랫 렌더한 저해상 이미지"라서
  Tripo 결과 얼굴이 뭉개졌음. 입력 퀄을 못 넘는 게 Tripo 특성(GIGO).
  → 그래서 INBOX 에는 아래 스펙의 "좋은 일러스트"를 넣어야 함.

[INBOX 에 넣을 좋은 입력 스펙]  (이러면 남들 자랑하는 퀄 나옴)
  1) 고해상도 (최소 1024px, 클수록 좋음). 씻긴 색감 X.
  2) 또렷한 눈동자 / 선명한 이목구비 (납작하게 칠해진 졸린눈 X).
  3) 음영이 살아있는 2D 캐릭터 일러스트 (플랫 무음영 X).
  4) A포즈 또는 자연스러운 정면 전신 (T자로 팔 수평 X).
  5) 단색 / 대비되는 배경 (캐릭터와 비슷한 회색 배경 X).
  6) 가능하면 정면 1장이면 충분 (멀티뷰면 더 좋지만 정면 퀄이 우선).

[넣는 법]
  - 캐릭터 1명당 한 폴더로 묶어주면 깔끔:  INBOX\char_서진우\front.png ...
  - 그냥 INBOX\ 바로 아래 1장 넣어도 됨.
  - 넣고 "돌려줘" 하면 내가 image_to_model 로 3D 뽑음.
