**도면(`도구/_rasel_plan.json`)은 새 로스터를 쓰고, `.umap` 파일 이름은 옛 로스터를 쓴다.**

## 3. 개명을 실제로 어떻게 했나 (2026-07-25 실행 — 위 계획을 두 군데 고쳤다)

### ① 임시 이름 2단계는 필요 없었다 (계획 정정)

원래 "`L10_Clinic → L08_Clinic`을 먼저 하면 `L08_Academy_Street`와 충돌한다"고 적어 두었으나
**틀렸다.** 에셋 이름은 번호가 아니라 **전체 문자열**이라 `L08_Clinic` ≠ `L08_Academy_Street`다.
대상 11개를 기존 25개와 전부 대조해 **겹치는 이름이 0**인 것을 확인하고 한 번에 갔다.
(`_renumber_levels.py`에 "하나라도 겹치면 아무것도 하지 않는다"는 사전 검사를 넣어 두었다.)

### ② ★UE 개명(rename)은 커맨들릿에서 안 된다 — 복제+삭제로 갔다

`EditorAssetLibrary.rename_asset` / `AssetTools.rename_assets` 둘 다 **11건 전부 조용히 취소**됐다
(로그엔 "완료 0/11"만 남고 이유가 안 보인다). 엔진 소스에 원인이 있었다:

```cpp
// AssetRenameManager.cpp:463
FMessageDialog::Open(EAppMsgType::OkCancel, EAppReturnType::Cancel,
    "... Otherwise assets can be missing from cooked builds. Continue with rename?")
```

**기본값이 `Cancel`** 이라 `-unattended` 에서는 무조건 취소된다. 설정으로 못 끈다.
(뜨는 이유 = 우리 맵이 **CDO 소프트 참조** 대상이다. 문이 목적지를 문자열로 들고 있고 C++ 에도
맵 경로가 하드코딩돼 있다.)

→ `duplicate_asset` + `delete_asset` 은 그 대화상자를 타지 않는다. 라셀 맵이 OFPA(외부 액터)를
쓰지 않는 것을 확인하고 이 길로 갔다.
→ **리다이렉터는 안 남는다.** 하지만 어차피 우리 참조는 전부 문자열이라 리다이렉터로는 안 고쳐진다.
   문자열은 `_fix_portal_names.py` 로 따로 고쳤다(맵 12개 · 17곳).
→ 함정: `delete_asset` 이 True 를 돌려줘도 **디스크의 .umap 은 안 지워진다.** 복제본과 짝을 맞춰
   확인한 뒤 파일을 직접 지웠다. (이름 길이가 달라지면 파일 크기도 달라진다 —
   `L17_Sanatorium`(14자) → `L13_Seir_Sanatorium`(19자)는 260바이트 커진 게 정상이다.)

```
UnrealEditor-Cmd.exe C:/Secret_Project/Secret_Project.uproject ^
  -ExecutePythonScript="C:/Secret_Project/도구/언리얼/_renumber_levels.py" -unattended -nosplash
```
