# 📐 라셀 좌표계 규약 — 모든 레벨이 지키는 하나의 자

> **이 문서가 이기는 범위:** 라셀 안의 모든 위치. 도면(`도구/_rasel_plan.json`)·UE 맵·C++ 좌표가 어긋나면 **여기가 정본**이다.
> **왜 있나:** 좌표를 문서마다 따로 적어 두었더니 동서가 뒤집힌 채 몇 달을 갔다(2026-07-25 발견).
> 자를 하나로 못 박지 않으면 레벨이 서로 말이 안 되는 자리에 앉는다.
>
> 작성 2026-07-25. 갱신 시 `도구/검수/_verify_coords.js`를 돌려 모순을 먼저 확인할 것.

---

## 1. 원점과 축

| 항목 | 값 |
|---|---|
| **원점 (0, 0)** | 아랫장터 **큰길 한복판** (= L01 한가운데) |
| **+X** | **동** — 내륙·상류 쪽 |
| **−X** | **서** — 바다·하구 쪽 |
| **+Y** | **북** — 강 건너 유리탑 쪽 |
| **−Y** | **남** — 신항 재개발지 쪽 |
| **+Z** | 위 |

### ★동서를 헷갈리지 않는 법

라셀은 **에오라 대륙 서안**이다. 그러므로:

- **바다는 서쪽**(−X). 부두도 화물선도 −X에 있다.
- **내륙·상류·옛 도읍 폐허는 동쪽**(+X).
- 요아의 방 창이 **서향**이면 그 창으로 **부두와 바다**가 보인다.

> 옛 `게임_라셀_배치정본.md`가 "하구=동·상류=서"로 적어 두었던 것은 **틀렸고 교정됐다.**
> 근거: `세계관_현대_이야기.md` §1 "에오라 대륙 서안".

## 2. 단위

| 항목 | 값 |
|---|---|
| 문서·도면 단위 | **미터(m)** |
| UE 단위 환산 | **1 m = 100 UU** (`meta.ue_per_m = 100`) |
| 도시 전체 범위 | 약 **14.4 × 9.7 km** |
| 블록 필지 | 긴 쪽 **34 m** 단위로 가름 |
| 1블록 | 약 **200 m** |

문서에 좌표를 적을 때는 **항상 m**로 적는다. UE 스크립트가 100을 곱한다.
**절대 UU로 문서에 적지 말 것** — 그 순간 두 자가 생긴다.

## 3. 수직 켜 (z)

지상은 z=0이 기준면이다. 아래층은 **켜가 정해져 있고**, 임의 깊이를 쓰지 않는다.

| z (m) | 켜 | 무엇 |
|---:|---|---|
| +12 | 옥상 | 요아의 셋방 옥상 |
| +6 | 이층 | 흥신소 등 |
| **0** | **지상** | 기준면 |
| −5.5 | 굴착 갱 바닥 | 신항 |
| **−8** | **폐선 승강장 · 끊긴 지하철 지선** | |
| −12 | 옛 지하수로 | |
| −14 | 갱 → 아래층 연결 통로 | |
| −16 | 승강장 → 아래층 연결 통로 | |
| −18 | **마른 골 밑 통로** (5.5 km) | |
| −22 | **묻힌 도시 회랑** (720 × 440 m) | |
| −26 | 지하철 터널 | |

새 아래층 공간은 **이 표의 켜 중 하나를 골라 쓴다.** 새 깊이가 필요하면 이 표에 먼저 추가하고 쓴다.

## 4. 레벨의 로컬 원점 규약

레벨 맵 하나하나는 **자기 원점을 (0,0,0)에 두고 짓는다.** 도시 좌표는 자리표가 들고 있다.

| 규칙 | 내용 |
|---|---|
| 로컬 원점 | 레벨의 **출입구(주 진입 문) 바닥 한가운데**를 (0,0,0)으로 |
| 방향 | 로컬 +X가 **도시 좌표의 +X**를 향하게 짓는다 (회전 0으로 앉을 수 있게) |
| 자리표 | 도시 좌표는 `_rasel_plan.json`의 `levels[]`가 유일한 정본 |
| 실외 | Level Instance로 `Rasel_City` 좌표에 박는다 |
| 실내 | 별개 맵. 문(Portal)으로 로드 |

### 실내 크기 상한

실내는 **자기가 앉은 필지보다 클 수 없다.** 필지 = 34 m 단위. 골동상 뒷방이 60 m면 앞 건물을 뚫는다.
실내를 지을 때 §1의 자리 좌표에서 필지 크기를 먼저 확인할 것.

## 5. 좌표를 새로 정할 때 밟는 순서

1. **구역을 고른다** — `01_지형과_자리표.md` §1의 8구역 중 어디인가
2. 그 구역 사각형 **안에** 들어가는 (x, y)를 잡는다
3. 아래층이면 §3의 **켜 중 하나**를 z로 고른다
4. **이웃과 말이 되는지 본다** — 문으로 이어지는 상대와 얼마나 떨어져 있나
5. `도구/_rasel_plan.json`의 `levels[]`에 적는다 (문서가 아니라 **여기가 정본**)
6. **`node 도구/검수/_verify_coords.js`를 돌린다** — 모순이 없어야 끝

## 6. 문 연결이 성립하는 조건

문 하나가 A→B로 이어지려면 좌표상 말이 돼야 한다.

| 연결 | 조건 |
|---|---|
| 실내 ↔ 그 건물 실외 | 두 자리가 **80 m 이내** |
| 골목 ↔ 큰길 | **250 m 이내** |
| 같은 구역 안 걸어서 | **600 m 이내** |
| 다른 구역 | 다리·지하철·배 중 하나를 **반드시 거친다**. 문 하나로 잇지 않는다 |
| 지상 ↔ 아래층 | 수직 통로(환기구·갱·계단)가 있어야 하고, **수평 거리 120 m 이내** |

> 이 숫자를 넘는 문은 「순간이동」이다. 페르소나식 허브에서 먼 거리는 **목적지 이동 UI**로 처리하지,
> 문으로 잇지 않는다.
