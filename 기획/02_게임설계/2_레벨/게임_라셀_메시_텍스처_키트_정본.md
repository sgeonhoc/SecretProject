# 🧱 라셀 레벨 키트 정본 — 메시 · 머티리얼 슬롯 · 텍스처

> **무엇:** 라셀 도시 뼈대(`Rasel_City`) 위에 실제 레벨을 세울 때 쓰는 **낱개 부재(메시) 목록**과, 그 부재가 물고 있는

## 0. 세 줄

1. **통짜 메시 금지.** 벽 한 장, 바닥 한 장, 기둥 하나가 각각 별개 액터여야 나중에 골라 지우고 고칠 수 있다.
2. 구시가(A)는 **이미 81개 부재가 저작돼 있다.** 나머지 일곱 구역과 아래층은 그 키트를 **같은 규약으로 확장**한다.
3. 텍스처는 **알베도(`_C`)만** 만든다. 노멀·러프니스는 알베도에서 우리가 스크립트로 파생한다.

## 2. 격자와 피벗 규약 (실측 — 기존 키트에서 그대로)

| 항목 | 값 | 비고 |
|---|---|---|
| 벽 널 | **400 × 320 × 30** (폭×높이×두께) | 층고 320이 기준 단위 |
| 파사드 셸 | **400 × 30 × 640** | 2층 = 320 × 2 |
| 창 구멍 | **160 × 175**, 바닥에서 **z=180** | 칸 한가운데 |
| 문 구멍 | **130 × 245**, 바닥에서 시작 | |
| 바닥 널 | **400 × 400 × 20** | 벽 폭과 같은 격자 |
| 스냅 격자 | **100** (거친 배치) / **10** (맞춤) | |

**피벗 규약** — 이걸 지켜야 복제·회전이 어긋나지 않는다.

- **벽·파사드**: 밑변 중앙, 안쪽 면 기준 (z=0이 바닥, y=0이 실내측)
- **바닥·천장**: 판 중심, z=0이 윗면
- **기둥·소품**: 밑면 중앙
- **문·창 짝**: 구멍 한가운데 (기존 `win_unit`·`door_unit`이 이미 그렇다)

## 2-2. ★무엇을 쪼개고 무엇을 합치나 (가장 자주 어기는 규칙)

> **사용자 지적(2026-07-25):** "레벨 제작할 때 문이랑 벽면이랑 합쳐서 디자인해서 만들 때가 있더라."
> — 실제로 그랬다. 아래는 그걸 못 하게 하는 판정 기준이다.

### 판정 기준 한 줄

**"에디터에서 이것만 지우거나 옮기고 싶은 순간이 있는가?" → 있으면 별개 메시다.**

문만 떼고 벽으로 막고 싶을 때, 창만 다른 크기로 갈고 싶을 때, 차양만 걷고 싶을 때가 온다. 그러니 다 쪼갠다.

### 절대 분리 (한 메시에 넣지 말 것)

| 갈래 | 낱개 부재 |
|---|---|
| 벽 | 벽 널 (구멍만 뚫린 판) |
| 개구부 | 문짝 · 창짝 · 가게 목 — **각각 별개**. 벽에는 구멍만 있다 |
| 장식 띠 | 기단 · 층 사이 띠 · 벽보 살 |
| 지붕 | 처마 · 기와면 · 굴뚝 · 홈통 · 낙수관 |
| 바닥 | 바닥 널 · 보도 · 연석 · 웅덩이 · 패치 |
| 뼈대 | 기둥 · 보 · 계단 한 단 · 계단참 · 난간 |
| 달린 것 | 차양 · 간판 · 등불 · 빨래줄 · 셔터 |

### 합쳐도 되는 것 (한 부재 안에서 절대 안 떨어지는 것)

- **문 유닛** = 문설주 + 문짝 + 댓돌 → 문을 지우면 벽 구멍만 남아야 하므로 이건 한 덩어리가 맞다
- **창 유닛** = 문설주 + 살 + 유리 + 창턱
- 소품 하나(궤짝의 널과 띠쇠 등)

### 슬롯은 나누되 메시는 나누지 않는 경우

한 부재 안에서 재질만 다른 것(문틀 나무 / 유리 / 창턱 돌)은 **머티리얼 슬롯을 나눠** 처리한다.
메시를 또 쪼개지 않는다 — 창 하나가 액터 셋이 되면 배치가 지옥이 된다.

### 🚨 현재 잔재 (감사 결과 2026-07-25)

## 3. 톤앤무드 — ★일관성의 기준

셀셰이드 캐릭터에 얹히는 **스타일라이즈드** 톤. 포토리얼 금지. 무드·조명 > 잡다한 현실 디테일.

### 3-1. 구역 색 앵커 (도시 뼈대에 이미 박혀 있는 값)

텍스처는 이 색 **주변으로 수렴**해야 한다. 뼈대를 실제 재질로 갈아끼울 때 도시가 같은 도시로 남는 유일한 방법.

| 구역 | 앵커 | 성격 |
|---|---|---|
| **A 아랫장터(구시가)** | `#95856A` | 따뜻한 흙빛 · 유기적 골목 |
| **B 학당가·의원권** | `#9B988A` | 밝은 돌빛 · 격자 |
| **W 서편 셋집** | `#9B988A` (조금 어둡게) | 격자 · 주거 |
| **E2 동편 새 동네** | `#9B988A` (조금 밝게) | 격자 · 신흥 |
| **Q 부두** | `#6C8585` | 찬 청록 · 소금기 |
| **C 신항 재개발지** | `#9D7961` | 녹빛 · 공사판 |
| **D 강 건너 유리탑** | `#6C8899` | 찬 청 · 유리와 금속 |
| **F 옛 도읍 폐허** | `#807A6E` | 바랜 회갈 |

### 3-2. 조명 전제 (텍스처를 이 밑에서 볼 것)

- 직사광 **`#FFFAF3`** (따뜻한 해 하나) · 대기 안개 **`#95A6B5`** (찬 청회색)
- **따뜻한 빛 ↔ 찬 그림자**의 대비가 무드의 전부다. 텍스처 자체는 중간 밝기·저채도로 두고, 대비는 조명이 만든다.

### 3-3. 금지

- 사진 그대로의 노이즈·먼지 얼룩 범벅 → 셀셰이드 캐릭터와 따로 논다
- 알베도가 너무 어둡거나(<15%) 너무 밝은 것(>75%) → 조명이 먹히지 않는다
- 채도 높은 원색 → 구역 앵커에서 튄다. 강한 색은 **천·간판·등불에만**

## 4. 텍스처 만드는 법

### 4-1. 알베도만 만든다

`_C`(베이스컬러)만 생성한다. **`_N`(노멀)·`_R`(러프니스)는 만들지 말 것** — 생성 이미지의 노멀맵은 가짜라
UE에서 빛이 이상하게 꺾인다. 우리가 알베도에서 높이를 뽑아 파생한다(기존 절차 텍스처 경로 재사용).

### 4-2. 규격

| 항목 | 값 |
|---|---|
| 해상도 | 벽·바닥 **2048²** / 소품 **1024²** / 데칼 **1024²** |
| 타일링 | **seamless tileable 필수** (데칼 제외) |
| 시점 | 정면 직교 (straight-on / top-down) |
| 형식 | 불투명 PNG 또는 JPG · **데칼만 투명 PNG** |

### 4-3. 공통 프롬프트 꼬리표

```
seamless tileable texture, 2048x2048, orthographic straight-on view,
stylized hand-painted game texture for a cel-shaded game,
flat even lighting, no cast shadows, no highlights, no vignette,
clean color blocking, low noise, muted desaturated palette,
no text, no letters, no symbols
```

앞에 「무엇을」 + 「어느 색으로」를 붙인다. 색은 §3-1 구역 앵커를 그대로 적어 넣을 것.
예: `weathered red brick wall, muted earthy tone around #95856A, ` + 꼬리표

## 7. 구역별 키트 — 메시 · 슬롯 · 텍스처

> 표 읽는 법: **부재**(만들 메시) → **슬롯**(그 메시가 쓰는 머티리얼 자리) → **텍스처**(슬롯에 들어갈 것, ★=새로 뽑을 것)

### 7-0. 구역마다 반복되는 기본 세트 (§2-2 분리 규칙대로)

아래 **일곱 부재는 구역마다 한 벌씩** 만든다(`SM_<구역>_...`). 구역 표에는 그 구역만의 특징적인 것만 적었으니,
읽을 때 이 세트를 항상 얹어서 볼 것.

| 부재 | 무엇 | 비고 |
|---|---|---|
| `Wall_Plain` | 구멍 없는 벽 널 400×320×30 | |
| `Wall_Win` | 창 구멍 하나 뚫린 벽 널 | **구멍만** — 창짝은 따로 |
| `Wall_Door` | 문 구멍 하나 뚫린 벽 널 | **구멍만** — 문짝은 따로 |
| `Win_Unit` | 창 한 짝 (문설주+살+유리+창턱) | 슬롯 3: 틀 / 돌 / 유리 |
| `Door_Unit` | 문 한 짝 (문설주+문짝+댓돌) | 슬롯 2: 틀 / 돌 |
| `Floor_4m` | 바닥 널 400×400×20 | |
| `Ceiling_4m` | 천장 널 | 실내가 있는 구역만 |

구역 성격이 A와 같으면(예: E2의 문·창) A 것을 그대로 쓰고 **머티리얼만 갈아끼운다** — 메시를 중복 저작하지 않는다.
