# 전투 설계 — 8근원 조합 체계 (2026-07-23 · 진행 중 · 사용자와 라이브 설계)

> **사용자 발제(2026-07-23):** 랜덤디펜스식 "쌓아 조합" 재미를 우리 턴제 전투에 얹되, 살란이 소모품이 아니라는 벽을 풀기 위해 **살란 밑에 소모형 근원 재료 한 층을 판다.** 매턴 근원이 생산·누적되고 플레이어가 조합해 올린다.
> **★확정 사항(2026-07-23):**
> - 최하위 = **8근원** (7 소리 근원 + 1 새김 근원 「획기」).
> - **7끼리 조합 = 순수 언어마법**(언령, 문양·회로 없음). **획기와 합치면 = 문양·진·회로**로 넘어감. (캐논 이분법 "소리로 만들면 살란, 새김으로 만들면 살란 글" 그대로.)
> - 근원은 **카드가 아니라 아래 고정 카운터 줄**로 표시(불기 ×3 …). 쌓여도 손패 안 늘어남.
> - 조합은 오행식 **귀속**(뜻 칵테일 아님) — 추상 살란도 근원 지배로 파생.

## 왜 8인가 (5→8 근거)
1. **변수(리플레이):** 기본이 많을수록 매턴 생산되는 재료가 달라져 조합 가능 폭이 달라짐 → 매판이 달라짐(랜덤디펜스 원리). 5는 이 변수를 주기엔 적음.
2. **커버리지:** 5로는 추상 살란(어둠·묶음·열림·아묾)이 안 쪼개져 억지가 남 → 근원 2개(엮기·빔기)가 모자랐던 것. 7 소리 근원이면 추상까지 귀속됨.
3. **캐논 정합:** 7 소리 + 1 새김 = "소리/새김" 두 모드(§문자 정본). 7은 벙어리책 아래층 글자 "일곱이라는 학자"와도 호응.
4. **손 UX:** 플랫 8 아님 — 7 언어 묶음 + 1 회로(떨어진 특수 칸). 고정 카운터라 관리부담 0.

## 8근원

### 7 소리 근원 (언어 뿌리 · 아래 고정 카운터)
| 근원 | 느낌 | 씨앗 살란(파생 예) | 대략 상성 |
|---|---|---|---|
| **불기** | 열·타오름 | 자르(불)·실란(빛) | ↔ 찬기 |
| **찬기** | 식음·가라앉음 | 시스(서리)·루(고요) | ↔ 불기 |
| **물기** | 흐름·스밈 | 마이(물)·후르(바람) | ↔ 땅기 |
| **땅기** | 굳음·무게·버팀 | 켈(돌)·옴(무게)·두르(벽) | ↔ 물기 |
| **울기** | 떨림·퍼짐 | 잔(소리)·카르(깨짐) | ↔ 빔기(고요) |
| **엮기** | 잇고 묶음 | 람(묶음)·코르(닫힘) | 짝=획기 |
| **빔기** | 비움·열림·없앰 | 오르(열림)·무네(어둠)·니르(아묾) | ↔ 울기 |

### 8번째 = 새김 근원
| **획기** | 새김·회로 씨 | 진·문양·룬의 관문 | 7근원과 섞여야 발현 |

- **규칙:** 획기 없이 7끼리 = 언령(소리 마법). 획기 섞임 = 문양·진·회로(새김 마법). → 두 트랙이 이 8번째 하나로 갈림.

## 조합식 — 오행식 귀속 (근원 → 낱말)
> 뜻을 물리적으로 섞는 게 아니라, 어느 근원의 **지배**를 받느냐로 파생(오행 귀속). 추상 살란도 이래서 나옴.

| 낱말(살란) | 귀속 | 비고 |
|---|---|---|
| 자르(불) | 불기 | 순수 |
| 마이(물) | 물기 | 순수 |
| 켈(돌) | 땅기 | 순수 |
| 잔(소리) | 울기 | 순수 |
| 시스(서리) | 찬기+물기 | 식은 물기 |
| 후르(바람) | 물기+불기 | 온도차의 흐름 |
| 실란(빛) | 불기+울기 | 빛나는 떨림 |
| 카르(깨짐) | 땅기+울기 | 굳음에 떨림 |
| 두르(벽) | 땅기+엮기 | 굳혀 세움 |
| 옴(무게) | 땅기+땅기 | 짙은 굳음 |
| **무네(어둠)** | **빔기+찬기** | ★추상 — 비고 식음 |
| **람(묶음)** | **엮기** | ★추상 — 순수 엮음 |
| **코르(닫힘)** | **엮기+땅기** | ★추상 — 엮어 굳힘 |
| **오르(열림)** | **빔기** | ★추상 — 순수 비움 |
| **루(고요)** | **찬기+빔기** | ★추상 — 식어 빔 |
| **니르(아묾)** | **빔기+물기** | ★추상 — 비워 흐름(새살) |

→ **추상 살란이 억지 없이 다 나온다** = 7 근원이 진짜 근원임의 증거(검증 가능한 주장).

## ★최하위 정정(2026-07-23) — 언령+문자 통합
사용자: **"최하위는 언령+문자 통합이야."** → 8근원은 **하나의 통합 풀**이다(소리 7/새김 1로 분리 아님). 획기도 그 풀의 하나이며, **획기가 섞이면 새김(문양·회로) 쪽으로 기운다**는 규칙일 뿐, 별도 재료 트랙이 아니다. 언령이든 문자든 같은 8근원에서 나온다.

## ★★원랜디 참고 — 구조 정정 (2026-07-23 밤, 사용자 "뭔가 이상하다 · 기술은 말도안되게 많다")
사용자가 나랜디/원랜디를 참고하라며 방향 교정. 원랜디 실제 구조 조사(ordsearch.net·나무위키):
- **흔함(기본)** = 매 라운드 랜덤 뽑기 → 위로 조합. **조합 = 3~6개** 유닛 합쳐 상위 하나(2개 아님).
- **등급 사다리:** 흔함 → 희귀(키) → 전설(기준점) → 초월 → 불멸 → 영원 → 제한 → 히든.
- **2차 자원 「목재」**가 큰 조합을 게이트(초월 목재×3·불멸×10·영원×5·왜곡=쓸수록 증가).
- **유닛 수백~수천** — 전용 조합 검색 사이트가 있을 정도.

**★내가 틀린 점(스케일 깎기 [[feedback-scale-never-shrink]] 위반):** 8원소를 깔끔한 화학식(불+물=증기)으로 만들어 기술을 수십 개로 쪼그라뜨렸다. 랜덤디펜스의 핵은 **거대한 조합 로스터의 스프롤**이고, 그게 우리 캐논 "기술 수천 개"와 맞다. 화학식 트리는 그 스케일을 죽인다.

**★정정 방향:**
- **8근원 = 그대로 최하위 재료층**(흔함 뽑기+손 관리 자리)로 유지.
- 그 위는 **화학식이 아니라 거대 조합 로스터:** ①**3~6개 조합**으로 올림 ②**등급 사다리**(흔함→희귀→전설→초월→불멸→영원, 우리 이름으로) ③**2차 자원**(원랜디 목재 자리 = 마력/획기)이 큰 조합 게이트 ④**히든/특수 조합 = 파먹기·스토리 해금** ⑤목표 규모 **수백~수천 기술**.
- **8원소 논리 = "왜 이게 되나"의 문법으로만 남김**, 로스터 자체는 폭발적으로 많게.
- ⚠아래 §무한의 엔진·§조합 트리는 **화학식 소버전(폐기 예정 초안)** — 로스터 폭발은 사용자 "구조 맞다" 확인 후. 오늘 밤은 구조 정정까지만.

## ★★정정판 구조 — 랜덤디펜스식 조합 로스터 (2026-07-23 밤 확정 방향)
> 화학식 소버전을 버리고 원랜디 구조로 재편. **8근원은 재료층으로 유지, 그 위는 거대 로스터.**

**세 층위**
1. **재료층 = 8근원** — 매턴 생산, 아래 고정 카운터. (원랜디 흔함 랜덤 뽑기 자리)
2. **로스터 = 기존 도감 그대로** — `살란_전서`의 350+ 기술을 **새로 안 만든다.** 등급으로 **재편만.** (원랜디 유닛 수백~수천)
3. **2차 자원 = 전리(戰利)** — 전투 중 뜯어낸 마력(기존 설계 [[project-mana-kan-combat-system]] 재사용). 고등급 조합 게이트. (원랜디 목재 자리. ★마나통 없음 캐논과 충돌 0 — 전리는 그 판 한정 뜯는 것)

**등급 사다리 (조합 티어 · 이름 잠정)**
| 우리 등급 | 원랜디 대응 | 조합 재료 |
|---|---|---|
| 근원 | (재료) | 매턴 생산 |
| 낱말 | 흔함 | 근원 2~3 |
| 겹말 | 희귀 | 낱말 3~4 |
| 큰말 | 전설 | 겹말 3~4 + 전리 |
| 비전 | 초월 | 큰말 3~5 + 전리 |
| 절기 | 불멸·영원 | 비전 3~6 + 전리 대량 + 히든 해금 |

**핵심 규칙 (원랜디에서 가져온 것)**
- **조합 = 3~6개** (2개 화학식 아님) — 재료를 여러 개 부어 한 단 위로.
- **2차 자원(전리)이 고등급을 게이트** — 초월·불멸급은 전리 대량 필요(원랜디 목재×10 자리).
- **히든/특수 조합 = 파먹기·스토리 해금** — 기본 조합식은 다 보이고, 히든은 발굴·스토리로 열림. ★이게 사용자가 원래 원한 "클리어 수 해금" 그 자리.
- **한 재료가 여러 조합에** — 같은 낱말이 등급·전리·꼴 따라 다른 상위로 감(원랜디처럼). 화학식처럼 1:1 아님.

**★스케일 (스케일 깎기 교정)**
- 로스터 목표 = 도감 350+ → **수천 기술.** 8근원은 **"왜 이 조합이 되나"의 문법**일 뿐, 로스터 수를 제한하지 않는다.
- 8원소 문법 = 조합식이 말이 되는 이유(불+물=증기). 로스터 규모 = 원랜디 대역(스프롤).

**▷밤샘 루프 할 일 (구조 채우기, 필러 금지)**
1. 기존 도감(`살란_전서` 350장)을 등급 사다리로 **재편**(새 기술 창작 0, 분류만).
2. 등급별 조합식 규격(몇 개·전리 얼마) 실제 수치.
3. 히든 해금 목록(파먹기·스토리 연동) 얼개.
4. 전리 획득·소모 밸런스(기존 전리 경제 재사용).
5. 웹페이지를 정정판 구조로 갱신.

## ★무한의 엔진 (조합이 끝없이 쌓이는 규칙)
1. **아무 두 개 = 한 단 위** (근원→낱말→겹말→큰말→대주문→…, 상한 없음).
2. **원소 상성(생극)이 결과를 정함** — 스크립트가 아니라 규칙에서 창발(불+물=증기, 서리+바람=눈보라).
3. **각 층에 꼴(범위)×맺음(-타/-사/-노)×획기(새김 여부)가 곱해짐.**
→ 8근원×개수×상성×꼴×맺음 = 상한 없음. 캐논 못 박음: "마력에도 한계가 없고 살란에도 한계가 없다"(§문자 정본).

### 문자/회로 가지 (획기 얹으면 새김 — 소리 트리와 평행)
| 결과 | 조합식 | 효과 |
|---|---|---|
| 기초 진 | 획기+땅기 | 바닥 설치대 |
| 불 부적 | 획기+불기 | 1회 방아쇠 폭발 |
| 용암 진 | 획기+용암 | 밟으면 분출 함정 |
| 올가미 진 | 획기+람 | 설치 속박 |
| 우레 문양 | 획기+우레 | 광역 기절 방아쇠 |
| 대진 | 획기+큰말 | 맵 규모 설치 |
→ **어느 층 소리 조합이든 획기를 얹으면 그 층의 새김(진·문양)이 된다** → 회로 트리가 소리 트리 옆에 평행하게 무한히 뻗음.

## 티어(등급) — 조합이 위로 쌓임
| 등급 | 재료 | 성능대 |
|---|---|---|
| **근원**(공용) | 매턴 생산 | 재료(직접=미미) |
| **낱말** | 근원 조합 | 자잘기 20~40 |
| **겹말** | 낱말 2 | 주력기 50~90 |
| **큰말** | 겹말+낱말 | 대형기 120~200 |
| **대주문** | 큰말들 | 피날레 300+ |
- 발현 = (조합해 올린 낱말/겹말) × 꼴(범위) × 맺음(-타/-사) — 기존 조합대 층 그대로 위에 얹음.

## 한 턴 흐름
매턴 → 8근원 중 몇 개 생산돼 아래 카운터에 누적 → 플레이어가 근원 끌어 낱말/겹말 조합(획기 섞으면 문양·진) → 꼴·맺음 붙여 발현. 판 갈수록 근원 쌓여 위 티어 조합 = 스노볼.
