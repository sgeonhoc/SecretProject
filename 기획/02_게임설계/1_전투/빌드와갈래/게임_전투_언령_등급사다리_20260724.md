# 언령(순수 살란) 등급 사다리 — 도감 512장 재편 (2026-07-24 · 루프 4회차)

> **선행:** 소리 루트 16계열 · 새김 루트 · 살란문자
> **작업:** 도감의 **소리길 카드를 일반~에픽 사다리에 배치**한다. 새로 만들지 않고 **있는 것을 등급으로 옮긴다.**

3. **★T10이 0개다.** 게임 상한이 T10인데(2026-07-18 사용자 확정) **도감에 T10 카드가 없다** — 술자만의 자리로 비워 둔 것인지, 아직 안 쓴 것인지. §6 열린 물음.

## §3 ★배치에서 드러난 문제 둘

### 문제 1 — 에픽 자리가 카드 1장뿐

T9가 「골수 서리」 하나다. **에픽 정령 열여섯이 쓸 T9 카드가 계열마다 없다.**

- 로스터에서 에픽은 "불 계열 전부 + 「불의 강」T7 포함"이라 적었다 — 즉 **T7~8로 채우고 있었다.**
- **★그래서 실질 에픽 언령 = T7~8(16장)**이고, T9는 예외적 한 장이다.

> **★정정:** 에픽 등급의 언령 자리는 **T7~9를 함께** 본다. T9 하나만으로는 열여섯 계열을 못 채운다. 다만 이것이 결함은 아니다 — **에픽 정령의 값은 T9 카드가 아니라 「고유의 곱」에 있다**(로스터 §17: 에픽 열여섯이 전부 "판 전체 + 곱하기"). 언령 자체를 T9로 안 올려도 된다.

### 문제 2 — 레어가 239장으로 비대

T3~4에 239장이 몰려 있다. 레어 정령의 익힘 상한은 3인데 고를 것이 239개다.

- **이것은 결함이 아니라 자산이다** — 같은 레어라도 **어느 셋을 익혔냐로 완전히 달라진다.** 랜디의 "같은 유닛인데 빌드가 다름"이 여기서 나온다.
- 다만 **UI가 239장을 보여줄 수 없다** — 계열로 걸러야 한다(불 정령이면 자르 계열만 뜸). 계열당 평균 **15장**이라 고를 만하다.

## §4 언령 조합 사다리 (재료 관점)

언령은 **살란(낱말)을 조각으로 배열**해 만든다. 등급이 오르면 **문장이 길어진다**(재료 사슬 §4 확인):

| 등급 | 조각 수 | 재료(살란) | 누적 원소 |
|---|---|---|---|
| 일반(한 마디) | **2** | 살란 ×1 | 3 |
| 매직(T2) | **6** | 살란 ×3 | 9 |
| 레어(T3~4) | **7~8** | 겹살란 ×1 | 27 |
| 스페셜(T5) | **9** | 겹살란 ×3 | 81 |
| 유니크(T6~7) | **10~11** | 큰살란 | 162+ |
| 전설(T8) | **12+** | 큰살란 ×2 + 전리 | 324+ |
| 에픽(T7~9) | 12+ · **채널** | ×2 + 전리 | 648+ |

**★T7 위는 조각 수가 아니라 「칸을 여러 턴 붓는 것」으로 오른다** — 「불의 강」(칸 2×3턴)·「내려앉는 하늘」(칸 2×4턴). 문장 길이의 천장을 **시간**으로 넘는다(캐논 §4-3: *굵기 위는 시간으로 잇는다*).

## §5 ★언령만의 값 (세 루트 비교 확정)

| | 언령 |
|---|---|
| **즉시성** | 그 턴에 나간다 — 설치·새김 없이 |
| **계열 자유** | 살란만 있으면 어느 계열이든 (그릇 불필요) |
| **재료 가벼움** | 획기가 아예 안 든다 — **순수 소리 루트만** |
| **다중영창과 물림** | 「겹쳐 외기」·「이어 외기」로 **한 칸에 여럿** — 새김은 이게 안 됨 |

**★언령 빌드의 정체:** 그릇(획)을 안 쓰니 **획기 전량을 다른 데(정령·자원 가속) 돌릴 수 있다.** 반대로 획기가 마른 판에서도 언령은 돈다 — **가장 안 막히는 루트.**

## §6 구멍 · 견제 짝

| 구멍 | 내용 |
|---|---|
| **안 남는다** | 그 턴에 사라진다. 초반 투자가 후반에 안 남는다 |
| **매번 외야 한다** | 술자가 칸을 계속 써야 한다(글 진처럼 깔아 두고 잊을 수 없다) |
| **★방해에 통째로 열림** | 완성 끊기 다섯 계열(잔·코르·후르·무네·카르)이 전부 언령을 노린다 |
| **못 베낀다** | 소리는 고정이 아니라 길들지 않는다(§2-5) — 문자 베끼기 가속을 못 씀 |
| **T10 공백** | 도감에 T10이 0장. 게임 상한인데 카드가 없다 |

**견제 짝(언령 빌드의 천적):**
- **코르 「말 끊기」**(칸 1·부은 칸 소멸) — 가장 싸다
- **루 「고요 벽」**(자리 안 언령 완성 칸 +1·**피아 공통**) · **「턱 닫힘」**(한 턴 언령 봉쇄)
- **람 「입 봉하기」**(T6·한 턴 언령 봉쇄) · **켈/몸길 「목 조르기」**(붙잡은 동안 전면 봉쇄)
- **후르 「숨 뺏는 바람」**(부은 칸 소멸)

> **★언령은 가장 안 막히지만(재료) 가장 잘 끊긴다(방해).** 재료의 자유와 방해의 취약이 맞바꿈이다.

## §7 세 루트 최종 대조표

| | **언령**(순수 살란) | **진**(순수 획) | **살란문자**(둘) |
|---|---|---|---|
| 재료 | 원소만 | 획기만 | 둘 다 |
| 카드 수 | **512** | 그림길 144 | 글 진 (진꼴 다수) |
| 등급 봉우리 | **T5**(170) | 스페셜~유니크 | 레어~스페셜 |
| 속도 | 즉시 | 설치 후 | 가장 느림 |
| 남나 | ✗ | ✓(깨울 때마다) | ✓(남음) |
| 베낌 | ✗ | 부분 | **✓** |
| 천적 | **완성 끊기 5계열** | 카르(심 짚기) | 카르(홈 하나) |
| 게임 자리 | 직격·난사·즉응 | 자동화·자원 | **정령**·베끼기 |

**★도감 512장이 언령에 몰려 있다** — 그림길 144, 몸길·매개 나머지. 소리길이 도감의 절반이니 **언령이 기본기고 나머지가 특화**라는 구조가 카드 수로도 확인된다.

## §8 열어 둔 것
- **T10 공백** — 게임 상한인데 도감에 0장. ①술자 전용으로 비워 둘지 ②계열별 T10을 만들지. **만들면 에픽 정령이 쓸 자리가 생긴다**(지금은 T7~8로 대체 중).
- **T9도 1장뿐** — 에픽 열여섯 계열 대비 얇다. 다만 에픽의 값은 고유의 곱이라 급하지 않다.
- 레어 239장의 UI 필터(계열별 15장으로 걸러 보여주기).
