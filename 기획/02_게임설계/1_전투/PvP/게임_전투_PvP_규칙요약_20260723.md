# PvP 규칙 요약 (2026-07-23 · 루프 20회차 · 한 장 정리)

> **선행 전량:** PvE 토대(뼈대·로스터 112·라운드곡선·전리·뽑기·시뮬 R1~40·무리 성격·뽑기 운/히든) + 술자 빌드 다섯 + PvP 1·2차·시뮬.
> **이 파일 = 전투 설계 한 바퀴의 도착점.** 흩어진 규칙을 한 장으로 모으고, 마지막 두 물음(정보 노출·매개길)을 닫는다.

## §1 마지막 두 물음을 닫는다

### 1-1. 정보 노출 — 무엇이 보이나

캐논 §4-3: *"오래 붓는 술자는 그동안 눈과 숨과 혀가 문장에 매여 있다 — 무방비의 값."* **붓는 것은 보인다.**

| 보이는 것 | 안 보이는 것 |
|---|---|
| 판에 선 정령(등급·계열·꼴) | 이번 턴 **칸 배분**(비공개, 동시 공개) |
| **여러 턴 붓는 대주문**(붓는 중 드러남) | 깔아 둔 **진·선걸기·갈래**(그림길·매개길의 밑천) |
| 정령의 버팀 상태(상한 것은 보임) | 손패에 든 카드 |
| 표면(불·젖음·서리·그늘) | — |

**★이 경계가 빌드 성격을 가른다:**
- **소환·난사·대형**은 판에 드러나는 빌드다 — 상대가 보고 대응한다.
- **그림길(자동화)·매개길**은 숨는 빌드다 — 깔아 둔 것이 안 보여, 상대가 밟거나 맞아야 안다.
- 대주문은 **붓는 중 보이므로** 완성 끊기(1단계)에 열려 있다 — 「숨죽인 영창」(말 끊기·되받기에 안 읽힘)이 그 값을 산다.

### 1-2. 매개길 견제 — 한 판 안에서 되는가

매개길은 상대의 **닮음·닿음**(머리카락·피·꼴)으로 눈을 우회한다(§2-4). PvE에서는 무리에 매개물이 없어 못 썼다. PvP에서는 상대 술자가 있으니 매개물이 있다 — 그런데 **판 밖에서 얻는 것**(왕이 머리카락을 금고에 두는 까닭)이라 한 판 안에서 어떻게 얻나.

> **PvP 규칙: 상대 정령을 잡으면 그 술자와의 「닿음」 조각 하나가 나온다**(전리와 함께). 그것을 매개로 걸면 **정령을 통째로 우회해 술자에게 직행**한다.

**★이것이 매개길에 판 안 자리를 준다** — 정령을 부술수록 매개가 쌓이고, 매개가 쌓이면 정령을 안 부수고 술자를 직접 친다. **견제(정령 부수기)가 견제 수단(매개)을 낳는** 순환. 다만 값이 얇다(멀수록 얇다·§2-4) — 매개길만으로는 술자를 못 죽이고, 마무리의 한 수다.

**정정 10:** 매개 조각은 **상대 정령을 잡을 때만** 나온다(판 밖 자원을 판 안 규칙으로 치환). 걸면 그 술자에게 직행하되 값 얇음.

## §2 ★PvP 규칙 한 장

### 판
- **양쪽 술자 하나씩.** 버팀 **6000**(+10%/라운드). 술자가 죽으면 진다.
- **한 판 = 50~70라운드**, 1라운드 = 3턴.

> **★2026-07-24 정정(사용자 "판은 길다"):** 옛 값(12~16R·버팀 2000)은 짧은 판을 전제로 내가 역산한 것이라 **폐기**했다. 빌드업 게임인데 유니크(사람 꼴)조차 못 보고 끝나면 성립하지 않는다. PvE 100R의 절반쯤이 PvP다 — 상대가 능동으로 견제하니 더 빨리 결판나되, **최소 유니크(R35)는 봐야** 한다. 자세한 역산은 `../시스템/게임_전투_판길이_리듬_20260724.md`.
- 술자 칸 **6 + 0.5/라운드**. 뽑기 **2/3/4/5**(구간별).

### 매 턴 (동시 해결)
1. 양쪽이 칸 배분을 **비공개로 정한다.**
2. **동시에 공개**하고 5단계로 해결한다:
   **① 방해**(완성 끊기·봉쇄·되받기) → **② 설치·유지**(진·표면·벽·묶음) → **③ 직격** → **④ 잡힘 판정**(버팀 0 이하 동시 제거·서로 잡으면 둘 다) → **⑤ 정산**(전리)
- 같은 정령을 동시에 노리면 **「빠른 손」** 든 쪽이 먼저.

### 정령
- 뽑기→합침(2~3:1)→갈래(칸2·+15%·라운드당 하나)로 키운다.
- **자동으로 싸운다**(우선순위). 술자가 칸 1로 그 턴 지정 가능.
- **「앞을 가리는」 고유**(돌지킴·두르·그늘담)를 가진 것만 술자를 대신 맞는다.

### 술자에게 값이 닿는 길
- 직격이 술자에게 가면 **값 절반**(정령이 「앞을 가리면」 그 정령부터 지워야 함).
- **막이 통과 넷**(후르·실란·카르·오르): 막이 정령의 한 겹을 지나 뒤를 침.
- **매개길**: 정령을 통째로 우회·직행(매개 조각 필요·값 얇음).

### 전리 (PvP의 심장)
- **라운드÷2의 절반만 자동 + 나머지 절반은 상대 정령을 부순 만큼.**
- **빌드만 하면 전리가 안 모여 상위 불가. 견제만 하면 정령이 없어 산출을 못 막음.**

## §3 ★전투 설계 한 바퀴 — 착수부터 여기까지

| 단계 | 산출물 | 핵심 |
|---|---|---|
| 구조 | 소환빌드 뼈대(제1~3부) | 정령=또 하나의 술사(도감 카드를 씀) |
| 로스터 | 정령 112마리(6파일) | 16계열 × 7등급, 꼴·고유·턴 행동 |
| 곡선 | 라운드곡선·전리·뽑기 | 도달선 R5/R9/R14/R22 |
| 검증 | 시뮬 R1~40(3파일) | **정정 6건** — 계단 곡선·합침 조건·갈래 +15%·에픽 익힘 16 |
| 살 | 무리 성격·뽑기 운/히든 | 로스터 구멍이 값을 가짐·물림 20회 해금 |
| 술자 | 술자 빌드 다섯 갈래(2파일) | 식힘을 이기는 빌드·다섯 다 정령을 요구 |
| PvP | 1·2차·시뮬·요약(4파일) | **정정 4건** — 뼈대를 깎아 만듦 |

**★사용자가 처음 판 것들이 전부 제자리를 찾았다:**
- *"랜덤디펜스식 쌓아 조합"* → 등급 사다리·합침
- *"살란은 소모품이 아니라 지식"* → 정령이 도감 카드를 씀(소모 아님)
- *"시간이 지나면서 상대도 크는"* → PvP 치환(무리=상대 정령)
- *"초반 견제가 더 위협적"* → 사다리 복리(수치 확인)
- *"빌드하면서 견제도 = 정석, 심리전"* → 전리 반반 + 동시 해결
- *"정해진 게 없다"* → 섞기가 정석이되 매 턴 배분은 도박

## §4 아직 안 한 것 (다음 큰 갈래)

**전투 설계의 뼈대·살·검증은 한 바퀴 돌았다.** 남은 것은 **폴리시와 확장**이다:

1. **정령 이름 재작명 + 등급 이름** — 사용자 확정 대기(*"정령 이름도 이름답게 바꿀 거고, 등급도 우리 세계관에 맞게 나중에"*). 지금은 잠정 살란 고유명·게임식 등급.
2. **정령 로스터 이름 충돌 대조** — 도감 1,031장과 겹치는 것 솎기(불담·서리못·돌창·우레 등).
3. **웹페이지** — 전투 설계 전체를 검수용 페이지로(사용자 상설 지시 "주기적 웹 업데이트로 검수").
4. **제 식힘 줄이는 카드** — 도감에 없음. 만들지 말지 사용자 확인.
5. **UE C++ 이식** — HexBattle 모듈([[project-hex-battle-ue-module]])과의 관계 정리.
6. **PvP 밸런스 심화** — 술자 빌드별 상성(몸 vs 소환·대형 vs 난사).
