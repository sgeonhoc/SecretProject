# 지수 재료표 — 근원부터 에픽 정령까지 (2026-07-24)

> **사용자 확정(2026-07-24):** *"상위 정령으로 갈수록 하위재료는 말도 안 되게 많이 들어가. 최하위 재료는 항상 말도 안 되게 필요해. 그러니까 자원값을 올리는 속도를 올리는 빌드도 있을 거고 거의 필수. 그리고 그 자원 빌드를 견제하는 마법들도 그래서 있는 거야."*
> **★스케일 원칙([[feedback-scale-never-shrink]]):** 하위 재료는 지수로 폭발한다. 정령은 흔한 게 아니라 하나하나가 재료의 산이다. **줄이지 않는다.**
> 이 표가 뼈대의 밑바닥이다 — 여기가 확실해야 깎고 붙이는 속도가 붙는다.

---

## §1 두 축이 지수로 오른다 — 갈래(등급) × 깊이(조합)

재료가 폭발하는 이유는 곱이 두 번 걸려서다:

1. **등급 사다리**(정령): 3:1(상위는 2:1) — 매직=일반 3, 레어=매직 3…
2. **조합 깊이**(재료→살란→정령): 각 층도 3:1 — 살란=원소 3, 문양=획기 3…

**두 사다리가 곱해진다.** 그래서 최하위(근원)는 지수로 든다.

---

## §2 정령 하나의 밑재료 (등급별)

### 계산 규칙
- 정령 = **심(살란) + 그릇(진 계열)**. 둘 다 근원에서 올라온다.
- 등급 오름 = 정령 3(상위 2) 합침 = **심·그릇이 함께 3배(2배)**.
- 심: 살란 = 원소 ×3 / 겹 = 살란 ×3 …
- 그릇: 문양·회로 = 획기 ×3 / 진 = 문양 ×5 …

### 순수 계열(불) 기준 — 근원 총량

| 등급 | 정령 재료(직접) | **누적 원소**(심) | **누적 획기**(그릇) | 근원 합계 |
|---|---|---|---|---|
| **일반**(자린) | 자르 + 문양 | 3 | 3 | **6** |
| **매직**(자르미) | 자린 ×3 | 9 | 9 | **18** |
| **레어**(자르나) | 자르미 ×3 | 27 | 27 | **54** |
| **스페셜**(자르담) | 자르나 ×3 | 81 | 81 + (진 전환 ×5) | **~200** |
| **유니크**(자르셀) | 자르담 ×2 | 162 | ~400 (진) | **~560** |
| **전설**(자르간) | 자르셀 ×2 | 324 | ~800 | **~1,100** |
| **에픽**(자르온) | 자르간 ×2 | 648 | ~1,600 (대진) | **~2,250** |

> **★에픽 하나 = 근원 2천 개 넘음.** 그릇(획기)이 진 전환(5:1)에서 심보다 빨리 커져 — 유니크부터 획기가 원소를 앞지른다. **그래서 획(그릇)이 상위의 진짜 벽이다.**

### 왜 그릇이 심을 앞지르나
- 심: 3:1로만 오른다 (원소 648)
- 그릇: 문양까지 3:1 → 진에서 **5:1** → 대진에서 다시 3:1. 진 전환의 5배가 누적돼 획기가 폭발.
- **정령이 상위로 갈수록 "무슨 힘이냐(심)"보다 "얼마나 큰 그릇에 앉았냐"가 재료를 먹는다** — 로스터 §10 "유니크에서 사람 꼴이 선다"가 곧 그릇이 진으로 커지는 자리.

## §3 ★이래서 자원 가속이 필수다 — 수치로

### 고정 지급만으로 얼마나 걸리나

원소가 매 턴 랜덤 ~3개(한 계열엔 3/16 ≈ 0.2개), 획기가 매 턴 고정 3개라 치면:

| 목표 | 필요 근원 | 고정 지급만으로 | 판 길이(12~16R) 안? |
|---|---|---|---|
| 레어 | 54 | ~9턴 (3R) | ✓ |
| 스페셜 | ~200 | ~22턴 (7R) | ✓ |
| 유니크 | ~560 | ~40턴 (13R) | 빠듯 |
| 전설 | ~1,100 | ~75턴 (25R) | **✗ 판 넘김** |
| 에픽 | ~2,250 | ~150턴 (50R) | **✗✗ 불가능** |

> **★고정 지급만으로는 유니크가 천장이다.** 전설·에픽은 **자원 가속 없이는 물리적으로 못 만든다** — 판이 먼저 끝난다. 그래서 자원 빌드가 "있으면 좋은" 게 아니라 **상위를 여는 유일한 열쇠**다.

### 자원 가속이 곡선을 바꾼다

가속 빌드로 생산이 매 턴 2배·3배가 되면:

| 생산 배수 | 에픽 도달 |
|---|---|
| ×1 (고정) | R50 (불가) |
| ×2 | R25 (빠듯) |
| ×3 | R17 (가능) |
| ×4 | R13 (여유) |

**가속을 얼마나 일찍·크게 까느냐가 곧 "몇 등급까지 가느냐"다.** 스타크래프트 일꾼과 같다 — 초반에 자원에 칸을 부으면 지금 약하지만 상위가 열리고, 안 부으면 지금은 버티는데 유니크에서 막힌다.

---

## §4 세 층 빌드 구조 (자원 층이 밑에 깔린다)

지금까지 빌드를 다섯으로 봤는데, 그 **밑에 한 층이 더 있었다:**

```
[상위 빌드]  소환 · 강화 · 본인강화 · 대형완성 · 난사
                    ▲ 이 전부가 재료를 먹는다
[자원 층]    ★자원 가속 — 원소·획기 생산을 올린다
                    ▲ 상위 빌드의 전제
[재료 층]    8원소(랜덤) + 획기(고정)
```

- **자원 빌드 = 랜디의 경제.** 안 깔면 상위 못 가고, 너무 깔면 지금 약하다 — 이 긴장이 "빌드 안 하면 비효율"의 진짜 뿌리(사용자 최초 발언).

---

## §5 ★그래서 자원 견제가 성립한다 (사용자 확정)

자원 빌드가 필수면, 그걸 때리는 견제도 필수다. 대칭이 완성된다:

| 자원 축 | 가속(내 것) | 견제(상대 것) |
|---|---|---|
| **원소 생산** | 매 턴 뽑는 수·종류 늘림 | 상대 생산 늦추기·계열 흐리기 |
| **획기 생산** | 술자가 한 번에 여러 획 | 술자 방해·손 묶기(람 「손목 묶기」) |
| **쌓인 재료** | — | **부수기** — 카르 「홈 흐리기」·「진 헛깨우기」가 쌓인 진을 깬다 |
| **조합 효율** | 오르 「합침 칸 절반」·「먹임 절반」 | 코르 「말 끊기」로 합침 완성 끊기 |

> **★견제의 정체가 바뀐다:** 획기가 고정 생산(술자 손)이라 **생산 자체는 못 끊는다** — 대신 **쌓인 것·진행 중인 진을 부순다.** 그러면 술자가 다시 그어야 하니 시간을 잃는다. 생산 차단이 아니라 **재고 파괴**라 공방이 생긴다(술자가 "다시 긋는" 반응).
> - 카르(깨짐)가 **자원 견제의 주력** — 「홈 흐리기」(진 완성 지연)·「진 헛깨우기」(설치 진 소진)·「매개 끊기」가 전부 쌓인 재료를 때린다.
> - 이것이 로스터의 카르 계열이 PvP에서 값이 뛰는 셋째 자리(앞선 둘: 막이 부수기·방어 무효).

## §6 검산 — 이 표가 앞 설계와 맞물리나

| 앞 설계 | 이 표와 |
|---|---|
| 로스터 "에픽은 판을 통째로 갈아 넣는 것" | ✓ 근원 2,250개 = 판 하나 |
| 시뮬 "대부분 판은 스페셜~유니크" | ✓ 고정 지급 천장이 유니크 |
| 뽑기 운(계열 랜덤) | ✓ 원소가 랜덤이라 계열 맞추기가 이미 병목 |
| "빌드 안 하면 비효율"(최초 발언) | ✓ 자원 층이 그 뿌리 |
| 오르 계열 "합침 칸 절반·먹임 절반" | ✓ 자원 가속의 실카드 |
| 카르 계열 "홈 흐리기·진 헛깨우기" | ✓ 자원 견제의 실카드 |

**앞 설계를 하나도 안 뒤집고 밑바닥 한 층이 더 깔렸다** — 스케일을 키우는 쪽이라 [[feedback-scale-never-shrink]] 정합.

## §7 열어 둔 것 / 다음
- **정확한 조합 개수 확정** — 진 5:1이 맞는지, 상위 2:1 전환 지점이 유니크가 맞는지(시뮬).
- **자원 가속 빌드 카드 목록** — 도감에서 생산 올리는 것 전수(오르 계열 + 몸길 「숨 돌리는 마디」류 + 잔 「말 고르기」류).
- **자원 견제 빌드 카드 목록** — 카르 중심 + 람(손 묶기) + 코르(합침 끊기).
- **획기 매 턴 지급값** — §3은 3 가정. 정령 희소도의 핵심 다이얼.
