# 자원 가속·견제 전량 + 조합식 + UI/UX/연출 (2026-07-24)

> **사용자 확정(2026-07-24):**
> - **판 길이는 길다.** 12~16R은 내가 멋대로 역산한 것 — 폐기. *"게임이 빌드업 하는 게임인데 겨우 만들었더니 바로 끝나면 어떡해."*
> - **자원 가속은 술사 본인이 만드는 매커니즘이다** — ①진을 깔아 특정 원소가 쌓이게 ②마법으로 살란문자를 복제 ③다중영창으로 언령 동시 전개 …여러 방식.
> - 그 가속을 **견제하는 마법**도 그래서 있다.
> - **어떤 류든 에픽까지 쫙 깔고, 조합식·조합 방식·UI·UX·연출까지.**
> ★=여기서 확정. 도감에 씨앗이 있는 것은 실카드명 표기.

# 제1부 — 자원 가속 세 방식

**세 방식이 세 발현에 각각 붙는다.** 술사가 어느 발현에 강하냐에 따라 가속 갈래가 갈린다.

| 방식 | 발현 | 성격 | 약점 |
|---|---|---|---|
| **① 샘 술식** | 진(순수 획) | 깔아 두면 저절로 쌓임 | 눈에 보이고 부술 수 있음 |
| **② 문자 베끼기** | 살란문자(살란+획) | 만든 것을 불림 | 원본이 있어야 함 |
| **③ 다중영창** | 언령(순수 살란) | 처리량이 늘어남 | 영창 방해에 약함 |

---

## §1 방식① 샘 술식 — 진에 원소가 고인다

> **도감 씨앗:** 「진 앞당겨 깨우기」T3 합 조건에 *"샘 술식과 이어져 있으면"* — 샘 술식이 이미 캐논에 있다.
> **원리:** 진은 마력이 도는 그릇이다. 도는 길을 한쪽으로 기울여 **고이게** 만든 것이 샘 술식. 술사가 깔아 두면 매 턴 그 계열 원소가 쌓인다.

| 등급 | 이름 | 조합식(재료) | 산출 | 비고 |
|---|---|---|---|---|
| **일반** | 「샘 문양」 | 획기 ×3 | 매 턴 **원소 +1**(계열 하나 지정) | 첫 삽. 대개 R1에 깐다 |
| **매직** | 「샘 회로」 | 샘 문양 ×3 | 매 턴 **+2** | 도는 길이라 안 마름 |
| **레어** | 「작은 샘 진」 | 샘 회로 ×3 | 매 턴 **+3** · **계열 둘** | 두 계열을 한 진에서 |
| **스페셜** | 「샘 진」 | 작은 샘 진 ×3 + 전리 3 | 매 턴 **+5** | 여기부터 판이 돌아간다 |
| **유니크** | 「여문 샘 진」 | 샘 진 ×2 + 전리 8 | 매 턴 **원소 +8 · 획기 +2** | ★획기까지 낳는다 |
| **전설** | 「큰 샘 진」 | 여문 샘 진 ×2 + 전리 20 | 매 턴 **원소 +12 · 획기 +4** | |
| **에픽** | 「대샘진」 | 큰 샘 진 ×2 + 전리 50 | 매 턴 **원소 +20 · 획기 +8 · 계열 자유** | 판 하나가 샘이 된다 |

**★유니크부터 획기를 낳는 것이 핵심** — 그릇이 그릇을 만든다. 여기를 넘기면 자기증식이 시작돼 상위 정령이 열린다(지수 재료표 §3의 그 문턱).

**연출:** 진 홈에 빛이 고여 넘실댄다. 등급이 오를수록 고인 빛이 진 밖으로 흘러넘쳐 바닥을 적신다.

## §2 방식② 문자 베끼기 — 만든 것을 불린다

> **도감 씨앗:** 「진 자국 탁본지」(도구) — *"남이 판 진의 홈에 대고 문지르면 그 결이 뜬다."* 베끼기가 이미 세계에 있다.
> **원리:** 살란문자는 **꼴이 고정된 것**이라 베껴진다(캐논 §2-5 "고정된 것만이 길든다"). 소리는 못 베끼고 새김은 베껴진다 — 그래서 이 방식은 문자(살란+획)에만 선다.

| 등급 | 이름 | 조합식 | 산출 |
|---|---|---|---|
| **일반** | 「탁본 한 장」 | 획기 ×2 + 살란 ×1 | 만든 **살란 하나를 베껴 하나 더** (1회) |
| **매직** | 「겹탁본」 | 탁본 ×3 | 살란 하나 → **둘** |
| **레어** | 「베끼는 붓」 | 겹탁본 ×3 | 매 턴 **살란 하나 복제**(상시) |
| **스페셜** | 「스스로 베끼는 판」 | 베끼는 붓 ×3 + 전리 3 | 매 턴 **문양·회로도 복제** |
| **유니크** | 「거울 진」 | 판 ×2 + 전리 8 | 매 턴 **가진 것 중 하나를 통째 복제**(진 포함) |
| **전설** | 「겹거울」 | 거울 진 ×2 + 전리 20 | 매 턴 **둘 복제** |
| **에픽** | 「끝없는 베낌」 | 겹거울 ×2 + 전리 50 | 매 턴 **가진 것의 10%가 저절로 늘어남** |

**★이 방식은 곱셈이다** — 샘이 덧셈(+N)이라면 베끼기는 배수. 가진 게 많을수록 커져 **후반이 폭발적**이지만, **초반엔 베낄 원본이 없어 아무 값이 없다.**

**연출:** 종이에 먹이 배어 같은 글자가 옆에 스미듯 뜬다. 상위에선 허공에 문자가 겹쳐 갈라진다.

## §3 방식③ 다중영창 — 한 입으로 여러 문장

> **도감 씨앗(전부 실카드):** 「겹쳐 외기」T3(한 칸에 자잘기 둘~셋) · 「이어 외기」T5(같은 계열 하나를 칸 0으로) · 「나눠 외기」T4 · 「되받아 잇기」T3(**칸 0**·칸 +1) · 「겹창 나눠 쥐기」T4 · 「숨 돌리는 마디」T2(**칸 0**·칸 +1/합 +3)
> **원리:** 소리는 한 줄이라 갈래가 없다(캐논 §2-2). 그 한 줄을 **더 빨리, 더 겹쳐** 굴리는 것이 이 방식 — 재료가 아니라 **칸(처리량)**을 늘린다.

| 등급 | 이름 | 조합식 | 산출 |
|---|---|---|---|
| **일반** | 「고른 숨」(실카드 T2) | 살란 ×3 | **칸 0 패시브** · 끊겨도 절반 남음 |
| **매직** | 「숨 돌리는 마디」(실카드 T2) | 고른 숨 ×3 | **칸 +1** (합: -타 둘이면 **+3**) |
| **레어** | 「겹쳐 외기」(실카드 T3) | ×3 | 한 칸에 **자잘기 둘**(같은 계열이면 셋) |
| **스페셜** | 「이어 외기」(실카드 T5) | ×3 + 전리 3 | 같은 계열 하나를 **칸 0**으로 |
| **유니크** | 「두 입 영창」 | ×2 + 전리 8 | ★**서로 다른 계열 문장 둘을 동시에** |
| **전설** | 「세 입 영창」 | ×2 + 전리 20 | ★**셋 동시** · 조합도 동시에 |
| **에픽** | 「만 입의 말」(실카드 T9) | ×2 + 전리 50 | 스물여섯 마디를 한 숨에 — **그 턴 칸 제한 없음** |

**★이 방식은 재료를 안 늘린다 — 재료를 쓰는 속도를 늘린다.** 그래서 샘·베끼기와 겹쳐 써야 값이 난다(재료가 있어야 빨리 쓸 수 있다). **혼자 쓰면 쓸 게 없어 헛돈다.**

**연출:** 술사 입에서 문장이 두 갈래, 세 갈래로 갈려 나온다. 에픽에선 목소리가 여럿으로 겹쳐 들린다.

# 제2부 — 자원 견제 (가속마다 약점이 다르다)

**★생산 자체는 못 끊는다**(획기는 술사 손, 원소는 세상에서 옴). **쌓인 것·돌아가는 장치를 부순다** — 그러면 술사가 다시 지어야 하니 시간을 잃는다.

| 노리는 것 | 견제 | 도감 실카드 |
|---|---|---|
| **샘 술식**(눈에 보임) | 진을 깨거나 흐린다 | **「홈 흐리기」**T4(진 완성 지연) · **「진 헛깨우기」**T4(소진시킴) · 「진 파묻기」T4(한 턴 잠재움) · 「홈 얼리기」T4 · **「돌벽 쪼갬」**T6(설치물 전부 파괴) |
| **문자 베끼기**(원본 필요) | 원본을 부순다 | 「갑주 조각내기」류 파괴 · **「미리 끊어 두기」**T6(세 칸 이상 못 세움 — 복제 마법 봉쇄) |
| **다중영창**(입이 필요) | 입을 막는다 | **「말 끊기」**T4(칸 1·부은 칸 소멸) · 「턱 닫힘」T5(언령 봉쇄) · 「입 봉하기」T6 · **「손목 묶기」**T3(새김 봉쇄) · 「손 굳히기」T6(진·부적 봉쇄) |
| **조합 자체** | 합침을 끊는다 | 「말 끊기」로 합침 완성 끊기 · **「식힘 늦추기」**T6 |

**★세 방식의 약점이 다 달라서 견제도 갈린다:**
- 샘 빌드 → **카르(깨짐)**가 천적
- 베끼기 빌드 → **파괴·봉쇄**가 천적 (원본이 죽으면 곱이 0)
- 다중영창 빌드 → **루·코르(고요·닫힘)**가 천적 (입을 막으면 끝)

**→ 상대가 어느 가속을 쓰는지 읽고 그 천적을 꺼내는 것이 자원전의 수싸움이다.**

# 제3부 — 조합식 규격

## §4 조합의 세 규칙

1. **같은 것 N개 → 한 단 위.** 하위는 사라진다.
2. **N은 층마다 다르다** — 원소·획기→낱말/문양 **3:1** / 문양·회로→진 **5:1** / 정령 일반~스페셜 **3:1** / 유니크 위 **2:1 + 전리**.
3. **★상위는 전리를 함께 먹는다** — 스페셜 3 · 유니크 8 · 전설 20 · 에픽 50. 재료만으로는 못 오른다(견제를 강제하는 자리).

## §5 조합식 표기 (UI에 그대로 뜬다)

```
[레어] 자르나
  ← 자르미 ×3
     ← 자린 ×3 (각)
        ← 자르(살란) ×1 + 문양 ×1
           ← 불기 ×3        ← 획기 ×3
  총 밑재료: 불기 27 · 획기 27
```

**어느 칸에서든 「펼치기」로 끝까지 내려간다** — 랜디 조합 검색 사이트가 게임 안에 들어온 꼴.

# 제4부 — UI

## §6 화면 구성

```
┌─────────────────────────────────────────────┐
│  [판]  정령들이 선 자리 · 밀려오는 것        │
│                                             │
│                                             │
├─────────────────────────────────────────────┤
│ [손]  조합 가능한 것 / 지금 만들 수 있는 것  │
├─────────────────────────────────────────────┤
│ ◆근원 줄 (고정 카운터 · 늘 보임)             │
│ 불기 12  찬기 5  물기 8  땅기 3  울기 0      │
│ 엮기 2   빔기 7  │  ✎획기 24                │
└─────────────────────────────────────────────┘
```

**★근원 줄은 카드가 아니라 아래 고정 카운터**(8근원 설계 확정). 쌓여도 손패가 안 늘어난다. 획기는 **구분선 뒤에 따로** — 계열이 아니라 그릇이니까.

## §7 조합 UI — 세 가지 방식

| 방식 | 어떻게 |
|---|---|
| **끌어 합치기** | 같은 것 셋을 겹쳐 끌면 합쳐진다(랜디 기본) |
| **레시피 눌러 만들기** | 만들 것을 고르면 **모자란 재료가 붉게** 뜬다 |
| **★자동 합침 토글** | 셋이 모이면 자동으로 올림 — 켜면 편하고, 끄면 **하위를 남겨 두는 전략**(카르는 하위를 남겨야 세다·불은 표면 깔 자린을 남긴다) |

**★자동 합침 토글이 중요하다** — 로스터에 "합침을 서두르면 제 밥상을 제가 치운다"(카르)·"표면 깔 자린 하나는 남긴다"(불)가 이미 있다. 자동만 있으면 그 전략이 죽는다.

## §8 정령 카드 표기

```
┌────────────────────────┐
│ [유니크] 자르셀     ▣▣▣│ ← 갈래(익힌 기술) 칸
│ 불 · 진에 앉은 것        │
│ ─────────────────────  │
│ 칸 7 · T7 · 버팀 2500   │
│ 먹임 4/턴               │
│ ─────────────────────  │
│ 고유 ①표면 저절로 번짐   │
│      ②표면 위 칸 −1     │
└────────────────────────┘
```

**등급이 왼쪽 위에 색으로** (일반 회색 → 매직 파랑 → 레어 노랑 → 스페셜 초록 → 유니크 보라 → 전설 주황 → 에픽 빨강 → 이터니티 무지개). 랜디 관습 그대로 — **딱 보고 서열이 읽혀야 한다**(사용자 확정).

# 제5부 — UX

## §9 원칙 넷

1. **한눈에 서열** — 등급 색이 모든 것을 지배한다. 이름을 안 읽어도 세기가 보인다.
2. **모자란 것이 붉게** — 무엇이 부족해 못 만드는지 즉시 보인다(원소? 획기? 전리?).
3. **★예측선** — 지금 생산 속도면 **"대샘진까지 R32"**처럼 도달 예정이 뜬다. 빌드업 게임이라 **"얼마나 남았나"가 곧 재미**다.
4. **되돌리기 없음** — 합치면 하위는 사라진다. 다만 **합치기 전에 미리보기**로 결과를 보여 준다.

## §10 긴 판을 지루하지 않게

판이 길다(사용자 확정). 지루함을 막는 장치:

- **매 라운드 눈에 띄는 변화** — 근원 줄 숫자가 오르고, 진에 빛이 고이고, 정령의 꼴이 여문다.
- **등급 오름이 사건이다** — 유니크에서 **사람 꼴이 서는 순간** 연출을 크게(§12).
- **★밀려오는 것의 성격이 구간마다 바뀐다**(무리 성격 배합) — 같은 걸 반복 안 한다.
- **자원 견제가 오면 판이 흔들린다** — 쌓은 게 부서지고 다시 짓는 공방.

# 제6부 — 연출

## §11 재료·조합

| 순간 | 연출 |
|---|---|
| 원소 지급 | 근원 줄에 낱알이 **툭 떨어져 쌓인다**(계열 색) |
| 획기 지급 | 술사 손끝에서 **획 하나가 그어져** 카운터로 간다 |
| 조합(합침) | 셋이 **가운데로 빨려들며 빛이 뭉치고**, 한 단 위가 **솟는다** |
| 진 완성 | 홈을 따라 **빛이 한 바퀴 돌고** 자리가 밝아진다 |
| 실패(재료 부족) | 붉게 **한 번 떨림** — 소리 없이 |

## §12 ★등급 오름 — 여기가 이 게임의 뽕맛

| 등급 | 오를 때 |
|---|---|
| 매직·레어 | 짧게 빛나며 꼴이 또렷해진다 |
| 스페셜 | 화면이 잠깐 어두워지고 **정령만 밝다** |
| **유니크** | ★**시간이 멈추듯 느려지고, 흐릿하던 것이 사람 꼴로 선다.** 이름이 화면에 뜬다 |
| **전설** | 판 전체가 그 계열 색으로 물든다. 소리가 한 박자 사라졌다 돌아온다 |
| **에픽** | ★**컷인** — 대진이 판 밑에 그려지고, 정령이 그 위에 내려선다. 판의 모든 정령이 잠깐 그쪽을 본다 |
| **이터니티** | 발굴 순간에만 — **지금 것과 꼴이 다른 것**이 깨어난다. 문자가 읽히지 않는 채로 돈다 |

**유니크(사람 꼴)와 에픽(대진)이 두 정점** — 재료의 산을 쌓아 도달하는 자리라 연출을 아끼지 않는다.

## §13 가속·견제

| 순간 | 연출 |
|---|---|
| 샘 술식이 돈다 | 진 홈에 **빛이 고여 넘실**, 상위는 밖으로 흘러넘침 |
| 문자 베끼기 | 먹이 배어 **같은 글자가 옆에 스민다** |
| 다중영창 | 술사 목소리가 **둘·셋으로 갈려** 겹쳐 들린다 |
| **견제 적중** | ★쌓인 것이 **부서져 근원으로 흩어진다**(되돌아가지 않고 사라짐) — 아픈 게 눈에 보여야 한다 |
| 진이 흐려짐 | 홈의 빛이 **끊겨 깜빡이다 꺼진다** |
