# 자원 가속·견제 전량 (도감 전수) — 2026-07-24 · 루프 5회차

> **선행:** 자원가속 1차(3방식 사다리) · 새김 루트(샘 계열 실카드 확인) · 언령 등급 사다리
> **작업:** 세 방식의 카드를 **도감에서 전수**하고, 각각의 견제 짝을 매칭한다. 새 카드 창작 0.
> ★=여기서 확정 / **볼드 「」=도감 실카드**

## §0 ★4회차 정정 — T10은 0장이 아니었다

4회차에서 *"T10 카드가 0장"*이라 적었는데, **소리길(`· 소리 · T10`)만 센 결과**였다. 실제로는 **「내려앉는 겨울」T10**이 있다 — 칸 [턴마다 2 · 세 턴] · 세 턴간 판 전체가 얼음판.

> **정정:** T10은 **겹 계열(소리+다른 길)에 존재한다.** 순수 소리길에만 없는 것 — 게임 상한 T10이 **여러 길을 겹쳐야 닿는 자리**라는 뜻이라, 오히려 캐논 정합이다(§3-2 겹 얹기: *"겹은 두 길이 다 깊어야 한다"*).
> **→ 「T10 공백」은 열린 물음에서 내린다.** 대신 **T10 = 겹 발현 전용**으로 확정.

# 제1부 — 가속 ① 샘 계열 (진에 고이게)

## §1 도감 실카드 전수

| 카드 | 무엇 | 등급 자리 |
|---|---|---|
| **「샘 술식」** | *"새김 자리에서 마력을 스스로 길어 올려, 곁에 이은 진 하나를 사람 손 없이 깨운다"* · *"유파 소유, 깎는 손이 드묾"* | **스페셜** |
| **「물레 술식」** | *"사람 손 없이 방앗간을 돌린다 · 톱니 몇이 상해도 남은 갈래로 계속 돈다"* | 레어 |
| **「이음 술식」** | *"떨어져 새긴 두 진의 홈을 회로로 이어, 한 부름 칸으로 둘을 깬다"* | 레어(연결) |
| **「엮음 술식」** | *"여러 진꼴을 한 심에 엮어, 하나 깨어나면 나머지도 차례로"* | **유니크** |
| **「진 앞당겨 깨우기」**T3 | 칸 1 · 반 완성 제 진 조기 발동(값 절반) · 합 [**샘 술식과 이어져 있으면** 값 오름] | 매직 |
| **「먼 진 깨우기」**T5 | 칸 1 · 눈 안 닿는 제 설치 진 원격 발동 | 스페셜 |
| **「발동자의 두 마디」**T2 | 칸 1 · 곁의 큰 진을 두 마디로 발동 — **꼴지음을 진이 진다** | 매직 |

**★「진 앞당겨 깨우기」의 합 조건이 「샘 술식」을 명시한다** — 도감이 이미 두 카드를 물려 뒀다. 샘 빌드의 실전 콤보가 캐논에 있던 것.

## §2 샘 빌드가 굴러가는 꼴

```
R1~   「고인 홈」 깔기 (획기 3)          → 원소 +1/턴
R3~   「물레 술식」로 교체              → +3, 부숴도 안 멎음
R6~   「샘 술식」 세움                  → +5 · ★진 하나를 공짜로 돌림
R10~  「이음 술식」로 진 둘을 잇고       → 한 칸에 둘 발동
R14~  「엮음 술식」로 판 전체를 엮음     → 하나 깨면 연쇄
```

**★「샘 술식」이 자원과 자동화를 겹치는 것이 이 빌드의 핵심** — 원소를 낳으면서 동시에 깔아 둔 진을 공짜로 돌린다. 칸을 두 번 아끼는 셈.

## §3 견제 짝 (샘 빌드의 천적)

| 견제 카드 | 무엇 |
|---|---|
| **「홈 흐리기」**T4 · 칸 1 | 상대가 새기는 중인 **진 하나의 완성 지연** · 합 [두 칸 이상 새긴 진이면 값 오름] |
| **「홈 얼리기」**T4 · 칸 1 | 새기는 중인 진 지연 · 합 [언·젖은 자리면 오름] |
| **「진 파묻기」**T4 · 칸 1 | 상대 설치 진 하나를 **덮어 한 턴 잠재움** |
| **「진 헛깨우기」**T4 · 칸 1 | 상대 방아쇠 진을 **헛발동시켜 소진** · 합 [그 자리 두 진 이상이면 오름] |
| **「돌벽 쪼갬」**T6 · 칸 3 | 앞 자리 **방벽·설치 구조물 전부 파괴** |
| **「미리 터뜨리기」**T5 · 칸 2 | 앞 자리 설치 진 전부 강제 발동 — **피아 없이 맞음** |
| **「발밑 깔개」**T5 · 칸 2 | 발밑 솟음·설치 진 발동 무효 — **제 진 포함** |

**★칸 1짜리가 넷이다** — 샘 빌드를 때리는 비용이 아주 싸다. 대신 **「물레 술식」류는 갈래가 여럿이라 일부가 상해도 돈다** — 그것이 샘 빌드의 방비.
**수비 카드:** **「홈 메우기」**T3(칸 1 · *상대가 이번 턴 흐린 진이면 그 방해 무효*) — 카르↔니르가 칸 1에서 맞서는 자리.

# 제2부 — 가속 ② 문자 베끼기

## §4 도감 실카드 전수

| 카드 | 무엇 |
|---|---|
| **「진 자국 탁본지」**(도구) | *"남이 판 진의 홈에 대고 문지르면 그 결이 뜬다"* — 베끼기의 원형 |
| **「새긴 손 짚기」**T6 · 칸 2 | 상대 진에서 **그 진을 새긴 자의 방향·인연을 얻음** |
| **「실로 진 옮기기」**T6 · 칸 2 | 멀리 있는 제 진을 한 걸음 옆으로 (그 턴 발동 불가) |
| **「진 밟고 서기」**T4 · 칸 1 | 이번 이동 경로에 **잔 방아쇠 진 한 자리 남김** |
| **「살갗의 진」**T4 · 칸 1 | 맞붙은 상대에게 **새겨 둔 진 발동** |
| **「몸에 새긴 방아쇠」**T5 | 선걸기 · 잡히거나 근접타 받는 **순간 자동 발동** |

**★베끼기는 도감에 도구(탁본지)만 있고 마법은 얇다** — 사용자가 제시한 방식이라 **여기가 신설이 필요한 유일한 자리**다. 다만 원리는 캐논에 있다(§2-5 *고정된 것만이 길든다* → 문자는 베껴지고 소리는 못 베낀다).

## §5 견제 짝

| 견제 | 무엇 |
|---|---|
| **「미리 끊어 두기」**T6 · 칸 3 | 두 턴간 상대가 **세 칸 이상짜리 기술을 못 세움** — 복제 마법 봉쇄 · **자잘기엔 무효** |
| **「식힘 늦추기」**T6 · 칸 2 | 상대 직전 기술의 **식힘 두 배** — 복제 주기를 늦춤 |
| **「갑주 조각내기」**·파괴 계열 | **원본을 부수면 곱이 0** |

**★베끼기의 구조적 약점:** 원본이 있어야 곱이 선다. **초반엔 값 0이고, 원본을 잃으면 통째로 0.** 곱셈이라 상한이 높은 대신 밑이 물러지면 전부 무너진다.

# 제3부 — 가속 ③ 다중영창 (칸을 늘림)

## §6 도감 실카드 전수 — 이 방식은 카드가 가장 많다

### 칸을 직접 늘리는 것

| 카드 | 값 |
|---|---|
| **「되받아 잇기」**T3 | **칸 0** · 같은 계열 연속 시 **칸 +1** · 합 [세 장 연속 → 뽑기 1] |
| **「숨 돌리는 마디」**T2 | **칸 0** · 칸 +1 · 합 [이번 턴 -타 두 장 이상 → **칸 +3**] |
| **「이어 외기」**T5 · 칸 1 | 직전과 같은 계열 하나를 **칸 0**으로 · 계열 다르면 **불발** |
| **「겹쳐 외기」**T3 · 칸 1 | 이번 칸에 **자잘기 둘** · 합 [같은 계열이면 셋] |
| **「거둬 담기」**T4 · 칸 1 | 제 표면 하나 거둬 **칸 1 환급** |
| **「미리 골라 두기」**T3 · 칸 1 | 기술 하나 지정 → 다음 턴 그 **칸 −1**(최소 1) |
| **「미리 왼 문장」**T3 | 이번 턴 **칸 절반 선불** → 다음 턴 벽두 자동 발동 |

### 손패를 늘리는 것

| 카드 | 값 |
|---|---|
| **「말 고르기」**T1 · 칸 1 | 뽑기 1 · 합 [직전 같은 계열 -타 → **뽑기 3 + 칸 1 환급**] |
| **「골라 뽑기」**T2 · 칸 1 | **가려잡기 1**(계열·길 지정) |
| **「불씨 뿌리기」**T2 | 합 [마른·돌먼지 표면 → 60 + **뽑기 1**] |

### 대주문을 지키는 것

| 카드 | 값 |
|---|---|
| **「나눠 외기」**T4 · 칸 1(얹기) | 채널 대주문을 칸 단위로 쪼갬 — 끊겨도 **부은 칸 절반 보존** |
| **「겹창 나눠 쥐기」**T4 · 칸 1 | 곁의 아군과 대주문을 **나눠 붓기**(각자 절반) |
| **「고른 숨」**T2 | **칸 0 패시브** · 세 칸 이상 기술이 끊겨도 **절반 남음** |
| **「선 방패」**T3 · 칸 1 | 채널 중 한 방 막기 · 합 [**나눠 외기와 함께면 부은 칸 전량 보존**] |

**★칸 0 카드가 셋**(되받아 잇기·숨 돌리는 마디·고른 숨) — 공짜로 칸을 늘리는 자리라 **다중영창 빌드의 뼈대**다.

## §7 견제 짝

| 견제 | 무엇 |
|---|---|
| **「말 끊기」**T4 · **칸 1** | 완성 임박 영창 끊기 — **부은 칸 무효** · 합 [세 칸 이상 부었으면 오름] · ★**최저가** |
| **「고요 벽」**T6 · 칸 4 | 자리 안 **언령 완성 칸 +1**(**피아 공통**) |
| **「턱 닫힘」**T5 · 칸 3 | 한 턴 **언령 봉쇄**(진·매개·몸길엔 무효) |
| **「입 봉하기」**T6 · 칸 3 | 한 턴 언령 봉쇄 |
| **「손목 묶기」**T3 · 칸 1 | 손을 묶어 **진 새김·매개 매듭 봉쇄** |
| **「손 굳히기」**T6 · 칸 3 | 한 턴 **진 새김·부적 봉쇄**(언령엔 무효) |
| **「숨 뺏는 바람」**T5 · 칸 2 | 완성 중이던 언령 무효 · **그 칸 소멸** |
| **「짓누름」**T5 / **「어깨 짓누르기」**T4 | **상대 기술 칸 +1** — 칸 경제를 직접 때림 |

**★「짓누름」·「어깨 짓누르기」가 새로 값을 얻는다** — 지금까지 "느려지는 것"으로만 봤는데, **다중영창 빌드는 칸이 곧 자원**이라 칸 +1이 **자원 견제**가 된다.

# 제4부 — 총괄

## §8 세 방식 × 견제 대조표

| | ① 샘(진) | ② 베끼기(문자) | ③ 다중영창(언령) |
|---|---|---|---|
| **늘리는 것** | 원소·획기(덧셈) | 가진 것(곱셈) | 칸(처리량) |
| **초반** | 강함(바로 깔림) | **0**(원본 없음) | 중간 |
| **후반** | 선형 | **폭발** | 선형 |
| **카드 수** | 도감에 충분 | **얇음**(신설 필요) | **가장 많음** |
| **천적** | 카르(칸 1짜리 넷) | 파괴·봉쇄(원본) | 코르·루(입 막기) |
| **방비** | 갈래 여럿(물레) | — | 「고른 숨」·「선 방패」 |

## §9 ★자원 견제가 성립하는 구조

1. **생산은 못 끊는다** — 획기는 술사 손, 원소는 세상에서 온다.
2. **쌓인 것·장치를 부순다** — 술사가 다시 지어야 하니 **시간을 잃는다.**
3. **칸 1짜리 견제가 많다**(홈 흐리기·진 헛깨우기·말 끊기·손목 묶기) — **견제가 싸고 재건이 비싸다.** 이 비대칭이 자원전의 압박.
4. **그래서 방비 카드가 있다** — 「홈 메우기」(방해 무효)·「고른 숨」(끊겨도 절반)·갈래 여럿(물레). **가속 빌드는 방비까지 세워야 완성된다.**

## §10 구멍 · 다음
- **★베끼기 방식만 도감이 얇다** — 도구(탁본지) 하나뿐. 사용자 제시 방식이라 **신설이 필요한 유일한 자리.** 다만 원리는 캐논(§2-5)에 있어 근거는 있다.
- **칸 1 견제가 너무 많을 수 있다** — 넷이 전부 칸 1이면 가속 빌드가 못 선다. 시뮬로 확인(방비 카드가 완충).
- **T10 = 겹 발현 전용**으로 확정됐으니, 로스터의 에픽 「쓰는 기술 T9」와 대조 필요(에픽이 겹을 쓸 수 있나).
