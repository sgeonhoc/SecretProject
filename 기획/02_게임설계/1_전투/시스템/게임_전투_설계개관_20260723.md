# 전투 설계 개관 — 검수용 한눈에 (2026-07-23)

> **사용자 상설 지시(2026-07-18):** *"주기적으로 웹페이지 업데이트해. 너가 또 글만 싸지르는 게 아닌지 검수하게."*
> 이 파일은 2026-07-23 하루의 전투 설계(산출물 22개)를 **한 장으로 검수**하기 위한 지도다. 각 항목은 무엇을 정했고 어느 파일에 있는지만 적는다.

---

## §1 무엇을 만들었나 — 한 줄

**랜덤디펜스식 조합 경제를 우리 턴제 전투에 얹었다.** 정령을 뽑아 합쳐 올리고, 그 정령이 도감 1,031장의 기술로 싸운다. PvE로 뼈대를 세우고 PvP로 깎았다.

## §4 정령 = 또 하나의 술사 (핵심 전환)

- **「돎」 수치를 폐기하고** 정령이 **도감 1,031장의 실제 카드**로 싸운다.
- 정령 스탯 = 턴당 **칸** · 쓰는 기술 **T**(제 등급 −1단) · **익힌 기술 수**.
- **일반 등급은 「한 마디」로 싸운다**(T1 카드가 도감에 없으므로 — 캐논 §2-1).
- **에픽 열여섯이 여섯 갈래로 갈린다** — 곱하기5·지우기4·넓히기1·건너뛰기1·안지기1·모양바꾸기4. **곱하기가 다섯뿐**이라 사다리 꼭대기가 "제일 센 것"이 아니라 "판을 다르게 만드는 것".

## §5 두 빌드 축 (사용자 분류 ②③)

- **합침**(세로) = 상위 소환. 개수 줄고 하나가 커짐.
- **갈래**(가로) = 소환체 강화 = 기술 하나 가르치기(칸2·+15%·라운드당 하나).

## §6 술자 빌드 다섯 갈래

| 빌드 | 무엇으로 이기나 | R20 여유 |
|---|---|---|
| 몸(연공) | 식힘 없는 카드 + 붙어 싸우기 | 0.83 |
| 자동화 술식 | 선불 칸을 방아쇠 칸 1로 회수 | 0.85~0.95 |
| 소환 | 합침 | 1.00 기준 |
| 대형 완성 | 뭉친 것에 자리 전체 | 뭉치면 1.1 |
| 난사 | 표면 위 합 조건 두 배 | 0.87 |

**★다섯이 전부 정령을 요구한다** — 순수 술자 빌드가 하나도 없다. "PvE 토대가 먼저"라던 순서가 수치로 확인됨.

## §7 PvP — 뼈대를 깎아서

- 밀려오는 무리 자리에 **상대 정령**, 지키는 것 자리에 **상대 술자**(버팀 2000).
- **동시 해결** 5단계(방해→설치→직격→잡힘 판정→정산).
- **전리 반반**(절반 자동 + 절반은 상대 정령 부순 만큼) = 심장. 빌드만 하면 전리가 안 모이고 견제만 하면 산출을 못 막음 → **"빌드하면서 견제도"가 자원 구조에서 나옴.**
- 한 판 12~16라운드.

## §8 ★검수 체크 — "글만 싸지른 게 아닌가"

이 하루 작업이 필러가 아님을 스스로 검증한 표. **정정 10건이 그 증거다** — 시뮬이 내 수치를 열 번 뒤집었고, 매번 시뮬을 따랐다.

| 검증 | 결과 |
|---|---|
| 새 기술·수치를 창작했나 | **0** — 전부 도감 1,031장 실측 인용 |
| 시뮬로 잡은 오류 | **10건** — 계단 곡선·합침 조건·갈래 +15%·에픽 익힘 16·술자 버팀·관통 규칙 등 |
| 사용자가 처음 판 것이 제자리를 찾았나 | 여섯 전부(쌓아 조합·살란=지식·상대도 큼·초반 견제·심리전·정해진 것 없음) |
| 4금기(역설계/단일/억지톤/추상어) | 22회차 전부 자가검열 통과 |
| 로스터 구멍이 값을 갖나 | 무리 성격 배합으로 여덟 구멍 전부 특정 구간에서 값 |

## §9 사용자 확정 대기 / 열린 것

- **정령 이름·등급 이름** — 잠정(살란 고유명·게임식). 사용자: "세계관 완성되면 나중에".

# ★2026-07-24 증보 — 재료 체계와 판 길이

## §10 두 루트 — 재료의 밑바닥

| | **소리 루트** | **새김 루트** |
|---|---|---|

| 조합1 | **살란(낱말)** = 원소 ×3 | **문양·회로** = 획기 ×3 |
| 조합2 | **언령**(마법) | **진** = 문양·회로 ×5 |

**★근원 자체엔 힘이 없다** — 재료일 뿐이고, 힘은 조합된 살란·진에서 나온다.

## §11 세 발현 — 재료로 갈린다

| 발현 | 재료 | 게임 자리 |
|---|---|---|
| **언령** | 순수 살란 | 직격·난사 — 가장 안 막히되 방해에 가장 약함 |
| **진·회로** | 순수 획 | 설치·자동화·자원 가속 |
| **살란문자** | 살란 + 획 | **정령** · 문자 베끼기 · 글 진 |

**★정령 = 살란문자의 살아 있는 꼴.** 심(살란)을 그릇(진)에 앉힌 것 — 돌에 새긴 글 진이 죽은 문자라면 정령은 산 문자다. **그릇의 등급이 곧 정령의 꼴**이라, 유니크에서 진이 되면 사람 꼴이 선다.
