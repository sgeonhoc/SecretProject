# 전투 UI·UX·유저플로우 — 카드게임 연출 문법으로 (2026-07-24)

> **사용자 지시:** *"가장 중요한 건 **UI UX 유저플로우**야 전투 때. 카드게임들 연출 어떤 건지 알지?"*
> **참고 문법:** 하스스톤(카드가 물리적으로 움직임·타격감) · MTG 아레나(스택 시각화·대상 지정 화살표) · 룬테라(주고받는 리듬) · 슬더스(정보 명확성·의도 표시).
> **★우리만의 문제:** 카드게임은 **내면 바로 효과**인데 우리는 **둘 다 숨겼다가 한꺼번에 해결**한다. 그 5켜를 읽히게 만드는 것이 이 문서의 절반이다.

---

# 제1부 — 카드게임에서 가져오는 것

## §1 그대로 쓰는 문법

| 문법 | 어디서 | 우리 적용 |
|---|---|---|
| **카드가 물리적으로 움직인다** | 하스스톤 | 손패 → 판으로 끌면 카드가 날아가 정령이 됨 |
| **대상 지정 화살표** | MTG 아레나 | 견제 카드를 쥐면 **상대 것으로 화살이 뻗음** |
| **쥐면 확대** | 전부 | 손패 카드 위에 커서 → 카드가 커지고 전문이 보임 |
| **자원이 눈에 찬다** | 하스스톤 마나 | **근원 줄의 낱알이 툭 떨어져 쌓임** |
| **타격감** | 하스스톤 | 값이 꽂힐 때 **화면 흔들림 + 숫자 팝** |
| **의도 표시** | 슬더스 | **상대가 붓는 중인 대주문**이 아이콘으로 미리 보임 |
| **죽음 연출** | 전부 | 정령이 풀릴 때 **근원으로 흩어짐**(우리 고유) |

## §2 ★우리만 다른 것 — 동시 해결

| | 카드게임 | **우리** |
|---|---|---|
| 언제 보나 | 카드 낼 때마다 즉시 | **턴 끝에 한꺼번에** |
| 누가 먼저 | 턴 플레이어 | **동시** |
| 연출 성격 | 주고받는 대화 | **★한 편의 장면** |

> **★그래서 해결 단계가 「극장」이 된다** — 둘이 무엇을 했는지 5켜로 펼쳐 보여준다. 프로즌 신랩스·블레이드러너식 동시 턴 연출.
> **이것은 약점이 아니라 우리만의 맛이다** — 내가 견제를 걸었는데 상대도 마침 그걸 피했다면, 그 순간이 한 장면으로 터진다.

# 제2부 — 한 턴 유저 플로우 (클릭 단위)

## §3 전체 흐름

```
[턴 시작]
  ↓ ①지급 연출 (2초)
  ↓ ②뽑기 연출 (1초)
[계획 단계] ← 여기서 플레이어가 조작 (제한 없음 or 60초)
  ↓ [확정] 버튼
[대기] "상대가 정하는 중…" (AI는 0.5초, 멀티는 실제 대기)
  ↓
[해결 극장] 5켜 재생 (8~15초)
  ↓ ⑥정리 연출 (1초)
[턴 끝]
```

## §4 ①지급 — 2초

```
근원 줄이 아래에서 빛나고,
낱알이 하나씩 「툭, 툭」 떨어져 쌓인다.
  불기 47 → 48 → 49  (숫자가 튀어오르며 증가)
획기는 술사 손끝에서 획이 그어져 카운터로 날아간다.
샘 술식이 있으면 → 진에 고인 빛이 넘쳐 근원 줄로 흐른다.
```

**★계열마다 색이 다르다** — 불기는 주황, 찬기는 하늘색, 획기는 먹빛. **안 보고도 뭐가 들어왔는지 안다.**

## §5 ②뽑기 — 1초

덱에서 카드가 **손패로 미끄러져** 들어온다. 새 카드는 **잠깐 테두리가 빛난다.**

## §6 ★③계획 — 이 게임의 본체

### 화면 상태
- **칸 줄이 커진다**(맨 아래) — 지금부터 여기가 주인공
- 쓸 수 있는 것들이 **또렷해지고**, 못 쓰는 것은 **흐려진다**

### 조작 흐름

| 하고 싶은 것 | 클릭 |
|---|---|
| **조합** | 근원 줄에서 끌어올림 → 조합대 열림 → 만들 것 클릭 |
| **합침** | 판에서 같은 것 셋을 **겹쳐 끌기** |
| **갈래** | 정령 카드의 **빈 갈래 칸** 클릭 → 기술 목록 → 고름 |
| **발현** | 손패 카드를 **판으로 끌기** |
| **견제** | 손패 카드를 쥐면 **상대 것으로 화살** → 놓음 |
| **취소** | 배치한 것을 **다시 끌어내면** 칸이 돌아옴 |

### ★실시간 되먹임 (매 조작마다)

```
칸 ▣▣▣▣▣▢▢▢  5/8 씀
   조합2 갈래2 발현1 ← 무엇에 썼는지 색으로 구분
```

- 카드를 **쥐는 순간** → 합이 서는 대상이 **판에서 빛난다**(불살을 쥐면 마른 표면 위 적이 주황으로)
- 조합 재료가 **모자라면** 그 항목이 **붉게 떨림**
- **위험 표시** — 상대 다음 수에 잡힐 내 정령이 **빨갛게 깜빡임**

### [확정] 버튼
누르면 **되돌릴 수 없다.** 누르기 전에 **칸이 남아 있으면 경고**("칸 3 남음 — 정말 확정?").

## §7 ★⑤해결 극장 — 8~15초

**이 게임에서 가장 중요한 연출.** 둘이 무엇을 했는지 한 장면으로 펼친다.

### 켜마다 화면이 바뀐다

```
━━━━━━━━━━━━━━━━━━━━━━━━━━
【1켜 · 방해】          ← 배너가 위에서 내려옴
━━━━━━━━━━━━━━━━━━━━━━━━━━
  화면이 살짝 어두워지고, 방해 카드만 밝다.

  · 상대의 「말 끊기」가 내 대주문으로 화살을 뻗는다
  · 내 영창이 흔들리며 「부은 칸 8 소멸」이 크게 뜬다
  · (내가 「선 방패」를 냈다면) → 화살이 튕기며 "보존!"

  ★여기가 가장 극적이다 — 서로의 수가 처음 드러나는 켜
```

```
━━━━━━━━━━━━━━━━━━━━━━━━━━
【2켜 · 설치】
━━━━━━━━━━━━━━━━━━━━━━━━━━
  · 조합한 것들이 판에 「솟아오른다」
      셋이 가운데로 빨려들며 빛이 뭉치고 → 한 단 위가 선다
  · 진이 깔리며 홈을 따라 빛이 한 바퀴 돈다
  · 표면이 바닥에 번진다(불·젖음·서리 색으로)
  ★등급이 올랐으면 여기서 연출을 크게(§9)
```

```
━━━━━━━━━━━━━━━━━━━━━━━━━━
【3켜 · 발현】
━━━━━━━━━━━━━━━━━━━━━━━━━━
  · 양쪽 정령이 「동시에」 기술을 쏜다
      — 화면 가운데에서 두 발현이 교차한다
  · 합 조건이 섰으면 값 옆에 「合」이 뜨고 숫자가 커진다
      60 → 「合」 125  (금색으로)
  · 「빠른 손」이 있으면 그쪽이 반 박자 먼저 — 상대 것이 헛방
```

```
━━━━━━━━━━━━━━━━━━━━━━━━━━
【4켜 · 판정】
━━━━━━━━━━━━━━━━━━━━━━━━━━
  · 버팀 0 이하가 「한꺼번에」 지워진다
  · 정령이 풀리며 → 근원으로 흩어져 바닥에 떨어진다
  · ★서로 잡았으면 둘이 동시에 흩어진다 (이 순간 화면이 멎음 0.5초)
```

```
━━━━━━━━━━━━━━━━━━━━━━━━━━
【5켜 · 정산】
━━━━━━━━━━━━━━━━━━━━━━━━━━
  · 전리가 판에서 떠올라 내 카운터로 날아온다
  · 수확 빌드면 근원도 함께
  · 술사 버팀 게이지가 줄어든다(빨간 잔상 남기며)
```

### ★재생 속도 조절
- **기본 1배** · **2배** · **건너뛰기**(결과만)
- **★중요한 순간은 건너뛰기에서도 보여준다** — 등급 오름·술사 피격·정령 죽음
- 판이 길어지면(R30+) 플레이어가 2배로 두고 본다 — **그래서 1배 연출은 "처음 볼 때 좋게"**

## §8 ⑥정리 — 1초

식힘 아이콘이 하나씩 줄고, 유지 못 한 것이 **흐려지며 풀린다.** 표면이 옅어진다.

# 제3부 — 큰 순간의 연출

## §9 ★등급 오름 (이 게임의 뽕맛)

| 등급 | 연출 | 길이 |
|---|---|---|
| 매직·레어 | 짧게 빛나며 꼴이 또렷해짐 | 0.5초 |
| 스페셜 | 화면이 어두워지고 **정령만 밝다** | 1.5초 |
| **유니크** | ★**시간이 느려진다.** 흐릿하던 것이 **사람 꼴로 선다.** 이름이 화면 가운데 뜸 | **3초** |
| **전설** | 판 전체가 그 계열 색으로 물들고, **소리가 한 박자 사라졌다 돌아옴** | 3.5초 |
| **에픽** | ★**컷인** — 대진이 판 밑에 그려지고 정령이 내려선다. **판의 모든 정령이 잠깐 그쪽을 본다** | **5초** |
| **이터니티** | 두 길이 겹치며 **양쪽 색이 섞인다.** 화면 전체가 한 번 하얘졌다 돌아옴 | 6초 |

**★유니크(사람 꼴)와 에픽(대진)이 두 정점** — 재료의 산을 쌓아 도달하는 자리라 아끼지 않는다.

## §10 대주문 (여러 턴 붓기)

```
붓는 중:  정령·술사 위에 「고리」가 하나씩 채워진다  ○○○ → ●○○ → ●●○
          그동안 그 대상이 살짝 빛나며 떨린다(무방비 표시)
          ★상대 화면에도 보인다 (경고 아이콘)
완성:     고리가 다 차며 → 화면이 한 번 밝아지고 → 대주문이 터진다
끊김:     고리가 「쨍」 하고 깨지며 → 부은 칸이 연기로 흩어진다
          ★가장 아픈 연출 — 8칸이 날아가는 게 눈에 보여야 한다
```

## §11 견제 적중

```
· 화살이 상대 것에 꽂힌다
· 진이면 → 홈의 빛이 「끊겨 깜빡이다」 꺼진다
· 쌓인 재료면 → 부서져 근원으로 흩어진다 (되돌아가지 않고 사라짐)
· ★"아픈 게 눈에 보여야" — 상대가 잃은 양이 숫자로 크게 뜬다
```

## §12 술사 피격

```
· 화면 가장자리가 붉게 번쩍
· 술사 초상이 흔들림
· 버팀 게이지가 「빨간 잔상」을 남기며 줄어듦
· ★버팀 30% 아래 → 화면 테두리가 계속 붉게 맥동 (위기 표시)
```

# 제5부 — 구멍과 판단

## §16 걸리는 것

1. **★계획 단계가 길다** — 칸 12개를 나누는 데 40초+. **자동 추천**(지난 턴과 같게·기본 배분)을 둬야 할지.
2. **해결 극장이 매 턴 10초면 판당 20분** — 2배·건너뛰기로 줄지만, **처음 몇 판은 다 볼 것**이라 그때 지루하면 안 된다.
3. **조합대 별창이 흐름을 끊는다** — 판 화면에 **간이 조합 줄**(자주 쓰는 것 3~4개)을 두는 안.
4. **동시 해결이 처음엔 헷갈릴 수 있다** — 첫 몇 판은 **켜마다 잠깐 멈추고 설명**하는 튜토리얼 모드.

## §17 다음
- **AI 칸 배분 알고리즘**(사용자 지시 — 이 문서 다음)
- 간이 조합 줄 여부
- 계획 자동 추천

## ▷정리
**카드게임 문법을 쓰되, 동시 해결이라는 우리 고유 구조를 「해결 극장」으로 살렸다.** 카드게임이 주고받는 대화라면 우리는 **한 편의 장면**이다 — 그것이 약점이 아니라 맛이 되게 5켜를 배너·명암·속도로 갈랐다.
