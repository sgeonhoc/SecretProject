# ★시스템 프레임 정정 — PvP 랜디 · 스토리 중심 (2026-07-24)

> **사용자 정정 원문:** *"너가 잘못 알고 있는 게, 우리는 **PVP 랜디**야. 그리고 **스토리 중심**이고. 그래서 캐릭터는 플레이어 캐릭터, **상대는 AI**야. 물론 그건 스토리 진행 중일 때고, 먼 훗날 멀티 기능을 넣고 PVP를 다른 사람들과 하게 된다면 **모든 기능이 해금된 채** 싸우게 되겠지. 그래서 실제로 게임 흐름은 **기술 습득해 가며 AI들과 빌드형 턴제전투 전개를 반복**하는 거야."*
>
> **내가 틀린 것:** PvE 타워디펜스(밀려오는 무리·지키는 것 20·R100 생존)를 완성형으로 굳혔다. **그건 뼈대를 세우려고 만든 발판**이었지 게임이 아니다(사용자는 *"뼈대가 없으면 깎을 수도 없다"*고 했다 — 깎을 차례였는데 발판을 게임으로 착각).

---

## §1 진짜 게임 흐름

```
[스토리 장면]
     ↓
[AI 술사와 전투]  ← 빌드형 턴제 · PvP 구조
     ↓
[기술·재료 습득]   ← 영구 진행
     ↓
[다음 스토리]
     ⋮  반복
     ↓
[먼 훗날] 멀티 PvP — 모든 기능 해금된 채 사람 대 사람
```

**★한 줄:** 기술을 습득해 가며 AI들과 빌드형 턴제전투를 반복한다.

## §2 ★무엇이 바뀌나 (정정 대조표)

| 내가 만든 것(PvE 발판) | **→ 진짜** |
|---|---|
| 밀려오는 무리(웨이브) | **AI 술사의 정령·기술** |
| 지키는 것 20 | **내 술자 버팀** |
| R100 생존 | **상대 술자를 잡음** |
| 무리 성격 여섯(나는 것·두른 것…) | **★AI 상대의 빌드 성향**(§4) |
| 라운드 곡선 ×1.12 | **AI도 나와 같은 사다리를 오름**(난이도로 조절) |
| "판 끝나면 지식만 남는다" | **★스토리로 기술을 영구 습득** |
| PvE 토대 → PvP 파생 | **PvP가 본체 · PvE 발판은 역할 끝** |

## §3 ★살아남는 것 (헛수고 아님)

프레임만 바뀌고 **부품은 거의 다 유효하다:**

| 부품 | 유효한가 |
|---|---|
| 재료 체계(근원→살란/문양→언령/진/문자) | ✓ **그대로** |
| 등급 사다리 8단(일반~이터니티) | ✓ 그대로 |
| 정령 로스터 112 | ✓ 그대로 |
| 자원 습득 8갈래 | ✓ 그대로 |
| 칸·턴·**동시 해결 5켜** | ✓ **PvP 구조라 오히려 본령** |
| 술자 빌드 5갈래 | ✓ 그대로 |
| 견제 체계 전량 | ✓ **더 중요해짐** — 상대가 술사라 견제가 전부 살아남 |
| 전리 반반(절반 자동 + 절반은 상대 것 부순 만큼) | ✓ **PvP의 심장** — 원래 이 자리였다 |
| 로스터의 "PvP에서 값이 뛰는 것들"(되받기·매개길·완성 끊기·루의 피아 공통) | ✓ **전부 본편에서 삼** |

> **★PvE에서 애매했던 것들이 전부 제자리를 찾는다** — 되받기(-노)는 무리가 -사를 안 써서 무용이었는데 **상대 정령은 전부 -사로 돈다.** 매개길은 무리에 매개물이 없어 못 썼는데 **상대 술사에겐 있다.** 완성 끊기는 「외는 것」 라운드에만 값이었는데 **상대가 늘 붓는다.**

---

## §4 ★무리 성격 여섯 → AI 빌드 성향

PvE의 여섯 성격은 버릴 것이 아니라 **AI 상대의 빌드 정체성**으로 옮긴다.

| 옛 성격 | **→ AI 상대 빌드** | 무엇으로 오나 |
|---|---|---|
| 두른 것 | **막이 빌드** | 두르(벽)·켈셀(돌지킴)로 굳히고 버팀 |
| 빠른 것 | **속공 빌드** | 초반 러쉬 · 자원 안 쌓고 바로 때림 |
| 나는 것 | **회피 빌드** | 무네(그늘)·발밑 무효 · 잡기 어려움 |
| 외는 것 | **대주문 빌드** | 큰 것을 붓는다 — 끊어야 함 |
| 덮인 것 | **설치 빌드** | 진·자동화로 판을 덮음 |
| 걷는 것 | **균형 빌드** | 무난 · 초반 상대 |

**★각 AI가 「어느 계열 + 어느 가속 갈래 + 어느 술자 빌드」인지로 정체가 선다** — 로스터·8갈래·빌드5가 그대로 AI 설계표가 된다.

**★그리고 이것이 스토리와 붙는다** — 다섯 손(세이르·셀란 등 현대 세력)마다 빌드 성향이 다르면, **누구와 싸우는지가 곧 무엇을 대비할지**가 된다.

---

## §5 ★기술 습득 = 스토리 진행 (영구)

PvE 판에서 "지식만 남는다"고 했는데, **스토리 게임이면 실제로 습득한다.**

| 얻는 것 | 어떻게 |
|---|---|
| **기술 카드** | 스토리로 · 이긴 상대에게서 · 발굴 |
| **조합식(레시피)** | 처음 만들면 도감에 등재 |
| **가속 장치** | 스토리 진행으로 해금 |
| **술사 성장** | T·칸 상한이 오름(스토리 단계) |

**★도감이 곧 진행도다** — 1,031장을 다 못 쓰고 시작해서, 스토리를 밀며 하나씩 는다. **덱 30장을 무엇으로 채우냐가 곧 그때까지 모은 것.**

> **★멀티는 "모든 기능 해금된 채"**(사용자 확정) — 스토리에서 모으는 과정이 싱글의 재미고, 멀티는 **다 가진 상태에서 빌드 실력만** 겨룬다.

## §6 ★한 판의 흐름 (정정판)

```
[스토리 장면] — 누구와 왜 싸우는가
     ↓
[전투 준비] 덱 짜기(지금까지 모은 것 중 30장) · 가속 갈래 고르기
     ↓  ※ 상대 빌드 성향이 스토리로 어느 정도 암시된다
[전투]
   라운드 = 3턴
   턴 = ①지급 ②뽑기 ③계획 ④동시공개 ⑤해결5켜 ⑥정리
   양쪽이 같은 사다리를 오르며 서로 견제
     ↓
[승패] 상대 술사 버팀 0 → 승 / 내 술사 0 → 패
     ↓
[보상] 기술·재료·조합식 습득 → 다음 스토리
```

**★판 길이:** 스토리 전투는 **20~50라운드**가 어림이다(PvE 100R은 발판 기준이었다). 초반 스토리는 짧고(등급 낮음) 후반으로 갈수록 길어진다 — **스토리 진행 = 판이 길어짐 = 더 높은 등급까지 감.**

## §7 ★난이도 = AI의 사다리 속도

AI도 나와 같은 규칙으로 오른다. 난이도는 **AI가 얼마나 빨리 오르나**로 조절한다.

| 난이도 | AI 성장 | 스토리 자리 |
|---|---|---|
| 쉬움 | 나보다 느림 | 초반 스토리 · 배우는 상대 |
| 보통 | 비슷 | 중반 |
| 어려움 | 나보다 빠름 | 보스 · 다섯 손의 수장 |

**★AI가 반칙을 안 한다** — 같은 재료·같은 사다리. 그래서 **AI의 판을 보면 배운다**(상대가 쓴 조합을 도감에 기록).

## §9 남은 물음 (사용자 확정 필요)
- **스토리 전투 횟수** — 몇 판을 싸우며 진행하나(도감 1,031장을 다 모으려면?).
- **패배하면** — 스토리가 막히나, 다시 도전하나, 우회하나.
- **덱 30장이 맞는지** — 초반엔 가진 카드가 30장도 안 될 텐데.
- **술사 종류** — 플레이어 캐릭터 하나인가, 여럿 중 고르나(스토리 중심이면 하나일 듯).
