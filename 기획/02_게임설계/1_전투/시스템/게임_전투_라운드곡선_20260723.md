## §1 먼저 — 정령의 실제 산출을 다시 쟀다

「돎」을 폐기하고 **실제 도감 카드**로 바꾼 뒤라 등급 격차가 달라졌다. 칸 × 그 T의 칸당 값으로 다시 계산한다.

| 등급 | 턴당 칸 | 쓰는 T | 그 T의 칸당 값 | **턴 산출** | 계단 |
|---|---|---|---|---|---|
| 일반 | 1 | 한 마디 | 20 | **20** | — |
| 매직 | 2 | T2 | 25 | **50** | 2.5× |
| 레어 | 3 | T4 | 40~70 | **150** | 3.0× |
| 스페셜 | 5 | T5 | 50~65 | **300** | 2.0× |
| 유니크 | 7 | T7 | 70~85 | **500** | 1.7× |
| 전설 | 9 | T8 | 100 | **900** | 1.8× |
| 에픽 | 12 | T9 | 150 | **1800** | 2.0× |

**실측 예시(자르 계열):** 자르나 = 「불띠」칸2·120 + 「불살」칸1·60 = **180** / 자르담 = 「불비」칸3·200 + 「불살」칸1·60 + 잔여 = **~290** / 자르셀 = 「불의 비」칸4·250 + 「불길 뿜기」칸3·120 = **370**(고유 칸−1 적용 시 더 큼) / 카르셀 = 「벗긴 자리 꽂기」500 + 잔여 = **~600**

> **★수정 사항:** 뼈대 제1부의 「3배 계단(12/36/110/330/1000/3000/9000)」은 **실측과 안 맞는다.** 실제 카드로는 **2.0~2.5배 계단**이다(20/50/150/300/500/900/1800). 고유 능력의 곱(에픽 2배 등)을 얹어야 3배에 가까워진다. **아래 곡선은 실측 쪽을 쓴다.**

**합침이 여전히 이득인가:** 레어 3 = 450/턴·먹임 6칸(칸당 75) vs 스페셜 1 = 300/턴·먹임 3칸(칸당 **100**). 유지비가 반이라 칸당 값에서 상위가 이긴다 — 격차가 줄어도 결론은 유지.

## §2 판의 뼈대

| 항목 | 값 |
|---|---|
| **1 라운드** | **3턴** — 라운드 벽두에 무리가 들어오고, 세 턴 안에 잡아야 한다 |
| **지키는 것** | 20 (한 마리가 끝까지 지나가면 1 깎임) |
| **술자 턴당 칸** | R1에 **6**, 라운드마다 **+0.5**(R10=10 · R20=15 · R30=20 · R40=25) |
| **뽑기** | R1~5 턴당 2 · R6~10 턴당 3 · R11~20 턴당 4 · R21~ 턴당 5 |
| **판 길이** | ~~40 라운드~~ → **★100 라운드(300턴)** |

> **★2026-07-24 정정:** 40R은 재료 사슬을 세우기 전에 잡은 값이다. 재료가 지수로 폭발하므로(에픽=근원 ~2,250) **에픽이 R75~80에 서고, 그것을 굴릴 시간까지 주면 100R**이 나온다. 판 길이를 정하고 재료를 맞춘 게 아니라 **재료가 판 길이를 정했다.** 역산은 `게임_전투_판길이_리듬_20260724.md`. 아래 §4 무리 곡선도 100R 기준으로 재조정(×1.18/1.09/1.07/1.06/1.05).

### ★술자 칸이 자라야 하는 까닭

먹임(일반0/매직1/레어2/스페셜3/유니크4/전설5/에픽6)이 고정 칸을 잡아먹는다. 술자 칸이 6에 묶이면 **스페셜 둘이면 이미 칸이 없어** 뽑기·합침·갈래를 못 한다. 칸이 안 자라면 사다리가 스페셜에서 멈춘다 — 곡선이 아니라 **구조가 막힌다.**

| 라운드 | 술자 칸 | 유지 가능한 편성(예) | 남는 칸(뽑기·합침·갈래) |
|---|---|---|---|
| R10 | 10 | 유니크1(4) + 스페셜1(3) | 3 |
| R20 | 15 | 전설1(5) + 유니크1(4) + 스페셜1(3) | 3 |
| R30 | 20 | 에픽1(6) + 전설1(5) + 유니크2(8) | 1 |
| R40 | 25 | 에픽2(12) + 전설2(10) | 3 |

**남는 칸이 늘 3 언저리**가 되도록 +0.5를 잡았다. 이 3칸이 뽑기·합침·갈래·지정을 다 감당하는 자리라, **정령을 하나 더 세우면 사다리가 멈춘다** — 유지와 성장의 저울이 여기서 선다.

## §3 합침 개수 정정 — 상위는 3이 아니라 2

3:1을 끝까지 밀면 에픽에 일반 **729개**가 든다. 턴당 5개를 뽑아도 40라운드(120턴)에 누적 495개라 **에픽이 아예 안 나온다.** 원랜디도 조합마다 개수가 다르다(3~6). 상위를 2로 낮춘다.

| 전설 | 유니크 **2** + 전리 20 | **108** |
| 에픽 | 전설 **2** + 전리 50 + 히든 | **216** |

## §4 라운드 곡선 — 밀려오는 것

**★등비가 아니라 계단이다(2026-07-23 종이 시뮬 정정).** 처음에 「라운드당 ×1.12 복리」로 적었으나 계산이 안 맞았다 — 150×1.12⁴=236인데 표는 700이었다. 표는 **정령 여유 배수에서 거꾸로 잡은 값**이라 맞고, 등비라는 요약이 틀렸다.
**정령 사다리가 계단으로 뛰므로**(매직→레어 3.0배 · 레어→스페셜 2.0배) **무리도 계단으로 따라가야 한다.** 구간 비율:

| 구간 | 비율 | 까닭 |
|---|---|---|
| R1→R5 | **×1.55** | 매직→레어→스페셜 계단을 따라간다 |
| R5→R10 | ×1.21 | 스페셜 다수 구간 |
| R10→R20 | ×1.13 | 유니크·전설 구간 |
| R20→R40 | ×1.12 | 에픽·곱 구간 |

| 라운드 | 무리 총 버팀 | 정령 산출(3턴) | 여유 | 이 라운드에 서 있어야 하는 것 |
|---|---|---|---|---|
| R1 | 150 | 매직2 = 300 | 2.0× | 매직 둘 |
| R2 | **300** | 레어1+매직1 = 600 | 2.0× | 레어 하나 |
| R3 | **450** | 레어2 = 900 | 2.0× | |
| R4 | **525** | 레어2+매직1 = 1050 | 2.0× | |
| R5 | **750** | 레어3+매직1 = **1500** | 2.0× | (합치지 않는 것이 낫다 — §3-1) |
| R8 | 1240 | 스페셜2 = 1950 | 1.6× | **스페셜 둘** |
| R10 | **1820** | 유니크1+레어2 = **2550** | 1.4× | **유니크 하나 — 없으면 1.32로 뚫린다** |
| R15 | 3350 | 전설1+유니크1 = 4200 | 1.25× | **전설 하나** |
| R20 | 5900 | 전설1+유니크1+스페셜1 = 5100 | **0.86×** | ★뚫림 — 갈래·고유 곱이 필요 |
| R25 | 10400 | 에픽1+전설1+유니크1 = 9600 | 0.92× | ★에픽 필요 |
| R30 | 18300 | 에픽1+전설1+유니크2 = 11100 | **0.61×** | ★고유 곱 없이는 못 막음 |
| R40 | 56800 | 에픽2+전설2 = 16200 | **0.29×** | ★곱 전면 필요 |

### ★결손 구간 — 이것이 설계 의도

> **2026-07-23 시뮬 정정:** 결손이 시작되는 지점을 처음에 **R20**으로 적었으나, 갈래(+15%·라운드당 하나)를 정확히 넣어 굴리니 **R35**다. R11~R30은 갈래로 여유 1.28~2.32를 유지하고, 갈래가 상한(에픽 16·전설 12)에 차는 R31 이후부터 무리만 오른다.
> **에픽이 R22에 서고 그 곱이 R35부터 필요해지는 편이 설계에 맞다** — 세우자마자 필수인 것보다 자연스럽다.
> **곱 하나(람온 1.5)면 R40에 여유 1.02로 딱 넘고, 없으면 0.68로 못 넘는다.**

밑값(칸×칸당값)만 세면 R20에서 뒤집힌다. 그 차이를 메우는 것이 **고유 능력의 곱**이다:

| 곱 | 배수 | 출처 |
|---|---|---|
| 자르온 | 불 정령 기술 **2배** | 에픽 곱하기 |
| 후르온 | 모인 자리 광역 **2배** | 에픽 곱하기 |
| 람온 | 모든 정령 기술 **1.5배** | 에픽 곱하기 |
| 옴온 | 무게·낙하 **2배** + 눌린 것 받는 값 **2배** | 에픽 곱하기 |
| 잔온 | 방어 무시 + 기절 **1.5배** | 에픽 곱하기 |
| 오르셀·오르한·오르온 | T +1 · 칸 +2 · 먹임 절반 | 넓히기 |
| 갈래 | 등급 기본의 **+50%**씩(최대 8~12) | 익힘 |

**R30에 에픽 곱 하나(2배) + 갈래 몇을 얹으면 11100 → 22000~25000**이 되어 18300을 넘는다. **R40에 곱 둘을 겹치면(예: 람온 1.5 × 옴온 2 = 3배) 16200 → 48600**, 갈래까지 얹어 56800에 닿는다.

> **그래서 곡선이 이렇게 생겼다** — 밑값만 쌓는 빌드는 R20에서 멈추고, **고유의 곱을 겹치는 빌드만 R40까지 간다.** 로스터 총평에서 나온 "에픽 열여섯 중 곱하기는 다섯뿐"이 여기서 값을 갖는다: 곱하기 에픽을 못 뽑은 판은 지우기·넓히기 에픽으로 **다른 방식으로** 버텨야 한다(§6).

## §5 무리를 둘로 나눈다 — 기본분과 증원분

코르간 고유(라운드 증원 절반)·코르온 고유(증원 없음)를 **총량에 그대로 걸면 코르 빌드만 곡선을 벗어난다.** 그래서 라운드 무리를 나눈다.

| 갈래 | 몫 | 성격 |
|---|---|---|
| **기본분** | 60% | 라운드 벽두에 들어온다. 아무도 못 막는다 |
| **증원분** | 40% | 라운드 도중 뒤에서 들어온다. **코르·두르가 막을 수 있다** |

- **코르간**(증원 절반) → 그 라운드 무리 **20% 감소**
- **코르온**(증원 없음) → **40% 감소**
- **코르나·코르담**(한 턴 막기·길 하나 폐쇄) → 증원분의 일부를 늦춤
- **두르온**(벽을 못 넘어 길로만 옴) → 증원분이 한 줄로 서서 광역에 먹힌다

**40% 감소는 R40에서 56800 → 34000**이다. 크지만 판을 깨지 않는다 — 곱하기 빌드가 3배를 내는 것과 견주면 대등한 값이다.

## §6 니르 유무가 도달선을 가른다

에픽 하나 = 일반 **216개**다. 잃으면 그 판은 끝난다.

| | 니르 없음 | 니르담 있음 | 니르간 있음 |
|---|---|---|---|
| 죽은 정령 | 소멸 | **한 등급 아래로 부활** | **그 등급 그대로**(라운드당 하나) |
| 현실 도달선 | **전설까지** | 에픽 1 | 에픽 2 |
| 최대 라운드 | R25~28 | R35 | **R40** |

**니르 없이는 아무도 에픽을 시도하지 않는다.** 216개를 부어 만든 것이 한 라운드에 날아갈 수 있으면 그 도박을 안 한다 — 니르는 화력이 0인데도 **후반 빌드의 전제 조건**이 된다.

## §7 검산 — 곡선이 로스터를 설명하는가

| 로스터에서 나온 것 | 곡선에서 값을 갖는가 |
|---|---|
| 잡는 열 계열 / 안 잡는 여섯 | ✓ 밑값이 필요하므로 잡는 계열 최소 하나는 필수 |
| 에픽 곱하기 다섯 | ✓ R20 이후 곱 없이는 못 막음 |
| 에픽 지우기 넷(무네·루·카르·실란) | ✓ 곱이 없어도 **적 산출을 깎아** 같은 자리를 판다(무리 값이 안 들어오면 막을 필요가 없다) |
| 에픽 넓히기(오르온) | ✓ 먹임 절반 = 술자 칸 6칸 확보 = 정령 하나 더 |
| 에픽 건너뛰기(코르온) | ✓ §5에서 40% |
| 에픽 안 지기(니르온) | ✓ §6에서 도달선 자체 |
| 갈래(익힘) +50% | ✓ R20 결손의 주된 메움 수단 |
| 계열끼리 물리는 짝 7종 | ✓ 곱을 겹치는 유일한 길 |

**여섯 갈래 에픽이 곡선에서 전부 제 자리를 가진다** — 곱하기만 정답이 아니고, 지우기·넓히기·건너뛰기·안 지기가 각각 다른 방식으로 같은 결손을 메운다. 로스터를 다 채운 뒤 곡선을 짜서 확인된 정합.

## §8 열어 둔 것
- **1라운드 = 3턴**이 맞는 길이인지(2턴이면 빡빡, 4턴이면 늘어진다).
- **술자 칸 +0.5/라운드**의 기울기 — 남는 칸이 늘 3이 되도록 잡았으나 시뮬로 확인해야 한다.
- **무리의 성격**(버팀만 큰 것·나는 것·갑주·술 쓰는 것·빠른 것)을 라운드별로 어떻게 섞을지. 로스터의 구멍(켈온=나는 것에 무력, 카르=부술 것 없으면 밑값)이 이 배합으로 값을 갖는다.
- **히든 해금** 조건(에픽에 필요) — 무엇을 하면 열리는가.
