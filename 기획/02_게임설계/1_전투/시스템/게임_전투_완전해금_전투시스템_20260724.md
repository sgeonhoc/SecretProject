# 완전 해금 전투 — 시스템·UI·UX·시뮬 (2026-07-24)

> **사용자 지시:** *"너가 지금 만들어야 할 건 **서로 모든 기술을 가지고 있다고 가정했을 때** 전투가 일어나는 **UI, UX, 시뮬레이션, 시스템**이야."*
> **전제:** 양쪽 다 도감 1,031장·8갈래 가속·112 정령·8등급 전부 사용 가능. **덱 크기 제한 없음.** 실력과 판단만으로 갈린다.
> (덱 수집은 스토리의 재미 — 사용자 확정: *"몇 개 못 굴려도 돼. 수집할수록 덱빌딩이 강해지는 게 재미요소."* 이 문서는 그 도착점.)

# 제1부 — 시스템

## §1 판의 뼈대

| 항목 | 값 |
|---|---|
| **양쪽** | 술사 하나씩 · 버팀 **6,000**(+10%/라운드) |
| **승패** | 상대 술사 버팀 0 |
| **라운드** | 3턴 |
| **판 길이** | 결판날 때까지(어림 **40~70라운드**) |
| **술사 칸** | 시작 6 · 라운드마다 +0.5 |
| **지급** | 원소 **랜덤 3/턴** · 획기 **고정 3/턴** |

## §2 턴 여섯 단계

```
①지급 → ②뽑기 → ③계획 → ④동시공개 → ⑤해결 → ⑥정리
```

**③계획이 이 게임의 전부다** — 칸을 어디에 나누느냐. 다섯 갈래로 쓴다:

| 쓰임 | 무엇 |
|---|---|
| **조합** | 근원→살란/문양 · 합침(등급 올림) |
| **갈래** | 정령에게 기술 가르치기(칸 2·라운드당 하나) |
| **먹임** | 세운 정령 유지(등급별 고정) |
| **발현** | 내 기술을 쏨(직격·설치·대주문) |
| **견제** | 상대 것을 끊고 부숨 |

## §3 ⑤해결 다섯 켜

| 켜 | 무엇 | 규칙 |
|---|---|---|
| **1 방해** | 완성 끊기·봉쇄·되받기(-노) | 끊긴 것은 다음 켜에서 **아예 안 나감** |
| **2 설치·유지** | 진 발동·표면·벽·묶음·먹임·**조합/갈래** | 3켜의 합 조건을 여기서 정함 · **합친 정령은 그 턴부터 싸움** |
| **3 발현** | 정령·술사 기술 | 1에서 안 끊긴 것 · 2가 깐 표면 위에서 |
| **4 판정** | 버팀 0 이하 **한꺼번에** 제거 | **서로 잡으면 둘 다 죽음** |
| **5 정산** | 전리·수확·근원 회수 | |

**동시 우선권:** 같은 대상을 동시에 노리면 **「빠른 손」**(칸 0 패시브)을 든 쪽이 먼저 — 상대 것은 헛방.

## §4 무엇이 보이나 / 안 보이나

| 보인다 | 안 보인다 |
|---|---|
| 상대 정령(등급·계열·꼴·버팀) | **이번 턴 칸 배분**(동시 공개까지) |
| 상대가 **붓는 중인 대주문**(캐논 §4-3 무방비) | 상대의 **깔아 둔 진·선걸기·갈래** |
| 판의 표면(불·젖음·서리·그늘) | 상대 손패 |
| 상대 근원 **총량**(대략) | 상대 근원 **계열별 내역** |

**★이 경계가 심리전을 만든다** — 상대가 자원을 쌓는지 때릴 준비를 하는지 **칸 배분을 못 보니 모른다.**

## §5 술사에게 값이 닿는 길

- 직격이 술사에게 가면 **값 절반**
- **「앞을 가리는」 고유 정령**(돌지킴·두르·그늘담)이 있으면 그것부터 지워야 함
- **막이 통과 넷**(후르 안 보임 · 실란 꿰뚫음 · 카르 부숨 · 오르 열어 무력화)은 한 겹을 지남
- **매개길**은 정령을 통째로 우회 · 직행(값 얇음)

## §6 전리 — 반반

> **기본 수급(라운드÷8)의 절반만 자동 + 나머지 절반은 상대 정령을 부순 만큼.**

**★빌드만 하면 전리가 안 모여 상위 불가. 견제만 하면 정령이 없어 산출을 못 막음.**

│                     [ 상 대 판 ]                            │
│   ◆시스셀(유니크)   ◆두르담(스페셜)   ▣샘술식  ▣겹벽       │

### 화면 원칙 넷
1. **칸 줄이 맨 아래·항상** — 모든 판단이 여기라서.
2. **근원 줄이 그 위** — 카드가 아니라 카운터(8근원 설계 확정). 쌓여도 손패가 안 늚.
3. **상대의 「붓는 중」이 맨 위에 경고로** — 끊을지 말지가 그 턴 최대 판단.
4. **판이 위아래 대칭** — 상대 위·나 아래. 가운데가 표면.

## §8 조합대 (별창)

「조합」 칸을 누르면 열린다.

```
┌─────────────── 조 합 대 ───────────────┐
│  [만들 것 고르기]                       │
│                                        │
│  ▸ 자르(살란)      불기3      ✓ 만들 수 있음│
│  ▸ 문양            획기3      ✓         │
│  ▸ 자린(일반정령)  자르1+문양1 ✓         │
│  ▸ 자르미(매직)    자린3      2/3  ✗    │ ← 붉게
│  ▸ 겹샘술식(유니크) 샘술식2+전리8 ✗전리부족│
│                                        │
│  ┌─ 펼치기: 자르미 ─────────────────┐   │
│  │ 자르미 ← 자린 ×3                 │   │
│  │   자린 ← 자르 ×1 + 문양 ×1        │   │
│  │     자르 ← 불기 ×3               │   │
│  │     문양 ← 획기 ×3               │   │
│  │   총 밑재료: 불기 9 · 획기 9      │   │
│  └─────────────────────────────────┘   │
│                                        │
│  [자동 합침]  ◉끄기  ○켜기              │
└────────────────────────────────────────┘
```

**★「펼치기」가 랜디의 조합 검색을 게임 안으로 들인 것** — 어느 칸에서든 끝까지 내려간다.
**★「자동 합침」 토글** — 켜면 편하고, 끄면 **하위를 남기는 전략**이 산다(카르는 하위를 남겨야 세고, 불은 표면 깔 자린을 남긴다).

# 제3부 — UX

## §10 한 턴에 플레이어가 하는 일

```
1. 화면 위를 본다     → 상대가 뭘 붓고 있나? 정령이 뭐가 늘었나?
2. 근원 줄을 본다     → 뭐가 쌓였나? 뭘 만들 수 있나?
3. 칸을 나눈다        → 조합? 갈래? 먹임? 발현? 견제?
4. [확정]             → 동시 공개
5. 해결을 본다        → 5켜가 순서대로 재생
```

**★평균 판단 시간 20~40초** — 칸이 8~15개라 배분에 시간이 든다. 그래서 §12의 보조가 필요.

## §11 조작 UX

| 하고 싶은 것 | 어떻게 |
|---|---|
| 조합하기 | 근원 줄에서 **끌어다 조합대에** · 또는 조합대에서 레시피 클릭 |
| 같은 것 셋 합치기 | 판에서 **겹쳐 끌기**(랜디 관습) |
| 갈래 치기 | 정령 카드의 **빈 갈래 칸**을 눌러 기술 고르기 |
| 발현 | 손패 카드를 **판으로 끌기** |
| 견제 | 손패 견제 카드를 **상대 것 위로 끌기** |
| 먹임 | **자동**(칸에서 먼저 빠짐) · 끄면 정령이 풀림 |

**★먹임이 자동으로 먼저 빠지는 것이 중요** — 안 그러면 매 턴 유지비를 손으로 내야 해서 지친다. 대신 **남은 칸이 몇인지 즉시 보인다.**

## §12 판단 보조 (긴 판을 견디게)

| 보조 | 무엇 |
|---|---|
| **모자란 것 붉게** | 못 만드는 이유가 즉시 보임(원소? 획기? 전리?) |
| **★예측선** | "이 속도면 유니크까지 R31" — 빌드업 게임이라 남은 거리가 곧 재미 |
| **위험 표시** | 상대의 다음 수가 내 정령을 잡을 수 있으면 **그 정령이 깜빡임** |
| **합 조건 하이라이트** | 손패 카드를 쥐면 **합이 서는 대상이 빛남**(불살을 쥐면 마른 표면 위 적이) |
| **미리보기** | 합치기 전에 결과를 보여줌(되돌리기가 없으므로) |
| **되짚기** | 지난 턴 해결을 다시 볼 수 있음 |

## §13 긴 판의 리듬

| 라운드 | 체감 |
|---|---|
| 매 턴 | 근원이 쌓이고 숫자가 오른다 |
| ~5R | 등급이 하나 오른다(연출) |
| R16·R36 등 | **전환점** — 유니크에서 사람 꼴이 서면 크게 |
| 수시 | 견제가 와서 쌓은 게 부서진다 → 다시 짓는 공방 |

# 제4부 — 시뮬레이션 (완전 해금 대전 R1~R40)

**A**: 샘 빌드(자원 특화) · 불 계열 / **B**: 수확 빌드(싸우며 큼) · 서리+깨짐

## §14 국면 1 — R1~8 (기반 vs 압박)

| R | A(샘) | B(수확) | 판세 |
|---|---|---|---|
| 1 | 「고인 홈」 깖(획기3) · 자린1 | 자린2 세움 · 술사 직격 | A 술사 −180 |
| 3 | 「물레 술식」(원소+8) | 시린3→시스미 · 계속 때림 | A −540 · B 전리 3 |
| 5 | 자르미2 · 원소 누적 60 | 시스나(레어) 세움 | **A가 밀림** |
| 8 | 「샘 술식」(원소+20·획기+2) | 카르나 추가 · A 정령을 잡음 | A −1,200 · **B 전리 11** |

**★B가 앞선다** — 수확은 때리면서 크니 초반이 강하다. A는 버티며 기반을 깐다.

## §15 국면 2 — R9~22 (역전 구간)

| R | A | B | 판세 |
|---|---|---|---|
| 12 | 자르나2+자르담1 · 원소 180 | 시스담·카르담 | 팽팽 |
| 16 | **「겹샘」**(원소+45·획기+12) | 「먹는 진」(잡을 때 근원12) | A 자원이 B를 넘어섬 |
| 20 | **자르셀(유니크)** 세움 | 시스셀 세움 | **양쪽 사람 꼴** |
| 22 | 갈래 5개 · 「불의 비」 250 | **「언 것 깨기」 콤보**(시스셀 얼림→카르 두 배) | B가 A 정령 하나 제거 |

**★R16이 분기점** — A의 겹샘이 서면 자원이 역전된다. B는 그 전에 끝내야 한다.

## §16 국면 3 — R23~40 (곱의 싸움)

| R | A | B | 판세 |
|---|---|---|---|
| 26 | 「샘의 마당」(원소+100·획기+30) | 「살진 판」(잡을 때 근원30) | A 폭주 시작 |
| 30 | **자르간(전설)** · 「불의 강」 붓기 | **「말 끊기」**(칸1)로 끊음 | **A 부은 칸 8 소멸** |
| 32 | 「고른 숨」+「나눠 외기」+「선 방패」로 재시도 | 못 끊음 | **불의 강 완성** — 매 턴 160 |
| 36 | **자르온(에픽)** — 불 정령 전부 2배 | 시스간+카르셀로 방어 | A 산출 3배 |
| 40 | 갈래 12 · 불바다 | B 술사 버팀 900 | **A 승** |

## §17 ★시뮬에서 읽히는 것

1. **초반은 수확(B), 후반은 샘(A)** — 곡선이 교차한다. **R16~22가 승부처.**
2. **「말 끊기」 칸 1이 대주문 8칸을 태운다** — 견제의 비대칭이 실제로 아프다. A는 **보존 셋(고른 숨·나눠 외기·선 방패)**을 갖춰야 대주문을 세운다.
3. **에픽의 곱이 판을 끝낸다** — 자르온의 "불 정령 2배"가 R36에 붙자 산출이 3배로 뛴다.
4. **★B가 이기려면 R22 전에 끝냈어야** — 수확 빌드는 **속공이 정체성**인데 A가 버텨 냈다.

## §18 남은 것
- **AI가 이 판단을 어떻게 하나** — 칸 배분 알고리즘(다음 작업의 핵심).
- **판당 40R × 3턴 = 120턴**, 턴당 30초면 1시간. **여전히 길다** — 자동 진행·속도 조절 필요.
- 조합대 별창이 자주 열리면 흐름이 끊긴다 — **판 화면에 간이 조합 줄**을 둘지.
- 「빠른 손」 우선권이 유일한 순서 규칙이라 단조로울 수 있다.
