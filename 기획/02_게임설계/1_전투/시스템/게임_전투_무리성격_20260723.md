# 밀려오는 무리의 성격 배합 (2026-07-23 · 루프 13회차)

> **선행:** 시뮬 R1~R40 완주(정정 6건 반영). 지금까지는 무리를 **총 버팀 하나**로만 셌다.
> **목적:** 무리에 성격을 주어 **로스터의 구멍이 실제로 값을 갖게** 한다. 켈온이 나는 것에 무력하고, 카르가 부술 것 없으면 밑값이고, 후르의 「화살 비낌」이 언령엔 무효인 것이 — 무리가 다 똑같으면 아무 뜻이 없다.
> ⚠확정 아님.

---

## §1 성격 여섯 — 로스터 구멍에서 거꾸로 잡았다

**새로 만들지 않았다.** 112마리를 쓰면서 적어 둔 구멍을 모아 보니 여섯 갈래로 모인다. 그 여섯이 곧 무리의 성격이다.

| 성격 | 무엇 | 이것이 값을 갖게 하는 로스터 구멍 |
|---|---|---|
| **걷는 것** | 기본. 아무 특성 없음 | (기준선) |
| **나는 것** | 땅을 안 밟는다 | **켈온**(잡은 것을 지우되 *나는 것 제외*) · 켈·옴의 발밑 솟음 · 「돌바닥 깨기」 |
| **두른 것** | 갑주·껍질·방패 | **카르**(부술 것 없으면 250→50) · 「벗긴 자리 꽂기」·「갑주 깨기」의 존재 이유 · 「바늘불」(갑주 막음값 무시) |
| **외는 것** | 술을 쓴다(완성을 붓는다) | **완성 끊기 다섯 계열**(잔·코르·후르·무네·카르) · 후르 「화살 비낌」이 *언령엔 무효*인 까닭 · 루 「턱 닫힘」·코르 「말 끊기」 |
| **빠른 것** | 두 배로 걷는다 | **시스·옴**(둔화) · 람(속박) · 두르(막이) · 코르(길 닫기) |
| **덮인 것** | 지붕·엄폐 아래로 온다 | **옴**(「내려앉는 하늘」이 *지붕/사방 벽만 막음*) · 실란(그늘 속 과녁 못 잡음) · 「위에서 드는 그늘」이 *지붕 있는 자리에서 곱* |

**★여섯 중 다섯이 특정 계열을 무력화한다.** 그래서 배합이 곧 "이 라운드에 무엇을 세워야 하는가"가 된다.

## §2 라운드별 배합표

한 라운드 무리는 **성격 하나가 주(主)이고 나머지가 섞인다.** 주가 무엇인지는 라운드 벽두에 보인다(대비할 시간이 한 턴 있다).

| 구간 | 주 성격 | 섞이는 것 | 이 구간의 시험 |
|---|---|---|---|
| **R1~4** | 걷는 것 | — | 없음. 무엇을 세워도 된다(배우는 구간) |
| **R5~8** | **두른 것** 40% | 걷는 것 | 카르나 관통(후르·실란) 없이는 값이 반이다 |
| **R9~12** | **빠른 것** 40% | 두른 것 | 둔화·속박 없이는 지키는 것이 깎인다 |
| **R13~16** | **나는 것** 35% | 빠른 것 | **켈·옴 단독 빌드가 여기서 처음 막힌다** |
| **R17~20** | **외는 것** 30% | 두른 것·나는 것 | 완성 끊기가 없으면 대주문을 그대로 맞는다 |
| **R21~26** | **덮인 것** 30% | 외는 것 | 옴 빌드가 반값이 된다 |
| **R27~34** | 섞임(각 20%) | 전부 | **한 계열로는 못 막는다** |
| **R35~40** | 섞임 + **외는 것 30% 상시** | 전부 | 곱을 세울 시간을 상대가 안 준다 |

### 배합의 원리
- **한 구간에 하나씩 새 성격을 낸다** — 플레이어가 하나씩 배운다.
- **낸 성격은 사라지지 않고 섞인다** — 뒤로 갈수록 답이 여럿 필요해진다.
- **R27부터 전부 섞인다** — 여기서부터 **한 계열 빌드가 구조적으로 안 된다.** 시뮬에서 R35부터 곱이 필요했던 것과 겹쳐, 후반은 "곱 + 다계열"이 동시에 요구된다.

## §3 성격별 값 보정

총 버팀은 곡선(9회차) 그대로 두고, **성격이 그 버팀을 어떻게 어렵게 만드는지**만 정한다.

| 성격 | 보정 |
|---|---|
| **나는 것** | 발밑 솟음·낙하·지형 기술 **무효**. 대신 버팀 **−30%**(뜬 것은 약하다) |
| **두른 것** | 받는 값 **−40%**. 단 갑주가 깨지면 그 즉시 정상 + **카르 계열 합 조건 성립** |
| **외는 것** | 세 턴에 한 번 **자기 라운드 무리 값의 20%만큼 되돌려친다**(완성). 끊으면 무효 |
| **빠른 것** | 걸음 두 배 = 잡을 턴이 **절반**. 산출이 같아도 못 잡으면 지나간다 |
| **덮인 것** | 위에서 오는 것(누 안 자리·낙하·무게) **무효**. 대신 좁은 길로만 온다 |
| **걷는 것** | 없음 |

> **★「빠른 것」이 산출 계산을 흔든다.** 다른 성격은 값을 깎지만 빠른 것은 **시간을 깎는다** — 3턴 라운드가 실질 1.5턴이 되므로, 산출이 충분해도 **못 잡고 지나간다.** 시뮬에서 여유 1.3이던 R10 구간이 빠른 것 40%면 실질 여유가 **0.9 언저리**로 떨어진다.
> 이것이 시스(둔화)·람(속박)·두르(막이)·코르(길 닫기)가 화력 없이도 필수인 까닭이고, 로스터에서 "안 잡는 여섯 계열"이 왜 있는지의 답이다.

## §4 검산 — 로스터 구멍이 실제로 값을 갖는가

| 로스터에 적은 구멍 | 어느 구간에서 아픈가 | 답이 되는 것 |
|---|---|---|
| 켈온 = 나는 것에 값 0 | **R13~16** (나는 것 35%) | 후르온(나는 것 전부 떨어뜨림) · 옴담(나는 것 떨어뜨림) · 실란(관통) |
| 카르 = 부술 것 없으면 250→50 | R27~ (두른 것 비중 하락) | 다계열 전환 |
| 후르 「화살 비낌」 = 언령에 무효 | **R17~20** (외는 것 30%) | 코르 「말 끊기」·무네 「먹빛 창」 |
| 옴 = 지붕·사방 벽에 막힘 | **R21~26** (덮인 것 30%) | 켈(측면)·잔(소리는 지붕을 지난다) |
| 실란 = 어둠 속 과녁 못 잡음 | 무네가 섞인 라운드 | 무네 자신을 세우거나 실란셀(그늘 무효) |
| 무네 = 밝은 자리 없으면 절반 | 밤 라운드 | 실란·자르(불 표면이 밝은 자리) |
| 시스 = 혼자 못 이김 | 전 구간 | 잡는 계열 필수 |
| 두르 = 잡는 값 0 | 전 구간 | 잡는 계열 필수 |

**여덟 구멍이 전부 특정 구간에서 값을 갖는다.** 배합을 안 넣으면 이 여덟이 그냥 설명글이었다.

## §5 ★이로써 "한 계열 빌드"가 왜 안 되는지가 수치로 선다

R27~40은 여섯 성격이 각 20%씩 섞인다. 한 계열만 쌓은 판을 대 보면:

| 빌드 | R27~40에서 무력해지는 몫 | 실효 산출 |
|---|---|---|
| 켈 단독 | 나는 것 20% + 덮인 것 일부 | **약 70%** |
| 옴 단독 | 나는 것 20%(뜬 것엔 강하나 지붕에 막힘) + 덮인 것 20% | **약 60%** |
| 카르 단독 | 두른 것이 20%뿐이라 합 조건이 대부분 불성립 | **약 50%** |
| 실란 단독 | 무네 섞인 라운드 + 통벽 | 약 75% |
| 잔 단독 | 두른 것 20%(전설 전 방어 무시 없음) | 약 80% |

**최소 세 계열은 있어야 100%에 가까워진다.** R40 여유가 곱 하나로 1.02였으므로, **실효 산출이 70%로 떨어지면 0.71이 되어 못 넘는다** — 다계열이 선택이 아니라 필수가 된다.

## §6 열어 둔 것
- **성격별 등장 비율의 실제 난수 폭** — "40%"가 고정인지 ±10% 흔들리는지.
- **주 성격을 라운드 벽두에 보여 주는 것**이 맞는지(대비 한 턴). 안 보여 주면 운이 세지고, 보여 주면 판단이 산다. **보여 주는 쪽으로 잡았다** — 정령은 세우는 데 여러 라운드가 드는데 못 보고 대비할 수 없다.
- **「외는 것」이 되돌려치는 20%**가 적정한지. 시뮬에서 재봐야 한다.
