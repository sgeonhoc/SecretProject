# 판 길이 리듬 · 밸런스 역산 (2026-07-24 · 루프 6회차 · 작업 순서 마지막)

> **사용자 확정:** *"판은 길다. 빌드업 하는 게임인데 겨우 만들었더니 바로 끝나면 어떡해."* — 짧은 판 전제(12~16R·술자 2000) 폐기.
> **작업:** 지수 재료표 + 가속 배수로 **"에픽이 판의 몇 % 지점에 서는가"**를 역산해 판 길이를 정한다. 판 길이를 먼저 정하고 재료를 맞추는 게 아니라, **재료가 판 길이를 정한다.**

---

## §1 역산의 전제 (앞 회차에서 확정된 것)

| 값 | 출처 |
|---|---|
| 에픽 하나 = 근원 **~2,250개**(원소 648 + 획기 ~1,600) | 지수 재료표 §2 |
| 원소 = **랜덤** 매 턴 ~3개 (한 계열엔 3/16 ≈ **0.19개**) | 소리 루트 |
| 획기 = **고정** 매 턴 3개 | 새김 루트 |
| 가속 배수 = 샘 계열로 최대 **×7**(고정 3 → 대샘진 20+8) | 가속 전량 §5 |
| 1라운드 = 3턴 | PvE 뼈대 |

---

## §2 ★가속 없이 vs 가속하며 — 에픽까지

### 가속 없음(고정 지급만)

- 원소: 계열당 0.19/턴 → 648개에 **3,400턴** = **1,135라운드** ✗ 말이 안 됨
- 획기: 3/턴 → 1,600개에 **533턴** = **178라운드**

**★원소가 병목이다** — 랜덤이라 한 계열에 모이는 속도가 절망적으로 느리다. **가속 없이는 에픽이 불가능한 정도가 아니라 아예 계산이 안 선다.**

### 가속하며(현실적 곡선)

샘 계열을 단계적으로 올리면 지급이 이렇게 오른다:

| 구간 | 세운 것 | 원소/턴 | 획기/턴 |
|---|---|---|---|
| R1~5 | 「고인 홈」 | 3 + 1 = **4** | 3 |
| R6~12 | 「물레 술식」 | **6** | 3 |
| R13~22 | 「샘 술식」 | **8** | 3 |
| R23~35 | 「겹샘 술식」 | **11** | **5** |
| R36~50 | 「샘의 마당」 | **15** | **7** |
| R51~ | 「마르지 않는 터」 | **23** · 계열 자유 | **11** |

**★유니크(겹샘)부터 획기를 낳는 것이 곡선을 꺾는 지점** — 여기 전에는 획기가 3에 묶여 진이 안 오른다.

### 누적 계산 (한 계열 집중 + 리롤 사용)

| 라운드 | 누적 원소(집중 계열) | 누적 획기 | 도달 가능 |
|---|---|---|---|
| R10 | ~50 | 90 | **레어**(원소 27·획기 27) |
| R20 | ~180 | 180 | **스페셜**(81·~120) |
| R35 | ~500 | 400 | **유니크**(162·~400) |
| R55 | ~1,100 | 900 | **전설**(324·~800) |
| **R75~80** | **~1,900** | **~1,700** | **에픽**(648·~1,600) |

> **★에픽 도달 = R75~80.**

## §3 ★판 길이 확정 — R100

에픽이 R75~80에 선다면, **판은 그것을 쓸 시간을 줘야 한다.** 세워 놓고 바로 끝나면 사용자가 말한 그 문제다.

> **★판 길이 = 100라운드(300턴).**

| 구간 | 비율 | 무엇을 하나 | 등급 |
|---|---|---|---|
| **R1~15** | 15% | 자원 기반 깔기 · 첫 정령 | 일반~레어 |
| **R16~35** | 20% | 사다리 오르기 · 가속 2단 | 스페셜 |
| **R36~55** | 20% | **사람 꼴이 선다** · 진으로 전환 | 유니크 |
| **R56~75** | 20% | 대주문·대진 · 곱이 붙기 시작 | 전설 |
| **R76~90** | 15% | **에픽** — 세우고 굴린다 | 에픽 |
| **R91~100** | 10% | 판의 결말 · 곱이 겹쳐 폭발 | 에픽 다수/이터니티 |

**★에픽이 판의 76% 지점에 서고, 남은 24%(24라운드)를 쓴다.** 세우자마자 끝나지 않고 **넉넉히 굴려 볼 시간**이 있다.

---

## §4 ★긴 판을 지루하지 않게 — 리듬 장치

100라운드는 길다. 앞 설계의 장치들이 여기서 값을 얻는다:

| 라운드 | 사건 |
|---|---|
| 매 라운드 | 근원 줄 숫자가 오른다 · 진에 빛이 고인다 |
| **~5라운드마다** | 등급이 하나 오른다(연출) |
| **R16·R36·R56·R76** | ★**등급 전환점** — 스페셜/유니크(사람 꼴)/전설/에픽. 연출을 크게 |
| 구간마다 | **무리 성격이 바뀐다**(나는 것·두른 것·외는 것·빠른 것·덮인 것) |
| 수시로 | 자원 견제가 와서 쌓은 게 부서진다 → 다시 짓는 공방 |

**★무리 성격 배합(13회차)을 100라운드로 늘려 재배치:**

| 구간 | 주 성격 | 원 설계(40R) |
|---|---|---|
| R1~12 | 걷는 것 | R1~4 |
| R13~25 | **두른 것** | R5~8 |
| R26~38 | **빠른 것** | R9~12 |
| R39~50 | **나는 것** | R13~16 |
| R51~62 | **외는 것** | R17~20 |
| R63~75 | **덮인 것** | R21~26 |
| R76~100 | **전부 섞임** | R27~40 |

각 성격이 **12~13라운드씩** 이어져 배우고 대응할 시간이 넉넉하다.

## §5 무리 곡선 재조정 (40R → 100R)

원 설계는 40라운드에 ×1.12~1.55였다. 100라운드로 늘리면 **비율을 낮춰야** 같은 도착점에 닿는다.

| 구간 | 비율 | 까닭 |
|---|---|---|
| R1~15 | ×1.18 | 초반 계단(일반→레어) |
| R16~35 | ×1.09 | 스페셜 구간 |
| R36~55 | ×1.07 | 유니크 구간 |
| R56~75 | ×1.06 | 전설 구간 |
| R76~100 | ×1.05 | 에픽 구간(곱이 붙으므로 완만) |

**★뒤로 갈수록 완만해진다** — 정령 산출이 곱(고유)으로 뛰므로 무리가 같은 속도로 오르면 따라잡힌다. 계단이 커지는 구간에서 무리를 늦춘다.

---

## §6 ★PvP 재조정 (짧은 판 전제 폐기의 영향)

PvP는 술자가 죽으면 끝나므로 PvE보다 짧다. 그러나 **12~16R은 빌드업을 못 한다.**

| | 옛(폐기) | **★새로** |
|---|---|---|
| 판 길이 | 12~16R | **50~70R** |
| 술자 버팀 | 2000 | **6000** (+10%/라운드) |
| 근거 | 짧은 판 역산 | 유니크(R35)~전설(R55)까지는 서야 빌드업 게임 |

**★PvP는 PvE의 절반 길이** — 상대가 능동적으로 견제하니 더 빨리 결판난다. 다만 **최소 유니크(사람 꼴)는 봐야** 게임이 성립한다.

---

## §7 ★검산 — 판 길이가 앞 설계를 뒤집나

| 앞 설계 | 100R에서 |
|---|---|
| 로스터 "에픽은 판을 통째로 갈아 넣는 것" | ✓ R76까지 전부 부어야 |
| "대부분 판은 스페셜~유니크" | **✗ 정정** — 100R이면 전설·에픽까지 간다. 원 진술은 40R 전제 |
| 니르 "없으면 전설에서 멈춤" | ✓ 더 강해짐 — 긴 판일수록 잃는 위험이 크다 |
| 갈래 "라운드당 하나" | **재확인 필요** — 100R이면 갈래 100개라 상한(에픽 16)을 훨씬 넘는다. **상한이 실질 제한으로 작동** |
| 전리 "라운드÷2" | **✗ 정정 필요** — R100이면 누적 2,500이라 과잉. 에픽 146 기준이면 **라운드÷8** 정도로 낮춰야 |

### ★정정 두 건
1. **"대부분 판은 스페셜~유니크"** → 100R에서는 **에픽까지 정상 도달.** 원 진술은 40R 전제였다.
2. **전리 = 라운드÷2 → 라운드÷8.** R100 누적 ~620으로 에픽(146)+여유가 맞는다.

## §8 구멍 · 열어 둔 것
- **100R × 3턴 = 300턴이 실플레이로 얼마나 긴가** — 턴당 30초면 2.5시간. 랜디 한 판으로는 긴 편이라 **턴당 시간을 줄이거나(자동 진행) 라운드를 압축**해야 할 수 있다. **실기 테스트 필요.**
- **원소 랜덤이 병목인 것이 너무 심하다** — 계열당 0.19/턴이라 리롤 없이는 못 모은다. 리롤 비용(둘+전리 1)이 적정한지 시뮬 필요.
- **갈래 상한이 100R에서 일찍 찬다** — R16쯤이면 에픽 상한 16을 채운다. 그 뒤 남는 칸의 쓸 곳이 필요(다른 정령에 갈래? 자원 가속?).
- PvP 50~70R도 여전히 길다 — 실기 확인 대상.
