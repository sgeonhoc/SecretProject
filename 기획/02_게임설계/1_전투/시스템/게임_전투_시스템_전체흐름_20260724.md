# 게임 시스템 전체 흐름 (2026-07-24)

> **사용자 지시:** *"더 우선적으로 게임 시스템을 먼저 완성하자."*
> **진단:** 부품(재료·등급·정령·자원·전투·빌드)은 다 만들었는데 **「시작 버튼을 누르면 무엇이 어떤 순서로 일어나는가」**가 없다. 부품이 아무리 많아도 흐름이 없으면 게임이 아니다.
> **이 파일이 그 흐름이다** — 판 시작 전부터 결과까지.

---

# 제1부 — 판이 시작되기 전

## §1 준비 단계 (판 밖)

| 고르는 것 | 무엇 | 왜 |
|---|---|---|
| **술사** | 어느 술사로 할 것인가 | 시작 T·칸·특기 길이 다름 |
| **익힌 기술 덱** | 도감에서 가져갈 카드 | **모든 카드를 다 못 들고 간다** — 고른 것만 |
| **첫 조각** | 늘 손에 있을 조각(칸 0) | 부름말·꼴·맺음 기본 세트 |
| **가속 갈래** | 여덟 중 무엇으로 시작할지 | 첫 장치 하나를 미리 정함 |

**★덱을 고르는 것이 이 게임의 「빌드 선언」이다** — 판이 시작되면 못 바꾼다. 다만 **뽑기가 랜덤이라 계획대로 안 된다** — 그 어긋남을 어떻게 수습하느냐가 실력.

### 덱 크기
- **기술 30장**(도감 1,031장 중에서)
- **조각은 별도**(칸 0 · 늘 손에 · 덱에 안 셈)
- 계열을 좁히면 조합이 잘 맞고, 넓히면 어느 근원이 나와도 대응한다 — **좁게 vs 넓게가 첫 판단.**

# 제2부 — 한 턴의 진행

## §2 턴 순서 (여섯 단계)

```
① 지급   → ② 뽑기 → ③ 계획 → ④ 공개 → ⑤ 해결 → ⑥ 정리
```

| 단계 | 무엇이 일어나나 | 플레이어가 하는 일 |
|---|---|---|
| **① 지급** | 원소가 **랜덤**으로, 획기가 **고정**으로 쌓인다 · 샘·낳기·복리 산출이 들어온다 | 본다 |
| **② 뽑기** | 덱에서 카드가 나온다(칸 안 씀) | 손패 확인 |
| **③ 계획** | — | **칸을 배분한다**(조합·갈래·먹임·발현·견제) |
| **④ 공개** | (PvP) 양쪽이 동시에 연다 | — |
| **⑤ 해결** | 아래 §3 다섯 켜로 처리 | 본다 |
| **⑥ 정리** | 식힘 감소 · 유지 안 된 것 풀림 · 표면 사라짐 | 본다 |

## §3 ⑤해결의 다섯 켜 (PvP 규칙에서 확장 · PvE도 동일)

| 켜 | 무엇 | 까닭 |
|---|---|---|
| **1. 방해** | 완성 끊기 · 봉쇄 · 되받기(-노) | 끊긴 것은 다음 켜에서 아예 안 나감 |
| **2. 설치·유지** | 진 발동 · 표면 · 벽 · 묶음 · 먹임 | 직격의 합 조건을 이 켜가 정함 |
| **3. 발현** | 정령·술자의 기술이 나감 | 1에서 안 끊긴 것, 2가 깐 표면 위에서 |
| **4. 판정** | 버팀 0 이하가 **한꺼번에** 지워짐 | **서로 잡으면 둘 다 죽는다** |
| **5. 정산** | 전리·수확·근원 회수 · 지키는 것 감소 | |

**★조합·갈래는 2켜(설치)에서 처리된다** — 그 턴에 합친 정령은 **그 턴부터 싸운다**(3켜).

# 제3부 — 한 라운드의 진행

## §4 라운드 구조 (3턴)

```
[라운드 벽두]  무리가 들어온다 · 주 성격이 보인다(대비 한 턴)
   턴 1  ──┐
   턴 2    ├─ 이 세 턴 안에 잡아야 한다
   턴 3  ──┘
[라운드 끝]   못 잡은 것이 지나간다 → 지키는 것 감소 · 전리 정산
```

**★주 성격을 벽두에 보여 준다**(무리 성격 §6 확정) — 정령은 세우는 데 여러 라운드가 드니 못 보고 대비할 수 없다.

## §5 100라운드의 리듬

| 구간 | 등급 | 무리 주 성격 | 이 구간의 일 |
|---|---|---|---|
| R1~15 | 일반~레어 | 걷는 것 | **자원 기반 깔기** · 첫 정령 |
| R16~35 | 스페셜 | 두른 것 | 사다리 오르기 · 가속 2단 |
| R36~55 | **유니크** | 빠른 것 | **사람 꼴이 선다** · 진으로 전환 |
| R56~75 | 전설 | 나는 것·외는 것 | 대주문·대진 · 곱이 붙음 |
| R76~90 | **에픽** | 덮인 것 | 에픽을 세우고 굴린다 |
| R91~100 | 이터니티 | **전부 섞임** | 겹 발현 · 판의 결말 |

# 제4부 — 이기고 지는 것

## §6 PvE 승패

| | 조건 |
|---|---|
| **진다** | **지키는 것이 0**이 된다(시작 20 · 한 마리 지나갈 때마다 −1) |
| **이긴다** | **R100을 버틴다** |
| **★기록** | 버틴 라운드 · 도달 등급 · 남은 지키는 것 — 세 값으로 판을 평가 |

**★"이겼다"보다 "얼마나 갔나"가 중요하다** — 랜디처럼 **R100 완주는 드물고**, 대개 R60~80에서 뚫린다. 다음 판에 더 가는 것이 목표.

## §7 PvP 승패

| | 조건 |
|---|---|
| **진다** | **술자 버팀 0**(6000 · +10%/라운드) |
| **이긴다** | 상대 술자를 잡는다 |
| **무승부** | R70까지 둘 다 살면 **남은 버팀 비율**로 판정 |

# 제5부 — 판이 끝나면

## §8 남는 것 / 안 남는 것

| 남는다 | 안 남는다 |
|---|---|
| **도감 해금**(그 판에서 처음 쓴 기술이 도감에 기록) | 근원·획기 |
| **조합식 발견**(처음 만든 조합이 레시피에 등재) | 전리 |
| **도달 기록**(최고 등급·최고 라운드) | 세운 정령·진 |
| **히든 해금**(물림 40회 등) | 표면·설치 |

**★판 안의 것은 판이 끝나면 다 사라진다**(캐논: 전리는 그 판에서 뜯은 것). **남는 건 「알게 된 것」뿐이다** — 무엇을 만들 수 있는지, 무엇이 무엇과 물리는지.

> **★이것이 랜디의 「조합 검색 사이트」를 게임 안으로 들인 것** — 판을 거듭할수록 **레시피 지도가 채워진다.** 처음엔 뭘 만들 수 있는지 몰라 헤매고, 나중엔 알고 짠다.

## §9 다음 판에 달라지는 것
- **아는 조합이 늘어** UI에 레시피가 뜬다(모르는 것은 물음표).
- **히든이 열려** 있으면 그 판부터 쓸 수 있다.
- **덱에 넣을 수 있는 카드가 는다**(해금된 것).
- ★그러나 **자원·정령은 매 판 처음부터** — 성장은 지식이지 힘이 아니다.

# 제6부 — 화면 흐름

## §10 화면 순서

```
[시작]
  ↓
[준비]  술사 고르기 → 덱 짜기(30장) → 가속 갈래 고르기
  ↓
[판]    ┌─────────────────────────┐
        │  라운드 벽두(무리 성격 표시) │
        │      ↓                   │
        │  턴 ×3 (지급→뽑기→계획→해결)│
        │      ↓                   │
        │  라운드 정산              │
        └──── R100까지 반복 ────────┘
  ↓
[결과]  버틴 라운드 · 도달 등급 · 새로 안 조합 · 해금
  ↓
[도감]  채워진 레시피 지도 확인
  ↓
[다시]
```

## §11 판 화면 배치 (UI 1차에서 확장)

```
┌──────────────────────────────────────────┐
│ R47 / 100   턴 2/3   지키는 것 ●●●●●○○ 14 │ ← 진행
├──────────────────────────────────────────┤
│  [밀려오는 것]  ← 주 성격: 빠른 것         │
│                                          │
│  [내 정령들]  자르셀 · 시스담 · 두르나      │
│  [내 설치]    샘 술식 · 불담 진            │
├──────────────────────────────────────────┤
│ 손패(30장 중 뽑힌 것)                      │
├──────────────────────────────────────────┤
│ ◆근원  불기12 찬기5 물기8 땅기3 울기0       │
│        엮기2 빔기7 │ ✎획기24 │ ⚔전리18    │
├──────────────────────────────────────────┤
│ 칸 ▣▣▣▣▣▢▢  5/7 남음                     │ ← 이번 턴 배분
└──────────────────────────────────────────┘
```

**★칸 줄이 화면 맨 아래** — 모든 판단이 "칸을 어디에 쓰나"라서, **항상 보여야 한다.**

# 제7부 — 시스템 완결 점검

## §12 부품이 흐름에 다 들어갔나

| 부품 | 흐름의 어디 |
|---|---|
| 8근원·획기 | ①지급 |
| 덱·뽑기 | 준비 · ②뽑기 |
| 조합·갈래 | ③계획 → ⑤해결 2켜 |
| 정령 로스터 | ⑤해결 3켜 |
| 자원 습득 8갈래 | ①지급 · ⑤해결 5켜(수확) |
| 완성 끊기·견제 | ⑤해결 1켜 |
| 무리 성격 | 라운드 벽두 |
| 등급 사다리 | 100R 리듬 |
| 전리 | ⑤해결 5켜 |
| 술자 빌드 5갈래 | ③계획의 성향 |
| 히든·물림 | 판 끝 해금 |

**★부품이 전부 흐름 안에 자리를 얻었다** — 뜬 부품이 없다.

## §13 아직 없는 것 (다음 작업)
- **★터(자리)** — 사용자가 "나중에"라 했으므로 보류. 넣으면 판 화면에 자리 개념이 생긴다.
- **술사 종류** — 준비 단계에서 고르는데, 몇 종이고 뭐가 다른지 안 정했다.
- **덱 30장이 맞는 수인지** — 시뮬 필요.
- **패배 후 재도전 구조** — 로그라이크식으로 이어갈지, 매 판 완전 초기화인지. §8은 "지식만 남는다"로 잡았으나 확정 아님.
