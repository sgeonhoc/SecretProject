## §2 턴 시작 — 자동으로 처리됨

플레이어가 할 것이 없다. 화면이 갱신된다.

| 순서 | 무엇 |
|---|---|
| 1 | **자원 지급** — 원소(랜덤)·획기(고정)가 카운터에 더해짐 |
| 2 | **가속 산출** — 샘·복리·낳기가 있으면 그만큼 더 들어옴 |
| 3 | **카드 뽑기** — 덱에서 손패로 |
| 4 | **칸 초기화** — 이번 턴 쓸 칸이 정해짐 (술사 칸 − 정령 먹임) |
| 5 | **식힘 감소** — 식힘 중인 카드가 1씩 줄어듦 |

**화면 표시:** 늘어난 근원 숫자 · 새로 뽑힌 카드(테두리 표시) · **이번 턴 쓸 수 있는 칸 수**

---

## §3 카드 선택 — 플레이어가 하는 곳

### 기본 규칙
- **칸이 남아 있는 한 계속 낼 수 있다.**
- 카드마다 **칸 소모량**이 다르다(1~5칸, 대주문은 여러 턴).
- **낸 것은 턴 종료 전까지 취소할 수 있다.**

### 낼 수 있는 것 다섯

| 종류 | 무엇 | 칸 |
|---|---|---|
| **기술 카드** | 손패에서 냄 (직격·설치·보조) | 카드마다 |
| **조합** | 근원 → 살란·문양, 또는 합침(등급 올림) | 1~3 |
| **갈래** | 정령에게 기술 하나 가르침 | 2 |
| **견제** | 상대 것을 끊거나 부숨 | 카드마다 |
| **정령 지정** | 그 턴 정령이 쓸 기술을 정함(안 하면 자동) | 1 |

### 조작

| 하고 싶은 것 | 어떻게 |
|---|---|
| 카드 내기 | 손패 카드를 **판으로 끌기** 또는 **더블클릭** |
| 대상 고르기 | 카드를 끌면 **대상 선택 모드** → 대상 클릭 |
| 조합하기 | **[조합]** 버튼 → 조합창 → 만들 것 선택 |
| 합치기 | 판에서 같은 것 셋을 **겹쳐 끌기** |
| 갈래 치기 | 정령 클릭 → **[기술 가르치기]** → 목록에서 선택 |
| 취소 | 낸 것을 **다시 끌어내기** → 칸 반환 |

### 화면에 항상 보이는 것
```
칸  ▣▣▣▣▣▢▢▢   5/8 씀
```
- **못 내는 카드는 흐리게** (칸 부족·재료 부족·식힘 중)
- **카드 위에 커서** → 카드 전문 확대

---

## §4 턴 종료

### [턴 종료] 버튼
- 누르면 그 턴의 선택이 **확정**된다.
- **칸이 남았으면 확인창** — "칸 3 남음. 종료할까요?"

### 종료 후 순서
| 순서 | 무엇 |
|---|---|
| 1 | (PvP·AI) 상대의 선택이 함께 공개됨 |
| 2 | **해결** — 양쪽이 낸 것이 처리됨(5켜 순서) |
| 3 | **정리** — 유지 못 한 것 풀림, 표면 소멸 |
| 4 | 다음 턴 시작 |

---

## §5 라운드와 턴

```
1 라운드 = 3턴
턴 1 → 턴 2 → 턴 3 → [라운드 정산] → 다음 라운드
```

**라운드 정산에서:** 전리 지급 · 무리(또는 상대) 상태 갱신 · 술사 칸 +0.5

## §6 화면 배치 (기능만)

```
┌──────────────────────────────────────┐
│ 상대 술사  4,820/6,000    R23 · 턴 2/3│
├──────────────────────────────────────┤
│  [상대 판]  정령 · 설치물              │
│  ──────────────────────────────       │
│  [내 판]    정령 · 설치물              │
├──────────────────────────────────────┤
│ 내 술사  5,340/6,000                  │
├──────────────────────────────────────┤
│ 근원  불기47 찬기12 물기31 …           │
│       획기118  전리27       [조합]     │
├──────────────────────────────────────┤
│ 손패  [카드][카드][카드][카드][카드]    │

└──────────────────────────────────────┘
```

**버튼은 둘뿐이다** — **[조합]**과 **[턴 종료]**. 나머지는 카드를 끌거나 클릭.

## §7 상태별 카드 표시

| 상태 | 표시 |
|---|---|
| 낼 수 있음 | 보통 |
| **칸 부족** | 흐리게 + 칸 숫자 붉게 |
| **재료 부족** | 흐리게 + 모자란 재료 표시 |
| **식힘 중** | 흐리게 + 남은 턴 수 |
| **선택됨** | 테두리 강조 · 칸 줄에 반영됨 |

---

## §8 예 — 한 턴 (R23, 칸 8)

```
[턴 시작]
  원소 +12, 획기 +5 들어옴
  카드 3장 뽑음
  칸 8 (술사 12 − 먹임 4)

[카드 선택]
  1. 「불의 비」 끌기 → 대상: 상대 정령 무리 → 칸 4 씀 (남은 4)
  2. [조합] → 자린 ×3 → 자르미 → 칸 1 씀 (남은 3)
  3. 정령 클릭 → 기술 가르치기 → 「불살」 → 칸 2 씀 (남은 1)
  4. 「말 끊기」 끌기 → 대상: 상대가 붓는 대주문 → 칸 1 씀 (남은 0)

[턴 종료]
  버튼 누름 → 상대 선택 공개 → 해결 → 다음 턴
```

## §9 정리

- **턴 시작은 자동** — 볼 것만 있다.
- **카드 선택이 전부** — 칸이 남는 한 계속 낸다.
- **턴 종료는 버튼 하나** — 누르면 확정, 해결로 넘어간다.
- **버튼은 [조합]과 [턴 종료] 둘.**
