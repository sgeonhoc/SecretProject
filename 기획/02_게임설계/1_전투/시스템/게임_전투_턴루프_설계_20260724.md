# 턴 루프 설계 — 이 게임의 재미가 사는 자리 (2026-07-24)

> **사용자 지적:** *"절대 이렇게 쉽게 끝날 작업이 아닌데. **턴 루프 UI UX는 전투 시스템의 거의 전부라고 할 정도로 게임의 재미를 책임져.** 우리 게임에서."*
> 맞다. 앞 파일(`턴루프_기본`)은 **버튼과 클릭만** 적었지 **왜 재미있는지·무엇이 어려운지**를 안 다뤘다. 이 파일이 본편이다.

---

# 제1부 — 왜 어려운가 (정보량을 실제로 세어 봄)

## §1 하스스톤과 비교

| | 하스스톤 | **우리** |
|---|---|---|
| 자원 종류 | 마나 1종 | **원소 8 + 획기 + 전리 = 10종** |
| 자원 최대치 | 10 | **수백~수천** |
| 한 턴 행동 수 | 3~5장 | **칸 8~15 = 최대 15수** |
| 행동 종류 | 카드 내기 · 공격 | **조합·합침·갈래·먹임·발현·견제·지정 = 7종** |
| 내 유닛 | 최대 7 | 정령 6 + 설치물 여럿 |
| 유닛당 정보 | 공/체 | **등급·칸·T·버팀·먹임·익힌 기술 8·고유 3** |
| 상대 정보 | 다 보임 | **일부만**(칸 배분 안 보임) |

**★대략 정보량이 하스스톤의 5~8배다.** 이대로 화면에 다 뿌리면 **아무도 못 한다.**

## §2 그런데 이 복잡함이 곧 재미다

이 게임의 재미는 **매 턴의 저울질**에 있다:

> "불기가 47이니 자르미를 셋 만들 수 있다. 그런데 칸이 8뿐이라 조합에 3을 쓰면 견제를 못 한다. 상대가 대주문을 붓고 있으니 끊어야 하는데, 끊으면 내 사다리가 한 턴 늦는다. 어느 쪽이 싼가?"

**★그러니 UI의 목표는 「복잡함을 없애는 것」이 아니라 「저울질을 빠르게 해보게 하는 것」이다.**
- 계산은 UI가 한다.
- 플레이어는 **고르기만** 한다.
- **이리저리 바꿔 보는 것이 공짜여야** 한다(확정 전까지).

# 제2부 — 플레이어 머릿속의 순서

## §3 실제 사고 흐름 (이 순서대로 화면이 도와야 함)

```
1. 무슨 일이 일어났나       → 상대가 뭘 세웠나? 내 게 뭐가 죽었나?
2. 뭐가 급한가             → 상대 대주문? 내 정령이 죽을 판인가?
3. 내가 뭘 할 수 있나       → 근원으로 뭘 만들 수 있나? 손패에 뭐가 있나?
4. 칸을 어떻게 나누나        → ★여기가 본체
5. 이렇게 하면 어떻게 되나   → 미리보기
6. 확정
```

**★4번이 전체 시간의 70%다.** 화면 설계는 4번을 중심으로 짠다.

# 제3부 — 화면 설계

## §4 4구역 배치

```
┌─────────────────────────────────────────────────────────┐
│ A. 판 (전황)                                             │
│    상대 술사 · 상대 정령/설치 · 표면 · 내 정령/설치 · 내 술사│
├──────────────────────────┬──────────────────────────────┤
│ B. 손패                   │ C. 조합대 (★상시·별창 아님)   │
│    카드들                 │    지금 만들 수 있는 것 목록   │
├──────────────────────────┴──────────────────────────────┤
│ D. 칸 배분 줄 (★본체)                                    │
│    조합 ▣▣▣ | 갈래 ▣▣ | 발현 ▣▣ | 견제 ▣ | 남음 ▢▢     │
│                                        [ 턴 종료 ]      │
└─────────────────────────────────────────────────────────┘
```

**★C(조합대)를 상시로 둔 것이 앞 판과의 가장 큰 차이** — 조합은 매 턴 하는 핵심 행동인데 별창이면 흐름이 끊긴다.

## §5 A구역 — 판 (전황을 한눈에)

```
┌───────────────────────────────────────────────────┐
│ 상대  ▰▰▰▰▰▰▰▱▱▱ 4,820   ⚠「얼어붙는 들」 ●●○○  │ ← 붓는 중
│                                                   │
│  [시스셀]  [두르담]  [샘술식]  [겹벽]              │
│   유니크    스페셜    ▣설치    ▣설치               │
│   2500/2500 700/850                               │
│ ─────────────── ❄서리 💧젖음 ──────────────────    │ ← 표면
│  [자르셀]  [카르담]  [람나]   [샘의마당]           │
│   2500/2500 850/850  280/280  ▣설치                │
│   ⚠죽을 위험                                       │ ← 경고
│                                                   │
│ 나    ▰▰▰▰▰▰▰▰▰▱ 5,340                          │
└───────────────────────────────────────────────────┘
```

**항상 보이는 것만 둔다:** 등급 · 버팀 · 설치물 아이콘 · 표면 · **붓는 중 표시** · **위험 경고**
**나머지는 클릭**(익힌 기술·고유·먹임).

## §6 ★C구역 — 조합대 (상시)

```
┌─────────── 조 합 ───────────┐
│ ▼만들 수 있음 (3)            │
│  자르(살란)   불기3      [+] │
│  문양         획기3      [+] │
│  자르미       자린3      [+] │
│                             │
│ ▼모자람 (2)                  │
│  자르나       자르미 2/3     │ ← 흐리게
│  겹샘술식     전리 5/8       │
│                             │
│ ▼자주 쓰는 것 (즐겨찾기)      │
│  ★자르 [+]  ★문양 [+]       │
├─────────────────────────────┤
│ [자동 합침] ○켜기 ◉끄기      │
└─────────────────────────────┘
```

**★설계 핵심 넷:**
1. **「만들 수 있음」이 맨 위** — 계산을 UI가 한다. 플레이어는 목록만 본다.
2. **[+] 한 번에 조합** — 클릭 하나로 칸이 빠지고 만들어진다.
3. **「모자람」도 보여 준다** — 무엇이 얼마 모자란지(2/3). **목표가 생긴다.**
4. **즐겨찾기** — 매 턴 같은 걸 만드므로(자르·문양) 상단 고정.

## §7 ★D구역 — 칸 배분 줄 (이 게임의 본체)

```
┌────────────────────────────────────────────────┐
│ 칸 12  (술사 16 − 먹임 4)                       │
│                                                │
│  조합  ▣▣▣      갈래  ▣▣    발현  ▣▣▣▣        │
│  견제  ▣         남음  ▢▢                       │
│                                                │
│  [지난 턴과 같게]  [비우기]      [ 턴 종료 ]     │
└────────────────────────────────────────────────┘
```

**★기능 넷:**

| 기능 | 무엇 |
|---|---|
| **색으로 구분** | 조합=파랑 · 갈래=초록 · 발현=주황 · 견제=빨강 |
| **먹임은 미리 빠짐** | "16 − 4"로 보여 줌 — 유지비를 손으로 안 냄 |
| **[지난 턴과 같게]** | ★긴 판의 반복 조작을 없앤다. 누르면 지난 턴 배분을 그대로 시도(못 하는 건 비움) |
| **[비우기]** | 전부 취소하고 다시 |

**★칸을 옮기는 것이 공짜다** — 낸 것을 다시 끌어내면 칸이 돌아온다. **확정 전까지 몇 번이든.**

# 제4부 — 저울질을 돕는 장치

## §8 ★미리보기 (4번 사고를 5번으로 잇는 것)

배분을 바꿀 때마다 **결과가 예상으로 뜬다:**

```
지금 배분이면:
  · 내 산출  약 1,240
  · 상대 대주문  ⚠끊김 (말 끊기 냄)
  · 자르셀  ⚠죽을 수 있음 (상대 시스셀+카르 콤보)
  · 다음 턴 칸  13 (먹임 +1 늘어남)
```

**★"다음 턴 칸"이 중요하다** — 정령을 하나 더 세우면 다음 턴이 좁아진다. **지금과 다음의 저울질**이 이 게임의 성장 긴장이다.

## §9 ★상대 예측 (동시 해결이라 필요)

동시 해결이므로 **상대가 뭘 할지 모른다.** 그러나 **단서는 준다:**

| 단서 | 어디서 |
|---|---|
| **붓는 중인 대주문** | 판 위 ●●○○ 표시 (끊을지 말지) |
| **상대 근원 총량** | 대략만("~340") — 큰 걸 만들 참인지 |
| **상대 정령 구성** | 무슨 계열·등급인지 보임 |
| **지난 턴 패턴** | 되짚기로 확인 |
| **AI 성향** | 스토리로 암시(막이형·속공형…) |

**★"상대가 이번 턴 이걸 할 확률이 높다"까지는 안 알려 준다** — 그건 플레이어가 읽는 몫.

## §10 합 조건 하이라이트

카드를 **쥐면** 판에서 **합이 서는 대상이 빛난다.**
- 「불살」을 쥠 → 마른·불 표면 위 적이 표시 → **60이 아니라 125가 뜬다**
- 「언 것 깨기」를 쥠 → 언 적이 표시 → **+140**

**★이것이 콤보를 「발견」하게 한다** — 도감 1,031장을 외울 수 없으니 UI가 알려 준다.

# 제5부 — 반복 조작 줄이기 (판 40~70R)

## §11 자동화 다섯

| 자동 | 무엇 | 끌 수 있나 |
|---|---|---|
| **먹임** | 유지비가 칸에서 먼저 빠짐 | ✗ (항상 자동) |
| **정령 행동** | 정령이 알아서 기술 고름 | 칸 1 쓰면 지정 가능 |
| **자동 합침** | 셋 모이면 자동으로 올림 | ✓ **끌 수 있어야 함**(하위를 남기는 전략) |
| **[지난 턴과 같게]** | 배분 복사 | 매번 선택 |
| **뽑기** | 자동 | ✗ |

**★"자동 합침"을 끌 수 있어야 하는 까닭:** 카르는 하위를 남겨야 세고(금 넣는 매직을 남김), 불은 표면 깔 자린을 남긴다. **자동만 있으면 그 전략이 죽는다.**

## §12 속도 조절

| 무엇 | 옵션 |
|---|---|
| 해결 재생 | 1배 · 2배 · 건너뛰기 |
| 라운드 자동 진행 | 켜면 턴 3개를 연속 |
| 애니메이션 | 끄기 가능 |

# 제6부 — 정보 계층

## §13 항상 / 쥐면 / 누르면

| 층 | 무엇 |
|---|---|
| **항상 보임** | 판(등급·버팀) · 표면 · 붓는 중 · 근원 줄 · 칸 줄 · 손패 · 조합대 |
| **쥐면(hover)** | 카드 전문 · 합 조건 하이라이트 · 정령 요약 |
| **누르면(click)** | 정령 상세(익힌 기술 8·고유·먹임) · 조합 펼치기(재료 트리) · 되짚기 |

## §14 ★조합 펼치기 (도감 대체)

```
자르미 ← 자린 ×3
   자린 ← 자르 ×1 + 문양 ×1
      자르 ← 불기 ×3
      문양 ← 획기 ×3
   총 밑재료: 불기 9 · 획기 9
```

**★어느 칸에서든 끝까지 내려간다** — 랜디의 조합 검색을 게임 안으로. **모르는 것은 물음표**(아직 안 만들어 본 것).

# 제7부 — 한 턴 워크스루 (세밀하게)

## §15 R23 · 칸 12

```
[턴 시작 — 자동]
  원소 +12(불기 8·물기 4) 획기 +5 들어옴
  카드 3장 뽑음: 불의 비 · 말 끊기 · 겹쳐 외기
  칸 12 (술사 16 − 먹임 4)

[1. 전황 확인 — 2초]
  판 위: 상대가 「얼어붙는 들」 ●●○○ 붓는 중 (2/4)
  판 아래: 내 자르셀에 ⚠죽을 위험

[2. 급한 것 판단 — 3초]
  대주문 끊을까? → 칸 1(말 끊기)로 8칸을 태울 수 있다. 싸다.
  자르셀 지킬까? → 두르 카드가 손에 없다. 못 지킨다.

[3. 만들 수 있는 것 확인 — 조합대 보기, 2초]
  자르(불기3) ✓  문양(획기3) ✓  자르미(자린3) ✓

[4. 칸 배분 — ★15~25초]
  · 「말 끊기」 끌기 → 상대 대주문 → 견제 ▣ (남 11)
  · 조합대에서 자르미 [+] → 조합 ▣ (남 10)
  · 조합대에서 자르 [+] ×2 → 조합 ▣▣ (남 8)
  · 자르셀 클릭 → 갈래 「불비」 → 갈래 ▣▣ (남 6)
  · 「불의 비」 끌기 → 상대 무리 → 발현 ▣▣▣▣ (남 2)
      쥐는 순간 상대 정령 둘이 주황으로 빛남 → 합 250 표시
  · 「겹쳐 외기」 → 자잘기 둘 → 발현 ▣ (남 1)
  · 남은 1칸 → 자르셀 지정(칸 1)? 아니면 남김?
      → 미리보기: 지정하면 산출 +80. 지정함. (남 0)

[5. 미리보기 확인 — 3초]
  내 산출 약 1,240 / 상대 대주문 ⚠끊김 / 자르셀 ⚠여전히 위험
  다음 턴 칸 13

[6. 턴 종료]
```

**총 25~35초.** 익숙해지면 15초, 큰 판단이 있으면 60초.

# 제8부 — 아직 안 풀린 것

## §16 걸리는 것

1. **★첫 판이 압도적일 것** — 정보량이 하스스톤의 5배다. **점진 해금 튜토리얼**이 필수(처음엔 조합만·나중에 갈래·그다음 견제).
2. **칸 12개를 15수로 쓰면 클릭이 많다** — [지난 턴과 같게]가 얼마나 먹힐지 실기 확인.
3. **미리보기의 정확도** — "죽을 위험"을 어디까지 계산해 보여줄지. 너무 정확하면 생각을 안 하고, 너무 흐리면 쓸모없다.
4. **조합대가 목록이면 길어진다** — 만들 수 있는 게 20개면? **접기·즐겨찾기·검색**이 필요.
5. **동시 해결의 답답함** — 확정 후 상대를 기다린다. AI는 즉시지만 멀티는 대기. **대기 중에 볼 것**(되짚기·도감)을 줘야.
