# 전투 비주얼 디자인 — 카드·손패·턴 애니메이션 (2026-07-24)

> **사용자 정정:** *"진짜 그냥 **디자인**이라니까? **손패가 멋있게 펼쳐져 있고, 카드가 멋있고, 턴 시작 턴 종료 애니메이션이 멋있게 이어지는 것.**"*
> **조합도 단순 확정:** *"8개 중 하나를 고르면 그 하나에서 조합 가능한 루트가 나오고, 누르고 조합이 되면 조합. 이 시스템의 반복."*
> **이 파일은 시스템이 아니라 「보이는 것」이다.**

# 제1부 — 전체 아트 톤

## §1 이 게임은 무엇처럼 보이는가

**「먹과 돌」** — 살란 글이 새겨지고, 진의 홈에 빛이 도는 세계.

| 요소 | 재질감 |
|---|---|
| **바탕** | 오래된 종이·먹빛 · 짙은 남색~검정 |
| **카드** | **기술서에서 뜯어낸 낱장** — 종이결·먹 번짐 |
| **정령** | 진의 홈 위에 도는 **빛** — 실루엣 + 발광 |
| **근원** | 여덟 빛깔 낱알 · 유리구슬처럼 |
| **진·설치** | 바닥에 새겨진 홈 · 빛이 흐름 |
| **UI 프레임** | 얇은 금선 · 모서리에 살란 글 장식 |

**★핵심 대비:** 어두운 바탕 · 밝은 발광. 판이 어두워야 정령의 빛과 카드의 종이빛이 산다.

# 제2부 — 카드 디자인

## §2 카드 한 장의 구조

```
┌─────────────────────┐  ← 등급 색 테두리(발광)
│  ▨▨▨▨▨▨▨▨▨▨▨▨▨▨  │
│  ▨   그림 영역   ▨  │  ← 상단 60% · 기술의 그림
│  ▨▨▨▨▨▨▨▨▨▨▨▨▨▨  │
├─────────────────────┤
│ ❰3❱  불 의  비      │  ← 칸(왼쪽 원) · 이름
├─────────────────────┤
│ 자리 · 140          │  ← 과녁 · 값
│ 合 마른 표면 → 250   │  ← 합 조건(금색)
├─────────────────────┤
│ 자르 · T6      식힘3 │  ← 계열·마디 / 식힘
└─────────────────────┘
```

### 부분별

| 자리 | 무엇 | 디자인 |
|---|---|---|
| **테두리** | 등급 | 색 + **은은한 발광**(높을수록 강함) |
| **그림** | 기술의 모습 | 먹 그림체 · 한 색 강조 |
| **칸(왼쪽 위)** | 소모 칸 | **검은 원 안 흰 숫자** — 가장 크고 또렷 |
| **이름** | | 붓글씨체 |
| **값·과녁** | | 담백한 활자 |
| **합 조건** | | **금색 줄** — 눈에 띄게 |
| **아래띠** | 계열·T·식힘 | 작게 |

## §3 등급별 카드 치장

| 등급 | 테두리 | 발광 | 더한 것 |
|---|---|---|---|
| 일반 | 회색 | 없음 | — |
| 매직 | 파랑 | 약함 | — |
| 레어 | 노랑 | 보통 | 모서리 장식 |
| 스페셜 | 초록 | 보통 | 모서리 장식 + 바탕 무늬 |
| 유니크 | 보라 | 강함 | **테두리가 천천히 흐름** |
| 전설 | 주황 | 강함 | 흐름 + **바탕에 살란 글 흐릿하게** |
| 에픽 | 빨강 | 아주 강함 | 흐름 + 글 + **그림이 미세하게 움직임** |
| 이터니티 | 무지개 | 최대 | 전부 + **두 색이 섞여 도는 테두리**(겹 발현이라) |

**★유니크부터 테두리가 흐른다** — 손패에 섞여 있어도 **좋은 게 왔는지 한눈에.**

# 제3부 — 손패

## §4 펼침 (부채꼴)

```
                    ╭───╮
              ╭───╮ │ 4 │ ╭───╮
        ╭───╮ │ 3 │ │   │ │ 5 │ ╭───╮
        │ 2 │ │   │ │   │ │   │ │ 6 │
   ╭───╮│   │ │   │ │   │ │   │ │   │
   │ 1 ││   │ │   │ │   │ │   │ │   │
   ╰───╯╰───╯ ╰───╯ ╰───╯ ╰───╯ ╰───╯
        \     \      |     /     /
         ──────  부채 곡선  ──────
```

| 값 | 설정 |
|---|---|
| **곡선** | 아래로 볼록 · 가운데가 가장 높음 |
| **각도** | 카드마다 **3~5도**씩 기울어짐(가운데 0도) |
| **겹침** | 카드 폭의 **35%** 겹침 |
| **장수 대응** | 5장 이하는 넓게 · 10장 넘으면 겹침을 늘려 폭 유지 |

## §5 손패 동작

| 동작 | 연출 | 시간 |
|---|---|---|
| **뽑힘** | 덱에서 **회전하며 날아와** 부채 오른쪽 끝에 꽂힘 · 테두리 한 번 반짝 | 0.4초 |
| **커서 올림** | 그 카드만 **위로 40px 솟고 확대 1.3배** · 기울기 0도로 바로 섬 · 양옆이 살짝 비켜남 | 0.15초 |
| **쥐기(드래그)** | 카드가 손에 붙어 따라옴 · **약간 기울어 흔들림** · 원래 자리에 **빈 그림자** | — |
| **낼 수 있는 곳** | 판이 **은은하게 밝아짐** · 대상 필요하면 **곡선 화살** | — |
| **냄** | 카드가 판으로 **빨려들며 사라짐** · 칸 줄에서 칸이 **채워짐** | 0.3초 |
| **취소** | 카드가 **손패로 되돌아 날아감** | 0.25초 |
| **못 냄** | 카드가 **좌우로 짧게 흔들림** + 붉은 테두리 한 번 | 0.2초 |

**★쥐면 위로 솟는 것**이 카드게임 손맛의 절반이다. 확대·정렬·이웃 비켜남 셋이 같이 있어야 자연스럽다.

## §6 못 내는 카드

- **흐리게**(투명도 45%) + **회색조**
- 아래에 작은 이유 뱃지 — `칸 부족` `재료 부족` `식힘 2`

# 제4부 — 턴 애니메이션

## §7 턴 시작 (총 1.8초)

```
0.0s  화면 가장자리에서 빛이 안으로 한 번 쓸고 지나감
0.2s  ★"턴 24" 글자가 가운데에 크게 떴다가 위로 사라짐 (0.6초)
0.4s  근원 줄에 낱알이 「톡, 톡, 톡」 떨어져 쌓임
        — 계열 색으로 · 숫자가 튀어오르며 증가
0.9s  샘 술식이 있으면: 진 홈의 빛이 넘쳐 근원 줄로 흘러감
1.2s  덱에서 카드가 회전하며 손패로 (장수만큼 0.1초 간격)
1.6s  칸 줄이 아래에서 차오름 — ▢▢▢▢▢▢▢▢ 빈 칸이 그려짐
1.8s  [턴 종료] 버튼이 켜짐 · 조작 가능
```

**★"턴 24" 글자와 칸 줄 차오름이 시작 신호** — 이 둘로 "내 차례다"가 읽힌다.

## §8 턴 종료 (총 1.2초 + 해결)

```
0.0s  [턴 종료] 누름 → 버튼이 눌리며 꺼짐
0.1s  ★손패가 아래로 스르륵 내려가 숨음
0.3s  칸 줄이 닫히며 옆으로 접힘
0.5s  화면이 살짝 어두워짐(판만 남음)
0.7s  ★"상대의 수" 자막이 위에서 내려옴 (멀티면 대기 표시)
1.2s  → 해결 시작
```

**★손패가 숨는 것**이 "이제 내 차례가 아니다"를 가장 확실히 알린다.

## §9 턴 사이 이음새

```
[내 턴 종료] → 손패 내려감 → 화면 어두워짐
      ↓
[해결] 판만 밝음 · 양쪽 수가 처리됨
      ↓
[정리] 식힘 아이콘 감소 · 풀린 것 사라짐
      ↓
[내 턴 시작] 화면 밝아짐 → 손패 올라옴 → "턴 25"
```

**★어두워짐↔밝아짐이 턴의 호흡** — 내 차례는 밝고, 해결은 어둡다.

# 제5부 — 조합 (사용자 확정 흐름)

## §10 흐름 — 세 번 클릭

> *"8개 중 하나를 고르면 그 하나에서 조합 가능한 루트가 나오고, 누르고 조합이 되면 조합."*

```
① 근원 줄에서 「불기」 클릭
        ↓
② 불기에서 뻗는 루트가 펼쳐짐
        ↓
③ 되는 것을 클릭 → 조합됨
```

## §11 ② 루트 펼침 화면

```
          ◉ 불기 47
             │
    ┌────────┼────────┐
    │        │        │
  ╭─┴─╮   ╭─┴─╮   ╭─┴─╮
  │자르│   │후르│   │실란│     ← 불기가 들어가는 살란들
  │불기3│  │물2 │   │불2 │
  │ ✓  │  │불1 │   │울1 │
  ╰─┬─╯   │ ✓  │   │ ✗ │     ← ✓되는 것 / ✗모자란 것
    │     ╰───╯   ╰───╯
  ╭─┴─╮
  │자린│  ← 자르로 이어지는 다음 단
  │자르1│
  │문양1│
  │ ✓  │
  ╰─┬─╯
    │
  ╭─┴─╮
  │자르미│
  │자린3 │
  │ 2/3 │  ← 모자란 수량 표시
  ╰────╯
```

| 표시 | 뜻 | 디자인 |
|---|---|---|
| **✓** | 지금 만들 수 있음 | 카드가 **밝고 테두리 발광** |
| **✗ / 2/3** | 모자람 | **흐리게** + 모자란 것 붉게 |
| **선** | 재료 관계 | 가는 금선 · 되는 길은 **밝게 흐름** |

**★위에서 아래로 뻗는 나무** — 근원이 위, 상위가 아래. 스크롤하면 계속 내려간다(에픽·이터니티까지).

## §12 ③ 조합 순간

```
0.0s  루트에서 그 카드를 클릭
0.1s  재료들이 아래로 빨려들며 모임
0.3s  ★빛이 뭉치고 → 결과가 솟아오름
0.5s  결과 카드가 반짝이며 판(또는 보유)으로 날아감
0.6s  근원 줄 숫자가 줄어듦 · 칸 줄에서 칸이 채워짐
```

**★등급이 올랐으면** 여기서 더 크게(제3부 등급 치장 참고).

# 제6부 — 판(전황) 비주얼

## §13 정령

```
     ✦
   ╱ ✦ ╲        ← 빛 실루엣 (등급 색)
  │  ◉  │       ← 심(중심 빛)
   ╲___╱
  ▬▬▬▬▬▬        ← 진 홈 (바닥에 새겨진 빛)
  ▰▰▰▰▱▱ 2500  ← 버팀 게이지
```

| 등급 | 모습 |
|---|---|
| 일반·매직 | **꼴 없는 빛 덩이** · 작게 떠다님 |
| 레어·스페셜 | **덩어리·기둥 꼴** · 윤곽이 잡힘 |
| 유니크·전설 | **사람 꼴 실루엣** · 발밑에 진 홈이 넓게 |
| 에픽 | 큰 실루엣 + **판 전체에 홈이 뻗음** |
| 이터니티 | **두 색이 섞여 도는** 실루엣 |

## §14 표면·설치

- **표면:** 바닥에 색이 번짐(불=주황 아지랑이 · 젖음=파랑 광택 · 서리=흰 결정 · 그늘=검은 안개)
- **설치(진):** 바닥에 **홈이 새겨지고 빛이 한 바퀴 돔** · 살아 있으면 계속 흐름
- **붓는 중:** 그 위에 **고리 ●●○○**가 뜨고 대상이 살짝 떨림
