# 정령 유닛 시트 — 자린 (일반·불) · ★완성 템플릿 (2026-07-24)

> **사용자 지시(2026-07-24):** *"여기에 대한 값을 좀 더 정돈을 해야 다른 것들을 붙일 때 완성도가 올라가."*
> **이 파일 = 한 마리를 끝까지 못 박은 정본.** 지금까지 상세 파일은 스탯 6줄 + 턴 행동뿐이라 실제로 게임에 넣으면 비는 값(사거리·이동·획득·죽음·PvP)이 많았다. 그 빈 칸을 전부 채운다. **이 아홉 항목이 112마리 공통 규격이 된다.**
> ⚠새 수치 창작 0 — 값은 전부 기존 설계 파일(뼈대·로스터·곡선·PvP)에서 모았다. **새로 못 박은 것은 ★로 표시**한다(빈 칸을 메운 것이라 창작이 아니라 확정).

---

## 1. 신원

| 항목 | 값 |
|---|---|
| 정식 이름(살란) | **자린** (어근 자르 = 불, 어미 -린 = 일반) |
| 꼴(생김새) | 손톱만 한 불티가 제자리를 돌며 떠 있다 |
| 계열 | 자르 — 불 |
| 등급 | 일반 (사다리 1/8) |
| 계열 역할 | 광역 지속(누적) — 표면을 깔아 위 등급·다른 불 정령이 곱으로 먹게 한다 |
| 이 등급의 몫 | 밑바닥 잔돈 + **표면 씨앗**. 제 값은 자잘하고, 진짜 일은 불 표면을 까는 것 |

## 2. 전장 스탯

| 스탯 | 값 | 뜻 |
|---|---|---|
| **버팀** | **30** | 이만큼 맞으면 풀린다 |
| **턴당 칸** | **1** | 한 턴에 한 번 행동 |
| **먹임** | **0** | 유지비 없음 — 갓 앉은 심은 제 한 바퀴만 돌아 유지에 칸이 안 든다(뼈대 §14) |
| **쓰는 기술 T** | **한 마디** | T1 기술이 도감에 없어, 기술 대신 부름말 한 마디를 뱉는다(캐논 §2-1) |
| **익힘(기술 슬롯)** | **1** | 「자르타」 하나로 참 |
| **갈래 최대** | **0** | ★못 가르친다 — 심이 너무 얕아 새길 홈이 없다. 갈래는 레어(3칸)부터 |
| **고유 능력** | **없음** | 고유는 레어부터 붙는다 |

## 3. 행동 — 「자르타」 한 마디

| 항목 | 값 |
|---|---|
| 값 | **25** |
| 과녁 | **한 사람**(단일) |
| ★사거리 | **눈 닿는 한 과녁** — 언령은 눈으로 과녁을 잡는다(살란 정본 §4-6). 자린은 제자리에서 보이는 것 하나를 친다 |
| 부가 | 마른·기름인 것에 닿으면 그 자리에 **불 표면**이 깔린다 |
| 식힘 | **없음** — 한 마디라 매 턴 뱉는다 |
| ★맺음 | **-타**(세상에 넘김) — 뱉은 불은 여느 불이라 되받기(-노)에 안 열리고, 자린이 죽어도 그 불은 안 꺼진다 |

## 4. ★이동과 자리 (지금까지 열려 있던 것 — 여기서 못 박는다)

| 항목 | 값 |
|---|---|
| **움직이나** | **안 움직인다.** 놓인 자리에 뜬 채로 있다(불티는 발이 없다). 판의 「밀려오는 것」이 다가오고, 자린은 사거리에 든 것을 친다 |
| **자리 옮기기** | 술자가 칸 1을 쓰면 한 자리 옮길 수 있다(급할 때만) |
| **차지하는 자리** | 한 칸. 여러 정령이 같은 칸에 겹치지 않는다 |

> **★왜 안 움직이나:** 이 게임은 랜덤디펜스다 — 무리가 오고 정령이 선다. 정령이 돌아다니면 「길목」·「막이」 개념이 무너진다(켈간 길목 강제·두르 벽이 뜻을 잃는다). **일반 정령은 고정, 유니크부터 「선 채로 옮겨 다닌다」(사람 꼴)가 고유로 붙는다** — 자르셀 꼴 설명이 그 예고였다.

## 5. 획득 — 어떻게 얻나

| 항목 | 값 |
|---|---|
| **나오는 법** | **뽑기.** 매 턴 자동으로 정령이 나오고(칸 안 씀·PvE 시뮬 정정), 그중 하나가 자린일 수 있다 |
| ★나올 확률 | 계열 열여섯이 고르면 **1/16**(한 뽑기당). 리롤(일반 둘 + 전리 1)로 원하는 계열로 바꿀 수 있다 |
| **놓는 값** | **0칸** — 뽑힌 자린을 판에 놓는 데 칸이 안 든다 |

## 6. 성장 — 자린이 오르는 길

| 길 | 값 |
|---|---|
| **합침**(세로) | **자린 ×3 → 자르미(매직)**. 합칠 때 칸 1. 자린 셋은 사라지고 자르미 하나가 선다 |
| **갈래**(가로) | **불가**(익힘 상한 0). 자린은 못 키운다 — 셋 모아 올리는 것만이 길 |
| 한 등급 위(자르미)와 차이 | 칸 1→2 · 「자르타」 한 마디 → 실제 기술(「불씨 뿌리기」 등) · 버팀 30→90 |

## 7. 죽음 — 풀리면 어떻게 되나

| 항목 | 값 |
|---|---|
| **풀림** | 버팀 0 이하 → 그 턴 4단계(잡힘 판정)에서 지워진다 |
| **되돌림** | 니르(아묾) 계열이 되세울 수 있다. 다만 자린은 값이 작아 대개 그냥 새로 뽑는다 |
| **남기는 것** | 이미 깐 불 표면은 자린이 죽어도 남는다(-타라 세상에 넘겼으므로) |

## 8. ★PvP 변형 (뼈대를 깎은 판에서)

| 항목 | 값 |
|---|---|
| **앞을 가리나** | **아니다** — 「앞을 가리는」 고유가 없다(그건 돌지킴·두르·그늘담만). 자린 뒤의 술자는 자린이 있어도 직격을 그대로(절반) 받는다 |
| **잡히면** | 상대가 자린을 부수면 **전리 + 술자와의 「닿음」 조각**이 나온다 |
| **초반 값** | R1~3에 자린 몇으로 표면을 깔아 두면, 뒤이어 세울 자르나·자르담의 합 조건이 미리 선다 |

## 9. 턴 행동 (우선순위 — 자동)

1. **마른·기름 표면이 아직 없는 자리의 적**이 사거리에 있으면 → 그쪽에 뱉는다 (표면 씨앗 심기)
2. 아니면 → **가장 가까운 적**에게 뱉는다
- 술자가 칸 1을 쓰면 그 턴은 지정한 과녁에 뱉는다(우선순위 무시)

## 10. 검산 — 자린이 값을 하는가

| 물음 | 답 |
|---|---|
| 자린 하나의 산출 | 칸 1 × 25 = **25/턴 = 75/라운드** — R1 무리 150의 절반 |
| 그럼 약한 것 아닌가 | 아니다. **자린의 값은 25가 아니라 불 표면**이다 — 그 위에서 자르나 「불살」이 60→**125**(2배). 자린은 딜러가 아니라 **밑밥** |
| 셋을 언제 올리나 | R1~4에 자린이 셋 모이면 자르미로 올린다. 다만 **표면 깔 자린 하나는 남기는** 것이 정석(전부 올리면 밑밥이 없어진다) |
| 왜 갈래 0인가 | 익히면 판이 깨진다 — 갈래 +15%가 자린 25에 붙어 봐야 3.75뿐이고, 그 칸 2로 차라리 뽑기·합침을 한다. **작은 것은 못 키우는 게 맞다** |

---

## 11. ★이 아홉 항목이 템플릿이다

지금까지 상세 파일은 **2·3·9번(스탯·기술·턴 행동)**만 있었다. 실제 게임 규격이 되려면 **1(신원)·4(이동)·5(획득)·6(성장)·7(죽음)·8(PvP)**이 있어야 한다. 이 아홉을 112마리에 붙이면 완성도가 오른다.

**다만 대부분은 등급이 정하므로 마리마다 다시 안 적는다:**

| 항목 | 마리마다 다른가 |
|---|---|
| 1 신원 | ✓ (이름·꼴·역할) |
| 2 스탯 | **등급이 정함**(표 하나로) |
| 3 기술 | ✓ (계열별 실카드) |
| 4 이동 | **등급이 정함**(일반~전설 고정 / 유니크+ 옮겨 다님) |
| 5 획득 | **공통**(뽑기·1/16) |
| 6 성장 | **공통 규칙**(3:1 또는 2:1) |
| 7 죽음 | **공통** |
| 8 PvP | 「앞을 가리는」 고유 유무만 다름 |
| 9 턴 행동 | ✓ (마리별 우선순위) |

**→ 마리마다 새로 적을 것은 셋(신원·기술·턴 행동)뿐**이고 나머지는 등급표·공통 규칙이 진다. 지금 로스터가 이미 그렇게 돼 있으니, **공통 규격(4·5·6·7·8)을 뼈대에 한 번 박아 두면** 112마리가 자동으로 완성도를 얻는다.
