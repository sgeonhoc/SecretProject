# 웹 디자인 원칙 노트 (2026-07-04, 사용자 "극찬받는 디자인 찾아보고 가독성+스타일 둘다" 지시)

> 우리 분위기 = **아직 나라도 제국도 없는 젊은 세계 / 따뜻한 양피지·테라코타 / 문학적 세계관 위키**.
> 리서치(editorial·longform·author-site 타이포 트렌드 2025~26) → 우리에 맞게 걸러낸 실행 원칙.

## 핵심 결론 (적용 지침)
1. **제목=세리프, 본문=산세리프.** 문학적 성격은 디스플레이 세리프(제목·섹션명)로 주되, 한국어 **본문은 깨끗한 산세리프(Pretendard) 유지** — 한글 장문 화면 가독성은 산세리프가 우위. 통째 세리프 전환은 역효과(사용자 반복 지적 "가독성").
   - 한글 세리프 후보(제목용): `Gowun Batang`, `Nanum Myeongjo` → 폴백 `'Batang',serif`. 로컬 파일이라 웹폰트는 온라인일 때만; 반드시 폴백 스택.
2. **리딩 measure 65~75자.** 본문 단락 `max-width` ~720–800px로 줄길이 제한(패널/리더 이미 720 근처 — 유지·확장).
3. **줄높이 ≥1.6~1.9**(장문), 단락은 **들여쓰기 없이 빈 줄 간격**으로 분리(웹 관례) — 현재 방식 유지.
4. **따뜻한 팔레트 의도적 유지·정제.** bg #f5f0e7 / ink #2a2620 / accent 테라코타 #b0562b. 대비 충분히(본문 ink-soft 너무 흐리지 않게).
5. **넉넉한 여백·좌측 정렬 레일.** 섹션 컨테이너 폭을 통일(--maxw 1120)해 좌측 끝 정렬 → 정돈감(세계지도 intro 이미 이걸로 수정함).
6. **에디토리얼 캐릭터:** 절제된 타입 스케일, 또렷한 섹션 라벨(작은 대문자 트래킹), 카드 hover 미세 모션, 히어로에 눈에 띄는 제목 1개.
7. **일관성:** 모든 페이지(세계지도·역사흐름·설정·힘의구조·브레인스토밍)가 같은 토큰(색·타이포·간격·카드·내비)을 쓰게 — 한 시스템처럼 보이도록.

## 우선 적용 순서
- ① 세계관_세계지도.html (사용자가 **주로 보는 화면**) — 제목 세리프 도입·리딩 measure·간격·카드 정제.
- ② 형제 페이지로 동일 토큰 전파(역사흐름·설정·힘의구조·브레인스토밍).
