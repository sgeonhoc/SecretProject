# 📦 에셋 이름 규칙 — "파일만 넣으면 자동 작동" 레퍼런스 (A 작성)

> 사용자: "에디터 안 만지고, 너가 지정한 이름대로 파일만 폴더에 넣으면 다 되게."
>
> 이 문서 = **어떤 파일을, 어떤 이름으로, 어느 폴더에** 넣어야 C++가 자동으로 찾아 쓰는지의 **전체 목록.**
> 파일이 없으면 **조용히 무시**(게임 안 깨짐) — 하나씩 채워가며 테스트 가능.
> 폴더가 없으면 만들면 됨(콘텐츠 브라우저에서 우클릭 → New Folder). 이름은 **대소문자/언더바 정확히.**

---

## 🗂️ 폴더 & 접두사 규칙 (전부 `Content/` = `/Game/` 아래)
| 종류 | 폴더 | 파일 이름 | C++ 호출 |
|---|---|---|---|
| 효과음 SFX | `/Game/Audio/SFX/` | `SFX_<이름>` | `ResolveSFX("<이름>")` / 오디오.PlaySFX |
| 배경음 BGM | `/Game/Audio/BGM/` | `BGM_<이름>` | 오디오.PlayBGM |
| 애니 몽타주 | `/Game/Anim/Montage/` | `AM_<이름>` | `ResolveMontage` / 스킬 |
| 초상화 | `/Game/Art/Portraits/` | `T_<이름>` | `ResolvePortrait` |
| 일러스트/컷인 | `/Game/Art/Illust/` | `T_<이름>` | `ResolveIllust` |
| 이펙트 VFX(Niagara) | `/Game/VFX/` | `NS_<이름>` | `ResolveVFX` / 스킬 |

> 이 폴더들은 `DefaultGame.ini`에 쿡 등록돼 있어 패키징(빌드)에도 자동 포함됨.

## 🔊 1. 배경음(BGM) — 파일만 넣으면 자동 재생
| 상황 | 파일 이름 | 언제 |
|---|---|---|
| 타이틀/메인메뉴 | `BGM_title` | 게임 켜서 메인화면 |
| 필드/탐험 | `BGM_field` | 본편 진입 + 전투 종료 복귀 |
| 전투 | `BGM_battle` | 전투 시작 시 자동 전환(종료 시 field 복귀) ✅ |
→ `/Game/Audio/BGM/` 에 위 이름으로 음악 파일 임포트만 하면 자동 재생.

## 🔊 2. 전투 연출 효과음(SFX) — 파일만 넣으면 그 순간 소리남
`/Game/Audio/SFX/` 에 아래 이름으로 넣으면 해당 연출에서 자동 재생:
| 연출 | 파일 | 연출 | 파일 |
|---|---|---|---|
| 약점 WEAK! | `SFX_weak` | 치명타 CRITICAL! | `SFX_critical` |
| 테크니컬 | `SFX_technical` | 원모어 1MORE! | `SFX_onemore` |
| 바톤터치 | `SFX_baton` | 총공격 | `SFX_allout` |
| 빗나감 MISS | `SFX_miss` | 반사 REPEL | `SFX_repel` |
| 흡수 ABSORB | `SFX_absorb` | 반격 COUNTER! | `SFX_counter` |
| 상태이상 | `SFX_ailment` | 근성 ENDURE! | `SFX_endure` |
| 즉사 | `SFX_instakill` | 선제 AMBUSH! | `SFX_ambush` |
| 기습당함 | `SFX_ambushed` | 승리 | `SFX_victory` |
| 패배 | `SFX_defeat` | | |

## ⚔️ 3. 스킬별 — 애니메이션 / 효과음 / 이펙트
**★ 28명 전 스킬이 이미 속성 이름으로 자동 채워져 있음** (CombatArchetype의 Skill 빌더가 속성→이름 자동 부여, 코드로 완료).
스킬 속성(physical/fire/ice/elec/wind/light/dark/almighty)에 따라 자동으로:
- `SkillAnimName` = `<속성>` → `AM_<속성>` 시전 애니(없으면 기본 공격 모션). `SkillMontage` 에셋 직접 지정 시 그게 우선.
- `SkillSFX` = `<속성>` → `SFX_<속성>` 자동 재생.
- `SkillVFX` = `<속성>` → `NS_<속성>` 대상에 스폰 ✅.

> **그래서 채울 건 속성당 3종류, 총 24개 파일이면 28명 전 스킬에 적용:**
> SFX 8개(`SFX_physical`…`SFX_almighty`) + NS 8개(`NS_physical`…) + AM 8개(`AM_physical`…).
> 특정 스킬만 다르게: 캐릭터 BP의 그 스킬에서 SkillSFX/VFX/Montage를 개별 덮어쓰면 속성기본보다 우선.

## 🧍 4. 캐릭터별 — 스탯/스킬/상성/애니/초상 (BP 데이터)
캐릭터 BP(예: `BP_Char_강현`)의 디테일에서 채우는 값들. **전부 C++가 읽어 자동 동작:**
- **스탯:** StatComponent의 레벨/HP/SP/공/방 (성장 곡선 C++).
- **스킬:** `Skills` 배열 — 각 스킬의 이름/타입/SP/위력/속성/연타/상태이상/즉사 + **SkillMontage/SkillSFX/SkillVFX**(위 3번).
- **레벨업 습득:** `LearnableSkills` (레벨 → 스킬).
- **상성:** `WeakElements`/`ResistElements`/`NullElements`/`AbsorbElements`/`RepelElements`, `AilmentImmune`, `bIsBoss`, `CounterChance` 등.
- **기본 모션:** `BasicAttackMontages` / `HitReactionMontages` 배열에 몽타주 드롭.
- **드롭:** `DropItemId`/`DropChance`/`DropCount`.
- **초상화(스토리 화자):** `/Game/Art/Portraits/T_<화자이름>` (예: 화자 "강현" → `T_강현`) — 스토리 위젯이 대사 줄의 화자 이름으로 자동 표시 ✅. (대화창[B]에도 연결 예정)

## 🎴 5. 스토리/이벤트 일러스트 (컷인)
- 스토리 비트/이벤트 컷인: `/Game/Art/Illust/T_<비트Id>` (예: `T_b_awaken`).
- 스토리 위젯이 비트 Id로 일러스트를 자동 표시 ✅ (해당 비트 장면에 배경 일러스트로 깔림).

## ⚙️ 6. 설정 화면 (에셋 불필요 — 전부 C++)
메인메뉴 '설정' → 볼륨(마스터/BGM/SFX)·해상도·화면모드·수직동기·텍스트속도·언어. 전부 C++로 동작/저장(슬롯 "Settings"). **사용자는 위젯에 컨트롤만 배치**(WBP_Settings, build_all_ui.py가 자동 생성: Slider_Master/Bgm/Sfx, Btn_WindowMode, Chk_VSync, Btn_ResPrev/Next, Btn_TextPrev/Next, Btn_Language, Btn_Apply/Reset/Close + Txt_*).

## 🔜 아직 "이름만" 단계가 아닌 것(에디터 불가피)
- **레벨(.umap):** 타이틀 레벨·본편 맵은 에디터로 생성·디자인.
- **메시/리타겟 애니 원본:** 캐릭터 스켈레탈 메시, 몽타주 원본 제작.
- **위젯 버튼 배치:** `build_all_ui.py`가 자동 생성하지만, 디자인 다듬기는 에디터.

## 📌 채워야 할 것 요약 (체크리스트)
1. `/Game/Audio/BGM/` : `BGM_title`, `BGM_field` (+ `BGM_battle` 예정)
2. `/Game/Audio/SFX/` : 위 연출 17종 `SFX_*` + 스킬별 `SFX_<효과명>`
3. `/Game/Anim/Montage/` : 캐릭터 기본/피격 + 스킬 시전 `AM_*`
4. `/Game/VFX/` : 스킬 이펙트 `NS_<효과명>`
5. `/Game/Art/Portraits/` , `/Game/Art/Illust/` : 초상/컷인 `T_*`
6. 캐릭터 BP 데이터(스탯/스킬/상성/슬롯) — 4번 항목

> **B의 세계관/스토리가 완성되면** A가 캐릭터·스킬·씬별 **정확한 이름 목록**을 이 문서에 확정해 줌 → 사용자는 그 이름대로 파일만 채우면 전부 자동 작동.
