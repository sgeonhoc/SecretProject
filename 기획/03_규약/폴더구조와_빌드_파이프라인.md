## 2. 빌더 → 산출물

전부 **프로젝트 루트에서** 실행한다.

```bash
node 도구/웹빌더/_build_lore_pages.js      # 통사 페이지 5장
node 도구/웹빌더/_md_to_page.js            # 위성 페이지 17장
node 도구/웹빌더/_build_map_docs.js        # 웹/세계관_지도_문서_데이터.js  (지도에 문서 싣기)
node 도구/웹빌더/_build_story_data.js      # 웹/세계관_이야기_보강_데이터.js
node 도구/웹빌더/_build_살란_전서.js       # 웹/살란_전서.html      (기술 도감)
node 도구/웹빌더/_build_조합대.js          # 웹/살란_조합대.html
node 도구/웹빌더/_build_역사본선_통독.js   # 웹/역사본선_통독.html
node 도구/웹빌더/_build_rasel_plan.js      # 웹/세계관_라셀_도시뼈대.html + 도구/_rasel_plan.json
node 도구/웹빌더/_build_노트북LM_통합.js   # 기획/…/세계관_역사본선_노트북LM_통합본.md
node 도구/웹빌더/_build_열람index.js       # 열람.html  (진입점 — 페이지가 늘면 다시 돌린다)
```

**순서가 있는 것:** `_build_lore_pages.js` → `_md_to_page.js` → `_build_map_docs.js`
(앞의 둘이 html 을 만들고, 마지막이 그 html 을 읽어 지도에 실을 데이터를 뽑는다.)

**한 원본 두 산출물:** `_build_rasel_plan.js` 가 뱉는 `도구/_rasel_plan.json` 을
`도구/언리얼/_build_rasel_city_ue.py` 가 읽어 언리얼에 도시를 짓는다.
→ **웹 도면과 실제 레벨이 같은 원본에서 나온다.** 도면을 고치려면 `_build_rasel_plan.js` 를 고친다.
