# 🌐 역사 본선 — 병렬 확장 설계 (2026-07-12 사용자 확정)

> **경위.** 사용자 질문 원문: "우리 세계관 근데 너무 병렬작업도 모자라고 좁지않아?" → B 진단(시점 독점·공간 좁음·시간축 한 줄)에 사용자가 확장 범위 A+B+C 전부 선택. 사용자 원문:
> **"C까지 — 새 대륙, 시간축 병렬도, 세계를 확장하는 작업이잖아? 지금 대륙구조를 틀을 부수던지 확장하던지 맘껏해서 확장시켜보자."**
> → **유지 자산 중 "에오라 대륙 틀" 잠금 해제.** 대륙 구조는 부수거나 확장 가능. (착수문서 §1 개정 반영.)

## 0. 이 문서의 지위
- 본선 병렬 확장(2단계)의 **틀 문서.** 착수문서 규율 3("척추 먼저 → 병렬 확장")의 병렬 단계가 지금이다. 척추(1~3권)는 완결.
- 읽기 세트는 착수문서 §0 그대로 + 이 문서. 구 세계관 md Read 금지 동일.
- **여기 적힌 신설 권역·대륙은 전부 "골격 + 열림"이다. 잠긴 것은 행성 구조의 층위(§2)와 확장 원칙(§1)뿐, 각 권역의 내용물은 쓰면서 앞으로 굴려 만든다.** 하나에 꽂힘 금지 — 이 문서의 어떤 항목도 "이대로 확정"이 아니라 "이 자리에 무엇이 있을 수 있는지의 후보 다발"이다.

## 1. 확장 원칙 (전 레인 공통 · 위반 = 사고)
1. **자기 눈.** 승격·신설되는 권역의 연대기는 그 권역 사람의 눈으로 쓴다. 삼각주는 그들에게 "소문으로만 듣는 먼 나라"거나 아예 없는 나라다. 3권을 참조 프레임으로 쓰지 않는다(사건 대조는 §4 시간축 규칙으로만).
2. **같은 물리, 다른 답.** 확정본(노트북LM 20260712)의 물리 — 능력자 약 1/3, 터·방출, 고대신과 흉터, 반신, 경지 감각 — 는 행성 공통이다. 갈라지는 것은 물리가 아니라 **그 물리에 대한 각 권역의 답**(신앙·제도·법·셈·전쟁·기술의 자리)이다. 확장의 재미는 전부 여기서 나온다.
3. **앞으로만.** 각 권역은 자기 지형·기후 조건에서 앞으로 굴린다. 현대 도착지 겨냥 금지(탄탄한 역설계 허용 조항은 있으나, 신설 권역에서는 아예 쓸 도착지가 없다 — 쓰지 마라). 지구 문명 1:1 복붙 금지 — 구조·질감·스케일만 재도출, 이름·수치 차용 금지(자료조사 워크플로 §4.5 동일).
4. **박자 독립.** 권역마다 흥망의 박자를 삼각주 연표에 맞추지 않는다(§4).
5. **4금기·금지어·톤 분리·경지=출력 서술** — 착수문서 §3 전부 그대로 적용.

## 2. 행성 틀 (공간 확장 — 층위만 잠금, 내용물은 열림)
> 방위·거리·해류 같은 지도 수치는 여기서 안 정한다(지도 작업 때 세계지도.html과 함께). 여기서 정하는 건 **"서로 얼마나 모르는가"의 인지적 거리**다.

### 2-0. ★층위는 관찰자 상대적이다 (2026-07-12 사용자 통찰 — 구조 개선)
- **사용자 원문:** "이 3층위를 말하는 방식이, 에오라 대륙의 관점인거 같거든? 그렇다면 채울게 너무 많겠는데? 2층위 입장에서 본인들의 대륙의 서사, 3층위 입장에서 본인들의 대륙의 서사를 다 채워넣어야해." (+ 앞서: "실제로 한 세계에 존재하는데 서로 목격을 못한거뿐" / "큰 대륙이 3개 멀리 떨어져있다는거지 다만 단순히 멀어서 모를뿐" — **다른 차원 아님·같은 행성·아메리카↔아프리카 같은 지리적 관계.**)
- **바로잡음:** 아래 층위 Ⅰ/Ⅱ/Ⅲ 구분은 **오직 에오라 대륙에서 바라본 하나의 뷰**다. 층위는 대륙에 붙은 고정 등급이 아니라 **관찰자에 따라 매번 다시 매겨지는 거리**다.
  - 에오라 기준: 에오라=Ⅰ(중심) / 계절비 대륙=Ⅱ(소문의 끝) / 신들이 누운 대륙=Ⅲ(미지).
  - **계절비 대륙 기준: 계절비 대륙 자신이 Ⅰ(중심).** 에오라가 그들에겐 Ⅱ(소문의 끝 — "자주 물감이 오는 서쪽 끝의 신화적인 땅"). 그리고 그들에겐 **그들만의 Ⅲ(미지)** 이 대양 어딘가에 또 있다.
  - **신들이 누운 대륙 기준: 자신이 Ⅰ(세상의 전부).** 에오라도 계절비도 그들에겐 아예 없는 땅.
- **그래서 채워야 할 것(사용자 지시):** 각 대륙을 **그 대륙 주인공의 눈으로, 자기가 중심인 세계로** 채운다. 즉 각 대륙마다 ①자기 대륙 안의 여러 이웃 권역(그 대륙의 "삼각주·고지·초원"에 해당하는 다극) ②자기가 소문으로만 아는 먼 대륙(그들의 Ⅱ) ③자기가 존재조차 모르는 대양 건너(그들의 Ⅲ)를 각각 가진다. **에오라만 3권을 가진 게 불공평하다 — 계절비도, 신들이 누운 대륙도 자기 3권을 가져야 한다.** (이것이 병렬 확장의 진짜 크기다.)
- **작업 순서(방대함 관리):** 각 대륙을 한 번에 3권까지 안 쓴다. **척추 먼저**(§1 원칙 3): 각 대륙의 "자기 층위 지도 + 내부 다극 골격 + 개관 1편"을 먼저 세우고 → 그 위에 내부 권역 연대기를 하나씩 얹어 심화. 에오라가 걸어온 길(삼각주 척추 → 권역 승격)을 각 대륙에서 반복한다.

### 층위 Ⅰ — 에오라 대륙 (★에오라 기준 뷰 · 아는 세계 · 기존 + 대륙 내 확장)
- 기존 5권역: 삼각주 · 잿빛 고지 · 숲 · 초원 · 걸음 폭 섬(군도). 3권 6부가 스케치, 이번에 각자 독립 연대기로 승격(§3).
- **대륙 내 신설(B):** 에오라 대륙 틀을 넓혀 얹는다. 후보 다발(전부 열림 — 쓸 때 지형이 허락하는 자리에):
  - **남쪽 마른 띠와 오아시스 사슬** — 대상(隊商)이 몇 달을 건너는 마른 바다. 같은 대륙인데 띠 너머를 서로 모른다(대륙 하나 안의 "모르는 세계"). 띠 너머에 무엇이 있는지는 **안 잠금.**
  - **북쪽 언 땅** — 겨울이 본체인 살림. 곳간이 아니라 이동과 나눔이 셈의 단위가 되는 곳. 능력 1/3이 혹한에서 갖는 뜻(불 능력 하나가 무리 하나의 겨울)은 쓰면서.
  - **큰 강 하나 더** — 삼각주와 다른 답을 낸 두 번째 강 문명 자리(인더스 질감: 도시계획은 정연한데 왕궁·신전이 안 보이는 수수께끼 같은 결). 후보일 뿐.
- 층위 Ⅰ 안에서는 교역·전쟁·소문으로 서로를 안다(3권이 이미 그렸다).

### 층위 Ⅱ — 소문의 끝 (★에오라 기준 뷰 · 교역 사슬 몇 단계 건너 — 이름만 아는 세계)
- **계절풍 쌍강 대륙(가칭 — 이름 안 잠금).** 에오라와 초원 육로 또는 남쪽 바닷길로, 물건은 오가되 사람은 거의 안 오간다. 삼각주 상인은 "비단 같은 천이 오는 동쪽 어딘가"만 안다. 질감 후보: 계절풍·모내기·큰 인구·글이 다른 원리(소리가 아니라 뜻을 적는 글)·관리를 시험으로 뽑는 발상. **전부 후보 — 이 대륙의 연대기는 자기 눈으로 새로 쓴다.**
- 층위 Ⅱ의 핵심 질감: **양쪽 다 상대를 반쯤 지어낸다.** 서로의 기록에 상대가 괴물 반, 신화 반으로 적힌다.

### 층위 Ⅲ — 모르는 세계 (★에오라 기준 뷰 · 대양 건너 — 존재 자체를 모름)
- **대양 자체가 하나의 권역.** 별 헤아려 원양을 건너는 군도 사슬 사람들(걸음 폭 섬과는 다른, 수평선 밖으로 나가는 항해). 이들은 층위 Ⅲ의 대륙들을 "먼저" 알게 될 수도 있다 — 안 잠금.
- **대양 건너 대륙 — 내용물 통째로 안 잠금.** 이미 숲(달력 도시)·고지(매듭 살림)가 에오라 안에 있으므로, 여기는 그 재탕이 아니어야 한다. 후보 다발만: 흉터가 대륙의 절반인 땅(고대신 톤이 일상인 세계) / 반신이 유난히 많은·또는 하나도 없는 땅 / 능력 비율은 같은데 신앙이 전혀 다른 길로 간 땅 / 아예 사람이 늦게 도착한 빈 대륙. **하나 골라 꽂지 말 것**(경우의 수 100만) — 단 🆕**착수 게이트는 해제됨(2026-07-12 "확장 마음껏해"). 대절멸이 예고 없는 외생 사건으로 확정되어 4권과의 얽힘이 사라졌다** — 이제 대양 건너 대륙도 자율로 열 수 있다.
- 층위 Ⅲ의 규칙: **본선 1~3권 어디서도 이 세계를 몰랐다는 사실이 바뀌지 않는다.** 소급 접합 금지 — 3권에 "사실 알고 있었다"를 심지 않는다. (1권 §7·층0 유적의 "끊긴 돌길" 같은 초고대 모티프가 대양 건너와 이어질지는 열림 — 잠그지 않는다.)

### 물리 공통 확인 (전 층위)
- 고대신 흉터는 행성 전체에 있다(1권 §4 "지구 규모"와 정합). 각 대륙엔 자기 흉터·자기 반신·자기 보냄/기림 관습이 있고, **서로의 존재를 모른 채 같은 물리에 다른 답을 냈다** — 이게 확장의 척추다.
- 반신의 시간 셈(수백 년 단위)은 어느 대륙에서나 같다. 대양을 반신이 건넜는가 — 안 잠금(층위 Ⅲ 연결 후보 중 하나일 뿐).

## 3. A — 기존 4권역 승격 (독립 연대기)
각 권역당 파일 1개, 자기 여명 → 자기 찬란 → (시대 끝은 4권 게이트라 안 씀). 3권 6부의 스케치와 모순 없이, 그러나 6부를 "밖에서 본 오해"로 뒤집는 재미 허용(예: 삼각주 눈에 "글 대신 매듭"이었던 것이 고지 눈에는 "적으면 죽는 것과 적을 필요 없는 것의 구분"일 수 있다 — 후보).

## 4. 시간축 병렬 규칙
1. **달력 독립.** W.0(0년)은 삼각주의 셈이다. 다른 권역은 자기 달력로 센다(후보: 홍수 몇 번째 / 큰 항해 몇 세대 / 달력 톱니 몇 바퀴 / 언 강이 몇 번 갈라졌나 — 권역마다 쓰면서). 본문에 W.연도 환산 병기 금지 — 환산은 후대 학자들도 다투는 것으로 열어 둔다.
2. **박자 어긋남.** 한 권역의 절정이 다른 권역의 캄캄한 골짜기와 겹치게 — 단 이것도 "맞추는" 작업이 되면 안 된다. 각자 굴리고, 어긋남은 결과로 생기게 둔다.
3. **동시성 봉인.** "삼각주의 §25 대회전이 있던 해에 고지에서는…" 식 대조 서술 금지(그게 다시 삼각주 시계로 묶는 짓이다). 권역 간 접점은 물건·소문·난파선처럼 **사물로만** 오간다.
4. 🆕**대절멸(2026-07-12 사용자 확정): "마른하늘 날벼락" — 예고 없는 외생 사건.** 어느 권역 연대기도 끝을 미리 쓰지 않는다(게이트라서가 아니라, 날벼락이라 역사 안에 징조가 없어야 하기 때문). 대절멸을 향한 복선·소급 설계는 금지 강화. 각 권역은 대절멸을 **의식하지 않고** 제 논리로 앞으로만 굴린다.

## 5. 레인 분담 (5계정 병렬)
- 권역/대륙 = 레인 1개. 한 레인이 한 권역을 잡으면 착수문서 §4에 "누가 어느 파일" 등록 후 시작(충돌 방지).
- 각 레인 공정: ①자료조사(필요분만, 채집록에 →사용처 명기) → ②집필 → ③금지어·4금기 grep 자가검열 → ④착수문서·지도 동기화. (본선 기존 워크플로 그대로.)
- 신설 대륙(층위 Ⅱ·Ⅲ)은 **기존 4권역 승격이 자리 잡은 뒤** 여는 걸 권장 — 단 자료조사는 먼저 돌려도 됨.

## 6. 자료조사 대기 큐 (신설분 — 채집록에 이관해 진행)
- 몬순·벼농사 살림(모내기 노동 조직·홍수 셈) / 뜻글자 체계의 사회적 비용과 힘 / 시험으로 관리 뽑기의 초기 형태
- 원양 항해(별·너울·새 읽기 항법·카누 계보) / 오아시스 대상 경제(소금-금 무언교역) / 혹한 살림(이동·나눔 규범)
