# 에오라 말 — 세계의 옛말 어휘집 (지명·나라·힘의 이름 체계)

> **지위:** 이 세계의 **고유명 짓는 규칙**을 세운 정본(2026-07-09 신설). 사용자 지시 — "갈대 둑·소금 해안 같은 이름이 독자에게 불친절하다(작은 지형 이름이 나라 이름처럼 안 읽힌다). 판타지 언어체계를 간단히 만들어 고유명을 주고, 그 이름이 무슨 뜻인지 병기하자. 그래야 몰입이 안 깨지고 '이건 이름이다'가 바로 읽힌다."
> **근거(현실 지명학):** 작은 지형은 묘사 이름을 그대로 쓰지만(Broken Bay·Salt Coast), 도시·나라는 **[특정 요소]+[성읍/왕령 요소]**로 지어져 세월에 **닳아 뜻이 불투명해진 고유명**이 된다(Lugdunum→Lyon·Mediolanum→Milano·Londinium→London / France=프랑크족·England=앵글족). 이 세계도 **규모·나이에 따른 이름의 위계**를 둔다.
> **규율:** ①매커니즘은 이 문서 소관 아님 — `../능력과_마력/세계관_힘의_구조.md`(②레인) 소유. 이 어휘집은 **이름(naming)만** 준다. ②추상어 금지(요소 뜻은 구체적으로). ③기존 고유명(베사·케라·수린·에오라·카나흐·마엔·세르네)의 소리결에 맞춘다 — 새 이름이 이물스럽지 않게. ④묘사 이름은 **버리지 않고 '옛 이름·뜻'으로 병기 보존**(런던을 '넓은 강의 요새'라 안 부르듯, 뜻은 어원으로만).

---

## §0. 이름의 위계 (무엇에 고유명을 주고, 무엇을 묘사로 두나)

| 층위 | 방식 | 왜 |
|---|---|---|
| **작은 지형** (여울·고개·내·곶·우물 골) | 투명한 묘사 그대로 | 사소한 곳은 눈에 보이는 특징이 곧 이름 — 현실도 그렇다(버들 내·손자국 고개 유지) |
| **변경 땅** (먼 들·찬 들·잿빛 고지·어스름 숲) | 대체로 묘사 유지 | 왕관 밖·인구 성근 곳은 묘사 이름을 오래 유지(현실 변경도 그렇다) |
| **도시** | 원래 묘사가 닳은 **고유명** + 뜻은 어원으로 | 만 년 된 수도를 아직 '갈대 둑'이라 부르면 소지역처럼 읽힌다 |
| **왕조·나라·제국** | 창건자/강/합친 도시에서 온 **고유명** | 현실 나라 이름도 사람·강·부족에서 옴 |

★ 원칙: **큰 것·오래된 것·도시일수록 이름이 닳아 불투명해진다.** 이건 이 세계 캐논과도 맞음 — 지명 사전 §0 "사건이 이름을 덮어씀", 릴레이 "문자=닳은 그림"(이름 마모 원리 이미 있음).

## §1. 소리결 (에오라 말이 어떻게 들리나)

- **닿소리:** m, n, r, l, s, th, k, t, d, b, v, h, y, w — 부드러운 것 위주(거센 군집 없음).
- **홀소리:** a, e, i, o, u — 열린 소리.
- **마디:** 대개 두세 마디. 받침은 -n, -r, -l, -s 정도로 가볍게. 흐르듯 이어짐.
- **결:** 베사·케라·수린·에오라·마엔·세르네와 한 핏줄로 들리게(이 이름들이 이미 에오라 말이다).

## §3. 이름표 — 큰 도시·나라·제국 (묘사 이름은 뜻으로 병기 보존)

| 옛 이름(묘사=뜻) | 에오라 말 고유명 | 지은 법 · 정체 |
|---|---|---|
| 물의 집 (삼각주 왕가) | **마레스**(Mareth) | 마르(물)+에스(집) — 글자 그대로 '물의 집'. 첫 왕국을 세운 **베사**의 왕가 |
| 갈대 둑 (첫 성벽 도시) | **켈두르**(Keldur) | 켈(갈대)+두르(둑·성벽). 첫 성벽 도시, 여러 왕관의 수도 |
| 소금 해안 (연맹) | **사르보르**(Sarvor) | 사르(소금)+보르(해안). 쇠와 배의 항구 연맹 |
| 시장 모래톱 (헌장시) | **탈렌**(Thalen) | 탈(모래)+엔(성읍). 만 년 묵은 공증의 자치시 |
| 강굽이 나루 | **마르벤**(Marven) | 마르(물)+벤(→여울·굽이). 중류 첫 붙박이 마을 [필요 시] |
| 케라 왕관 (첫 제국) | **케라**(Kera) | 케라 강 이름 그대로 — 이미 고유명 |
| 쇠 왕관 (둘째 제국·세르네) | **세르나르**(Sernar) | 세르네+아르(왕령). 별명 '길의 제국'. 능력자가 직접 쓴 왕관 |
| 두 강 왕관 (셋째 제국) | **마르켈**(Markel) | 마르(마레스)+켈(켈두르) — 두 세력이 겹혼인으로 합친 제국. 글자 그대로 '물과 갈대' |
| 수린 군도 | **수린**(Surin) | 수린+인(섬) — 이미 고유명 |
| 대륙 | **에오라**(Eora) | 이미 고유명 |
| 새 땅 | **카나흐**(Kanah) | 이미 고유명 |

★ 왕관 별명(케라 왕관·쇠 왕관·두 강 왕관)은 왕좌의 칭호로 **그대로 살려 둔다**(현실의 '철왕좌'처럼) — 나라의 고유명(케라·세르나르·마르켈)과 나란히 쓰면 층이 생긴다.

### 변경·소지형 (묘사 유지 — 고유명 안 줌)
먼 들·찬 들·잿빛 고지·어스름 숲(변경 땅) / 버들 내·손자국 고개·갈로 여울·잿개·문곶(소지형). 이들은 왕관 밖·작은 곳이라 묘사 이름이 자연스럽다.

## §4. 힘의 말 — 권능을 부르는 옛말 (naming만 · 매커니즘은 힘의_구조.md 소유)

> 이 세계의 힘(몫·결·상쇄 등)은 `../능력과_마력/세계관_힘의_구조.md`가 정본이다. 여기서는 그 개념들에 **에오라 말 이름만** 준다 — 매커니즘은 안 건드린다. 능력자의 힘이 "마법·주문"처럼 이름으로 불릴 때 몰입이 깊어지도록.

| 에오라 말 | 뜻 (힘의_구조 개념) |
|---|---|
| **셀**(sel) | 한 사람 안에 깃든 세계의 몫 — 그 사람 힘의 양 [= 몫·내림] |
| **셀라**(sela) | 셀을 지닌 사람 = 능력자 (통칭) |
| **다르**(dar) | 셀이 흐르는 결·통로 (사람마다 다름) [= 결·두께] |
| **엔나**(enna) | 셀을 여는 일 = 발동·권능을 씀 ("엔나한다") |
| **멜**(mel) | 두 힘이 부딪쳐 서로 지워짐 = 상쇄 |
| **베르**(ver) | 쓴 힘이 세계로 도로 스미는 것 = 재흡수(대가) |
| **셀바**(selba) | 셀을 길러 키우는 일 = 수련 (개화·벼림 포함) |

★ 씨앗(정하지 말 것·②레인과 함께 넓힐 것): 유파·경지·전설의 물건·신화 속 권능에도 에오라 말 이름을 줄 수 있다(예: 마엔의 안개, 베사의 물기둥에 옛말 이름). 단 **매커니즘 판정은 힘의_구조가, 이름은 여기가** — 두 층을 섞지 않는다. 파수/비상/온실/사무실(임시 placeholder)에는 이름을 주지 않는다.

## §5. 쓰는 법 (글에서)

- **첫 등장 때 병기:** "삼각주의 **마레스 왕가**(옛 물의 집)" 또는 "**켈두르** — 첫 성벽 도시" 처럼 고유명 + 정체/뜻을 한 번 붙인다. 이후엔 고유명만.
- **묘사 이름은 어원·별명으로 산다:** '물의 집'은 마레스의 뜻이자 옛 별명으로 남는다(버리지 않음).
- **작은 것엔 억지로 고유명 붙이지 않는다**(§0 위계).
- 새 큰 도시·나라가 생기면 이 표에 한 줄 추가하고, §2 조각으로 짓는다.
