## 3-0. 분류 + 논리 구멍 메우기
- **두 종류:** **기록 유물**(글·진실+거짓 섞임) / **능력 유물**(실제 권능이 깃든 물건).
- ★**구멍 ① 왜 능력 유물이 봉인 아래서도 작동하나:** 봉인은 *사람(능력자)의 현실 발현*을 겨냥해 막는다 — 표적이 *자아를 가진 세포*라서. 물건은 자아가 없어 재흡수 압력의 표적 방식이 다르다. 신들의 시대에 *반신이 만지거나 만든* 물건은 내부의 성질을 머금은 채 굳었고, 봉인은 그 *굳은 잔류*까지 일일이 못 지운다(사람을 겨눈 그물이라). 단 봉인이 짓눌러 *옛 위력의 그림자만* 남는다.
- ★**구멍 ② 왜 안 흔한가:** 능력 유물은 *신들의 시대 산물*이라 새로 못 만든다(봉인 후 반신화도 막혀 새 권능 물건이 안 생김). 검은 물·마녀사냥의 불로 대부분 소실 → 남은 건 손에 꼽음(밸런스 락).
- ★**구멍 ③ 왜 세상을 안 뒤엎나:** 봉인이 위력을 그림자로 눌러 능력 유물도 *그 자체로 판을 못 엎는다*(첩보·국소 효과 수준). 판을 엎을 위력=잠든 자 곁 *신들의 시대 잔재*뿐=sequel.
- ★**구멍 ④ 왜 기록은 안 사라지나(흔적0%인데):** 흔적0%는 *권능의 흔적*을 거두는 것이지 *종이·돌*을 지우는 게 아니다(범속한 물질은 그대로). 그래서 기록은 평범하게 닳고 타고 위조된다 — 검은 물·마녀사냥에 *물리적으로* 소실됐을 뿐.
- ★**구멍 ⑤ 진본/위조 어떻게 가리나:** 기록은 *못 가린다*(재의 서판 이래 진실조차 파편·작화). 그래서 진본 다툼이 끝없고, 능력 유물 「진짜 비록」만이 *물질적 시금석*(가문 진위에 한해).

## 3-A. 기록 유물 — 실제 내용 (시대순)
> 각 기록이 *무엇을 사실이라 적었나* + *지금 우리가 아는 진실/왜곡.*

### 제1시대
- **「재의 서판」**(돌·파편) — *적힌 내용:* 검은 물이 위에서 덮쳐 사람이 손끝부터 풀림 / 단단한 자만 생존 / 신은 노하지 않고 '제 몸 긁듯' 거뒀다(무심) / 강한 자들이 억제·초월로 갈려 세상을 찢고 '천장'이 내려옴(봉인). ★**논리(작화):** 증인이 검은 물에 *절반 녹았고*, 살아남은 마음이 빈 기억을 *제멋대로 메움*→메워진 기억과 진짜를 *구별 못 함*→"절반은 거짓이나 참이라 믿고 적었다"(거짓말 아닌 손상된 기억의 정직한 경고). **깨져 셋이 나눠 쥠** → 정통/초월/온실이 각자 유리한 조각만 읽음.

### 제2시대
- **「신들의 노래」**(경전군) — *적힌 내용:* 강을 다스리는 이가 가뭄을 물리고 도시를 잠금(반신 권능) / 괴물을 벤 이가 인간의 아들이나 늙지 않고 상처가 아물어 죽지 않고 '멀리 떠나 돌아온다 했다'. *진실:* '신'은 다 옛 반신/강한 각성자(기제만 틀린 진실). '돌아온다'=초월 메시아주의의 가장 오래된 메아리, '멀리 떠남'=사망=실종+잠든 자 화석.
- **「첫 등록부」**(명부) — *적힌 내용:* 각성자의 깨어난 자리·때·모양(불·물·멈춤·헛것) + 처분 한 글자(거둘/벨) + "이 한 글자가 우리를 둘로 찢으리라"는 자기예언. *진실:* 현대 명단 관리의 원형. 「재의 배신」으로 적에게 넘어가 내부 숙청 광기를 부름.
- **「계보 비록」**(가문 족보·이후 계속) — *적힌 내용:* 초대를 신격 조상으로 + *닮은 아이*(잠결에 공기를 멈추고 늙지 않으려 하고 비록을 두려워 않는)를 알아보는 법 + "셋 이어 닮은 아이 없으면 초대를 잊은 것=위선=곧 죽는다." *진실:* 일부 진짜·대부분 위선. 망실 가문의 경고가 새겨짐.

### 제3시대
- **「이단 명부」**(정통 기록) — *적힌 내용:* 솎은 자들의 이름·죄(죄목 하나=권능을 쌓았음) + 골짜기 컬링 정당화("둑 쌓아 홍수 막고 비가 적었다 말하는 격"). *진실:* 증명 못 할 위협을 막았다는 믿음으로 증명되는 동족을 죽인 자기변호=파수의 영혼.
- **「금서」**(능력 유물도 됨·3-B) — *적힌 내용:* 봉인을 깨고 반신 되는 길의 지도(약속이 아니라 지도), 각 문에서 누가 어디서 녹았나(실패담), "마지막 문은 적지 않는다, 거기서 신이 되거나 흩어진다." *진실:* 피로 쓴 불가능의 지도.
- **「귀의의 서」** — *적힌 내용:* 두려움은 아직 네가 너이기 때문 / 검은 물은 부름(귀가)이니 돌아가라 / 이름이 입에 설어지면 문 앞, 뒤돌아보는 자만 돌이 됨. **두 판본:** 창시자 최후를 온실은 승천, 회의자는 '첫 번째로 녹으심(소멸)'으로.
- **「봉인된 지도」** — *적힌 내용:* 잠든 자 위치 + 가지·파지·부르지·깨우지 마라 / 가장 늙은 「잠든 왕」 자리는 표시 안 함 / **공백 한 곳**(「깨움」이 지운 도시). **위조본 셋**이 추적자를 엇갈리게.
- **「두 손의 편지」** — *적힌 내용:* 적 진영 연인이 서로의 진영이 *둘 다 옳고 둘 다 틀렸음*을 적음("한 편이 이기면 그 편의 절반의 거짓이 세상의 전부가 된다"). *진실:* 양쪽 모두에게 위험(절대성을 무너뜨림). 누구 손이냐로 원한/화해 갈림.

### 제4시대
- **「화형 명부」** — *적힌 내용:* ○진짜 일곱 / ×무고 사백+ / ?셀 수 없음 + "일곱 중 셋은 구할 수 있었으나 구하지 않았다." *진실:* 진짜는 거의 안 타고 무고가 압도적으로 탐, 세력이 동족 일부를 버려 살아남음=폭로파 성배·세력 치부.
- **「재건의 협약문」**(MAD 헌장) — *적힌 내용:* 화해·용서·사랑 아니다 다만 서로 안 죽인다 / 제1조 폭로 금지 / 제2조 신의 아닌 두려움(서로 인질) / 제3조 깨지면 셋 다 끝. **현대 갱신본:** 본문 불변·각주만 기업 언어("개정 논의 자체가 균형을 흔든다").
- **「소실의 목록」** — *적힌 내용:* 잃은 줄 *아는* 것만(등록부 절반·계보 비록 다수·금서·너무 많은 이름) + "잃은 줄도 모르는 건 못 적어 이 목록은 손실보다 작다." **마지막 빈 장**=잃은 줄도 모르는 것들의 자리(영영 못 채움).

### 제5시대
- **「실종 장부」** — *적힌 내용:* 진짜 실종 통계, 한 지역 실종↑면 셋 중 하나((一)각성 (二)컬링 (三)적지 않는 정화 전조) + "셋이 동시에 떨면 위를 보라." **셋째 칸 메모:** 전 지구가 아닌 *한 점*의 가속(=등대=유리)을 '넷째 칸이 필요한가'로 첫 직감.
- **「프런트 등기부」** — *적힌 내용:* 재단·경비·행정=파수 / 코칭·연구소=비상 / 상담·요양·영성=온실 + "어디에도 안 적힌 작은 사무소(사무실)는 이 모두를 안다." **사무실 비공식본:** 제 자신만 안 적음(방패).
- **「폭로 미수 파일」** — *적힌 내용:* 한 기자를 해치지 않고 *틀린 사람으로 만듦* / 위험한 사진은 음모론자 수집품에 둠('진실은 미친 자의 손에 가장 안전') + "덮은 자는 포기 못 하는 손에 남아 폭로파로 자란다."
- **역정보전 가짜 문서들** — 가짜 등기부(둘을 부딪치게)·과장된 화형 명부(진짜를 음모론에 묻기)·위조 두 손의 편지(가문 앙금 덧내기). *진짜 아흔아홉 줄에 가짜 한 줄.*

## 3-B. 능력 유물 — 무슨 권능 (극소수·미약·대가)
- **「첫 칼」**(제1시대) — 첫 칼이 동족을 벤 칼(검은 물 증인의 손). **권능:** 이 칼이 낸 상처만은 *흔적0% 복구가 반 박자 늦다* = 흔적 없는 세계에서 유일하게 *증거를 남기는* 무기(평범 위장 살인의 천적·증발도 막음). **대가/한계:** 한 번 베면 칼이 *식어* 한동안 못 씀, 소지 자체가 표적. **누가:** 파수가 성유물로 *봉인*(증거 남는 칼=비닉의 적) / 폭로파가 탐냄.
- **「잎맥지」** — 온실 포교 도구. **권능:** 지친 마음에 *귀가 본능(합일 부름)*을 미약하게 증폭, *이미 기운 자만 더 기욺*(자아 단단한 자에겐 무력=하준 면역). **왜 안 막히나:** 종이에 죄를 못 묻고 효과가 자연스러운 우울/탈진으로 보임 → 온실이 물건 하나로 천 명을 거두는 핵.
- **「진본 금서」** — 사다리를 든 자(반신 후보) 친저. **권능:** 읽는 자를 결정화의 길로 *끌어당기는* 미약한 유혹(대부분 무리하다 녹음). **「틀린 사본」**은 유혹 없이 *길만 틀리게*(다정한 거짓이 더 많이 죽임) → "금서는 미신" 소문이 사는 이유. **누가:** 비상의 성배 / 파수는 불태우려. 실물 행방불명.
- **「진짜 계보 비록」** — 진짜 반신 초대가 손댄 족보. **권능:** *닮은 아이(진짜 후예)*가 펼치면 미약하게 반응(데움·떨림), 위선의 것은 죽은 종이 = 진짜/위선을 가리는 *유일한 물질적 시금석.* **왜 중요:** 마녀사냥 때 비록 다수 소실로 *누가 진짜 핏줄인지 글로는 못 가림* → 반응하는 비록 하나가 *망실 가문(소가) 정체*를 깨우는 열쇠.
- **(sequel 떡밥) 신들의 시대 잔재** — 봉인 *전* 위력을 더 머금은 물건(반신이 *만든* 것). 잠든 자 곁·지도 공백에 묻힘. 1편엔 소문·이상현상으로만(한 물건이 곁의 시간을 머금는다거나). 후속작 게이트.

## 3-D. 유물 현재 소재 — 누가 쥐었나 (탈취·추적 서브플롯의 토대)
> 어느 유물이 *지금 누구 손에* 있나. 빈 자리(행방불명·미발견)가 곧 본편 사건의 추격 동선.

| 유물 | 현재 소재 | 비고(드라마) |
|---|---|---|
| 재의 서판(3조각) | 정통/초월/온실이 각 조각 = 현대 파수·비상·온실이 한 조각씩 | 세 조각을 다시 맞추는 자=진실에 가장 가까이/셋 다의 거짓을 봄 |
| 신들의 노래 | 널리 퍼진 경전(공개 신화) | 일반엔 신화로, 진실 해석은 세력이 통제 |
| 첫 등록부 | 진본 절반 소실(소실의 목록), 파수가 현대 데이터로 계승 | 명단 관리의 뿌리 |
| 이단 명부 | 파수 보관 | 정통의 자기변호=치부이기도 |
| **금서(진본·능력유물)** | **행방불명**(불의 세대에 탔는지 빼돌렸는지) | 비상이 총력 추적·파수는 불태우려=1편 엔진 |
| 귀의의 서(두 판본) | 온실 보유(승천 정본) / 이본=어딘가 여백 | 이본 발견=온실 신앙 흔들림 |
| **봉인된 지도(진본)** | 파수가 원본 지키려 / **위조본 셋 떠돎** | 잠든 자 추적자를 엇갈리게 |
| **화형 명부** | 소재 미상 | 폭로파의 성배(찾으면 세력 치부 폭로) |
| 재건의 협약문 | 세 세력 공유(MAD 헌장)+현대 갱신본 | 고치려는 손이 균형을 흔듦 |
| 실종 장부 | 세 세력 각자 운용+서로 훔쳐봄 / 사무실·폭로파가 되모음 | 셋째 칸=정화 전조 첩보전 |
| 프런트 등기부 | 세력별 보유 + **사무실 비공식본** | 위조전의 핵 |
| 폭로 미수 파일 | 세력(비닉 담당) 보유 | 폭로파 손에 들면 '무엇을 덮었나' 지도 |
| **두 손의 편지(반쪽씩)** | 진(陳)가·하(河)가가 반쪽씩 | 합쳐지면 원한이 사랑이었음 |
| 계보 비록 | 각 가문이 흩어 보유(다수 망실) | 유(柳)가 조각은 셋으로 흩어짐 |
| **첫 칼(능력유물)** | 파수가 성유물로 **봉인**(쓰기보다 가둠) | 증거 남는 칼=비닉의 적·폭로파가 탐냄 |
| **잎맥지(능력유물)** | 온실이 포교에 *유통 중* | 물건 하나로 천 명을 거두는 핵 |
| **진짜 계보 비록(능력유물)** | **미발견**(소가의 것=망실, 어딘가) | 발견=망실 가문 정체 깨움 |

★**빈 자리=추격 동선:** 금서(행방불명)·화형 명부(미상)·진짜 비록(미발견)이 *본편 사건의 세 추격선.* 세력·가문·사무실·폭로파가 각자 이 빈 자리를 좇는다.

## 3-C. 연계
- 첫 칼→증거(1)·파수(5) / 잎맥지→온실(5) / 금서→비상·반신화(2·5) / 진짜 비록→가문 진위(4).
- 재의 서판 작화 = 잠든 자(7) 검은 물 증인의 반쯤 녹은 기억과 같은 결.
- 기록=세력(5)이 좇는 성배·인질(협약문·등기부·명부). *탈취·위조·은닉*이 본편 사건(1)의 씨앗.
