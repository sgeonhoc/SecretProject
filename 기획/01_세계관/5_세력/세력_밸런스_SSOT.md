# ⚖️ 세력 · 전력 밸런스 SSOT (Single Source of Truth)

> **역할 분담(2026-06-19):** 스토리 집필 = 사용자(+제미나이). **세력/설정 정합성·밸런스 = Claude(이 문서).**
> **목적:** 스토리 쓸 때 바로 꺼내 쓰는 *논리적·허점 없는·밸런스 맞는* 세력/전력 레퍼런스.
> **권위 순서(충돌 시):** ① 사용자 확정 > ② 메타피직스 캐논(`gen_lore.js` doc 10~210) > ③ **이미 쓰인 원고(`_fa_sync/원고/`)** > ④ 설계 다이제스트(doc 400~) > ⑤ 브레인스토밍 더미.
> ⚠️ 메타피직스(세계맥/권능/대가/반신 등 doc 10~210)는 **건드리지 않음.** 이 문서는 그 위에 얹힌 *세력·전력·밸런스* 레이어만 정리/수선한다.

## 1. 전력 티어 사다리 (Power Ladder) — *절대 흔들지 말 것*

> 두 무대(현실 / 고립계)에서 같은 존재의 강함이 **다르다.** 이게 밸런스의 척추.

| 티어 | 존재 | 현실(평형) | 고립계(교란) | 비고 |
|---|---|---|---|---|
| T0 | **일반인** | 안전(채널 분리, 직접 권능 면역) | 진입 불가(끌려들어오면 약자=실종 위험) | 무대·표면 |
| T1 | **인간 측(사냥꾼/인간 팔/컬트)** | 약~중(자금·정보·폭력은 있음) | **진입 불가**(맹목) | 신/세력 후원 없으면 약함 |
| T2 | **능력자(약 자질)** | 무력(칼·총·독·경찰에 죽음) | 약(누출 수준) | 대부분 졸·자산 |
| T3 | **능력자(중 자질)** | 무력 | 중(표준 전투원) | party·행동대 주력 |
| T4 | **능력자(강 자질)** | 무력 | 강(에이스). 결정화 *후보* | 세력 간부·숙적·세린·한별급 |
| T5 | **텅 빈 고위 각성자(숙적)** | 무력 | 강+(불안정). **party 격파 가능** | 결정화 실패자. 인간 스케일. 격파=해방 |
| T6 | **폭주 승천자** | 준-신(미완) | 반신 미만·능력자 초과(메테오급이나 incoherent) | party가 깎음 → **유리 erase로 마무리**(Arc5 dread) |
| T7 | **반신(일반)** | **무적**(예외 티어) | 신급 | 현실 거주·개입 싫어함·개별 |
| T8 | **유리(apex 반신)** | 무적 | 신급 최상위(활동 반신 중 최강) | **밸런스는 힘이 아니라 '자제'로 잡힘**(§3) |
| T9? | **고대 잠든 존재** | (잠듦) | raw로 T8 초과 가능하나 **통제·소통 불가** | **1편엔 미각성**(깨우면 sequel급 재앙). 깨우기=컬트 떡밥 |

**불변 규칙(캐논 doc 110/154/184):**
- 능력자는 **현실에서 무력**. 반신만 현실 무적(유일 예외).
- **원거리 권능 불가** — 반드시 현실 같은 좌표 대면 후 고립계.
- **강제각성(일반인 끌어들이기)=정점/반신만**, 자질 낮으면 실패=실종. → 능력자 **대량생산 불가**(희소성 락). 세력은 *만드는 게 아니라 모은다*.

## 2. 세력 로스터 (여명시 1편 무대) — *2축 전력 + 누가 있나*

> ★ **2축 분리 점검(핵심 밸런싱 도구):** 세력의 힘 = ①**현실 권력**(인간 팔·자금·프런트·정보전) + ②**고립계 전력**(능력자 수·강함·반신 후원). 한 세력이 *양축 모두 1위면 OP* → 의도적으로 엇갈리게 배분함.

### 6 가치축 → 여명시 세력 매핑 (H1 해소)
- 유지/보존 → **파수** · 권능확장 → **비상** · 합일/초월 → **온실** · 탐구/관측+상부상조 → **사무실(조사진영)** · 폭로/해방 → **군소 NPC** · 신앙 → **군소 NPC(온실에 일부 흡수)** · 지배/세계변환 → *1편 무대엔 미등장*(세계 스케일·sequel, 비상의 극단 분파로만 암시)

---

### A. 파수 (수호 / 유지·보존)
- **가치:** "노출=마녀사냥 재발=공멸. 비닉 절대 유지, 일반인 보호." 가장 오래된 결사.
- **현실 권력 ★★★★☆ (1위):** 클리닉·언론·기록·학계 침투. 흔적0%를 *사회 시스템으로* 운영(실종을 가출·돌연사로 분류). 컬링(비닉 위반 신참 처리).
- **고립계 전력 ★★★☆☆:** 조직화된 색출조. 강하지만 *자제*가 교리라 화력보다 통제·은폐 중심.
- **누가:** 클리닉 원장(프런트 수장), 컬링 집행관(중~강 자질), 등록·감시 요원. 내부 **강경파↔온건파 분열**(드라마 광맥).
- **약점:** 관료적·자제 교리 → 기민함 부족. 강경파의 과잉 컬링이 다른 세력에 명분 줌. **"가장 선해 보이는 악역."**
- **MC와:** Arc1 첫 케이스 배후 = 파수 클리닉 컬링. 영입/등록 압박(원고 EP14).

### B. 비상 (확장파 / 권능 추구)
- **가치:** "더 멀리·더 깊이 끌어 쓰는 게 옳다. 한계를 넘어라." 비닉엔 느슨(들켜도 힘으로).
- **현실 권력 ★★☆☆☆:** 신흥. 코칭모임·자기계발 프런트. 제도 뿌리 얕음.
- **고립계 전력 ★★★★☆ (1위):** 공격적 강자 다수. 한계 돌파(초월)를 장려 → *무리한 반신화 시도로 흡수=소멸·폭주 자멸이 잦음(사람이 빨리 빠짐).* 능력 사용 자체의 노화가 아니라 *초월 도박의 대가.* 지도자가 **반신화 시도 → 실패 → 폭주 승천자**(T6, Arc5 절정 위협).
- **누가:** 야심 간부들, 한계까지 간 에이스(세린 = 비상 소속·상승), 반신화 도전한 지도자.
- **약점:** 빠른 침식 = 인적자원 소모율 높음(강한데 망가짐). 현실 권력 약 → 파수의 사회적 매장에 취약. 무리=폭주 자멸.
- **MC와:** 세린 통한 은근한 손짓(원고 EP02,10). "그쪽 끝"의 공포 시연 = MC의 결정화 동기 강화.

### C. 온실 (합일/초월 컬트) ★H3로 재정의
- **가치:** "무거운 자아를 내려놓으면 평온하다. 세계맥과 하나 됨이 구원." = **자아 침식(흡수)을 *평온*으로 포장한 죽음-컬트.** (캐논 초월=흡수=소멸과 정합. 원고의 잎맥/온실 그대로.)
- **현실 권력 ★★☆☆☆:** 식물원·요양 프런트. 강요 안 함 — **지친 자를 자발적으로 걸어 들어오게**(세력 다툼·도시 흔들림이 지친 자를 양산 → 온실이 수확). 가장 음험한 포교.
- **고립계 전력 ☆~★★★★★ (비대칭):** 구성원이 자아를 비울수록 *개인은* 신급에 근접(합일 직전=기능적 반신급)하나 **incoherent·통제불가·곧 소멸(실종).** 안정적 전력은 낮고 **천장만 비정상적으로 높은 블랙박스.** 협상 상대가 안 됨.
- **누가:** 단정한 포교자(EP07,24), 이미 비워진 평온한 신도들(껍데기), 합일 직전의 이질적 고참.
- **약점:** 구성원이 *유지가 안 됨*(비울수록 소멸). 지속 조직력이 약함. 자아 강한 자는 안 넘어감.
- **MC와:** 한별이 솔깃했다 거부(EP11). 다경 친구가 유혹받음(EP24). MC는 "비우지 않고 단단해진 결정화"라 **온실의 안티테제** = 주제적 대척점.

### D. 사무실 / 조사진영 (탐구·관측 + 상부상조) ★H4로 정식화
- **가치:** "이해하고, 살아남고, 손 닿는 사람을 지킨다." 거대 세력 틈의 약자. = 브레인스토밍 「제3관측소/검시」 = **느와르 주인공의 집.**
- **현실 권력 ★☆☆☆☆:** 작은 사무실. 자금·인맥 빈약(파수가 "너희는 못 지킨다" 압박, EP14 = 사실).
- **고립계 전력 ★★☆☆☆:** 소수정예. 윤아(멘토·베테랑), 한별(강하나 침식 중=T4→T5 경계), 민서(온기·중자질), **하준(결정화=잃지 않는 단단함=특수 전력).** 수는 적으나 **MC의 천연 포렌식(흔적 판독)**으로 정보전에서 한 방.
- **약점:** 절대 규모 열세. 침식·소모를 버틸 보충 인력 없음.
- **MC와:** **홈 베이스.** 모든 돌봄 아크(다경·한별·세린 귀환)의 무대. = 상부상조 가치의 진짜 담지자.

### E. apex 반신 — 유리 (T8, 세력 없음·독립)
- **가치:** 세상엔 심드렁. 동기 = MC를 '내 걸로 키운다'(호기심·소유욕→연심). **세력에 안 속함**(독불장군).
- **전력:** 양 무대 무적. 위협을 소리 없이 erase. **단 §3의 자제 규칙으로 밸런스됨.**
- **다른 반신:** 대체로 불간섭(무관심파). **상시 라이벌 신 없음**(라이벌 반신 폐기=갱신#1). 유리만 적극 개입 = 고독·특별.

### F. 군소 / 인간 측 (NPC·프런트)
- **폭로/해방:** 비닉을 깨려는 와일드카드 셀. 모두의 적(폭로=공멸) → 등장 시 임시 반(反)폭로 연대. NPC·정보원 규모.
- **신앙:** 세계맥 숭배 신흥종교. 온실과 일부 겹침. 영입 풀.
- **인간 사냥꾼:** 각성자 제거 시도. **고립계 진입 불가=기본 약체.** 강하면 *어느 신/세력의 부인가능 대리인.*
- **유리의 하수인(가정부):** 양육 감시·환경 관리. 미세 'off'(부모 화제 회피)=L4 단서원.

## 3. ★밸런스가 안 무너지는 이유 (왜 아무도 OP가 아닌가) — 검증

> 강력한 존재가 있어도 긴장이 죽지 않는 *기계적 잠금*들. 스토리에서 이걸 어기면 밸런스 붕괴.

1. **유리(T8)가 항상 옆에 있는데 왜 MC가 위험한가?**
   - **위험 안 감수 + 아껴 씀 + 노출 비용.** 유리가 erase하면 *다른 반신·세력에 손패가 노출*됨(doc 440). 그래서 **결정적 순간에만, 드물게.** → 평소 위협은 MC가 자력으로 감당해야 함.
   - **하드 룰(스토리용):** 유리는 ①MC *생명*이 확정적으로 끝나는 순간에만 개입, ②개입하면 그 대가로 *판이 시끄러워짐*(추격·의심 증가). → 매 위기를 유리가 풀면 안 됨. *대부분의 위기 = party가 푼다.*

2. **비상이 능력자를 못 찍어낸다** — 강제각성=정점/반신만+실패율↑(doc 110/204). → 어떤 세력도 군대를 양산 못 함. **희소성=밸런스 락.** 여명시 능력자 급증은 *유리의 작업+node(등대 효과)*이지 세력의 생산이 아님.

3. **2축 엇갈림(§2):** 파수=현실 1위·고립계 3위 / 비상=고립계 1위·현실 4위 / 온실=천장만 높고 지속 0 / 사무실=양축 약하나 정보 한 방. **양축 동시 1위가 없음** → 어느 세력도 단독 제패 불가(doc 182 구조적 제약: 영구·총체·공개 승자 불가).

4. **반신끼리도 현실에선 서로 못 침**(둘 다 무적) → 반드시 고립계에서. 그래서 유리도 *함부로 다 못 쓸어버림*(상대를 고립계로 끌어들여야=품·노출). 신들의 전쟁이 **냉전**으로 유지(MAD=상호확증 침묵).

5. **숙적·폭주체는 신이 아님**(T5·T6) → **party가 실제로 이긴다**(주인공 행위주체성 보존). 진짜 신(T7+)은 *싸우는 게 아니라 피하거나 유리가 처리.* → "이길 수 있는 적"과 "이길 수 없는 존재"가 티어로 분리.

## 8. 여명시 1편 — 세력 수싸움 동학 (전략 밸런스) — 2026-06-25 [B]

> §2~5가 *정적 전력*(누가 얼마나 세나)이라면, 여기는 *동적 균형*(왜 안 끝나나·무엇이 깨나·각자 어떻게 이기고 지나). 제미나이가 세력전 비트를 *임의가 아니라 전략에서* 짜도록. ★4파전은 *체스가 아니라 포커* — 패를 숨기고, 부정 가능하게, 공멸을 피하며 미는 수싸움.

### 8-0. 판이 안 끝나는 구조 (균형의 바닥)
- **MAD(재건의 협약):** 공개전 = 노출 = 마녀사냥 재발 = *공멸.* → 모든 수는 *부정 가능한 그림자 수*(진단·분류·사고처리·포섭·유혹). 드러내 죽이면 제가 탄다.
- **양축 동시 1위 없음:** 현실 1위=파수 / 고립계 1위=비상 → 단독 제패 불가(구조적 락 §3-3).
- **그래서 평형.** 단 여명시 = *급증(자원 폭증)*으로 평형이 **과열** — 안 끝나되 뜨거워진다.

### 8-1. 각 세력의 전략 좌표 (강축·자원·시간)
| 세력 | 강축 | 자원 | 시간은 누구 편 | 그래서 성향 |
|---|---|---|---|---|
| **파수** | 현실 | 제도·안정 인력(다세대 축적) | **파수 편**(오래 살수록 쌓임) | *급할 게 없다.* 천천히 조이고 덮는다 |
| **비상** | 고립계 | raw 화력(but 소모율↑·빨리 침식) | **적**(아끼면 녹슬고 쓰면 망가짐) | *급하다.* 기회 보면 들이받는다 |
| **온실** | 천장만(안정 0) | 지친 자 throughput | **다툼이 길수록 편**(남 싸움에 기생) | *기다린다.* 남들이 지치게 둔다 |
| **사무실** | 없음(정보 한 방) | 앎·인연 | 중립(생존이 곧 시간 벌기) | *피한다.* 좁은 골목·정보로 국지 |

### 8-2. 승리 조건 / 실패 모드 (각 세력이 어떻게 이기고 지나)
- **파수** — WIN: 급증을 *조용히* 흡수·등록·컬링해 평형 복원(아무 일 없던 듯). LOSE: **강경파 과잉 컬링**이 다른 세력에 명분 주고 폭로 위험 키움(「헛된 경보」의 그림자). 내부 강경↔온건 분열로 자가마비.
- **비상** — WIN: 급증 각성자 포섭+결정화 성공으로 고립계 압도. LOSE: 무리한 한계돌파 → **폭주 자멸(T6)** + 현실 권력 약해 파수에 사회적 매장.
- **온실** — WIN: 다툼이 길어져 *지친 자 대량 수확.* LOSE: 안정전력 0이라 직접 충돌엔 무력 + *평온=소멸* 들키면 신뢰 붕괴.
- **사무실** — WIN: 손 닿는 사람 지키며 생존, 정보로 국지 한 방. LOSE: 표적이 되거나 인력 소진(보충 0).
- ★*아무도 "전부 이김"이 없다* — 각자의 win이 *부분적·일시적*이라 판이 계속 돈다.

### 8-3. 에스컬레이션 사다리 (냉전 → 어디까지 뜨거워지나)
1. **평소(0단):** 부정 가능한 그림자 수 — 진단/분류/포섭/유혹. 표면은 클리닉·모임·요양원 간 *평범한* 분쟁.
2. **1단 — 자원 쟁탈:** 급증 각성자(누가 먼저 등록/포섭/유혹)를 두고 *그림자 살인·가로채기.*
3. **2단 — 과잉이 균형 깸:** 한 세력의 *과잉*(파수 강경 컬링 / 비상 폭주)이 선을 넘음 → 보복 연쇄. **사건의 진짜 방아쇠 = 늘 '과잉'.**
4. **3단 — 리셋 버튼:** **폭로파 출현** = 공멸 위협 → *전 세력 임시 연대*(반폭로). 적이 잠깐 같은 편.
5. **천장(1편 락):** 협약이 *끝까지 당겨지되 1편엔 안 끊김.* 끊기면 = 공개전 = 공멸 = **후속작 스케일**(1편 밖).

### 8-4. 유리/등대라는 외란 (셈 밖 변수 · ★노리빌 표면 0%)
- **급증의 진짜 원인 = 유리(등대).** 세력은 *원인을 모른다* → 천 년 기질 그대로 그 우물로 빨려든다.
- **균형 교란:** 자원(각성자)이 *예상보다 많이* 솟아 평형 과열. 파수는 '검은물 전조?'로 *오해해 패닉 컬링*할 수도, 비상은 '수확철'로 *과욕*할 수도 — **오해가 사건을 만든다.**
- **유리는 판에 직접 안 나선다(자제룰 §3-1):** 생명/도시 실존 위협에만 개입. → 세력전은 *세력끼리* 굴러간다(유리가 매번 풀면 긴장 사망).
- **하준 = 셈에 안 든 결정화 신참 = 4파전의 국소 초점:** 세 세력이 각자 노림(파수 등록 / 비상 포섭 / 온실 유혹), 사무실이 지킴. 거대 동학이 *한 아이*로 수렴하는 지점. (하준·유리 카메라는 0 — 세력 시점에선 '왜인지 모를 끌림'으로만.)

### 8-5. 제미나이 집필 룰 (이 동학으로 비트 짤 때)
1. **모든 세력 수는 전략 좌표에서 도출** — 파수=천천히 조임 / 비상=급해서 들이받음 / 온실=남 싸움에 기생 / 사무실=회피·정보. *성격이 아니라 전략이 행동을 정함.*
2. **균형을 깨는 건 '과잉'** — 강경 컬링·비상 폭주·폭로파. 이게 사건의 방아쇠(8-3의 2·3단).
3. **유리는 판을 안 푼다** — 위기는 party/세력이 푼다. 유리 개입=확정 죽음/도시 위협만, 그것도 *판이 시끄러워지는 대가.*
4. **승부는 무대 선택**(§5) — 강자도 불리한 무대로 끌리면 진다.
5. **폭로파 = 공동의 적**(리셋 버튼) — 쓰면 전 세력 일시 연대.

### 8-6. 흔들기 레버 × 방어선 (드라마가 어디를 누르나)
> 사건을 짤 때 "이 사건이 어느 세력의 *어디*를 찌르나"를 고르는 표. 레버=눌러서 흔드는 약점(드라마 진입점) / 방어선=정면으론 못 깨는 강점(여기로 치면 헛수고).

| 세력 | 흔들기 레버(여기를 누른다) | 방어선(여기론 못 깬다) |
|---|---|---|
| **파수** | 내부 **강경↔온건 분열** · 과잉 컬링의 *폭로 위험* · "또 헛되이 솎는가"(헛된 경보 트라우마) | 제도·여론·기록 장악 — *현실에선 정면으로 못 건드림* |
| **비상** | **대가 소모(시간)** · 폭주 유도(무리시키면 자멸) · 현실 권력 약 → *사회적 매장* | 고립계 정면 화력 — *맞붙으면 못 이김* |
| **온실** | **"평온=소멸" 폭로 시 신뢰 붕괴** · 자아 단단한 표적엔 무력(MC=안티테제) | *막을 명분이 없음*(자발적이라 컬링 정당화 불가) |
| **사무실** | **표적화·인력 소진**(보충 0) · 정보원/은신처 노출 | 작아서 *안 보임* + 천연 포렌식 *정보 한 방* |

- **활용:** 적대 사건은 *레버*를 누르게(파수 강경파 폭주를 비상이 명분 삼기 / 온실의 소멸 진실을 사무실이 쥐기). *방어선*을 정면으로 치는 전개는 비논리(파수를 현실에서 이기려 들거나, 비상을 고립계 화력으로 누르려는 등)—피할 것.
- ★MC(사무실·결정화)가 **온실의 정확한 안티테제**(비움 vs 지킴)라, 온실 레버를 누르는 주체로 가장 자연스럽다.
