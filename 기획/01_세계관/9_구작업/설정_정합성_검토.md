## 5. ★★교차 충돌 — 원고 · 설계 · 캐논 세 층 (제일 큰 문제)

> 내가(AI) 만든 두 산출물(`원고/`·`story_design.md`)이 사용자 캐논(메모리·gen_lore 락)과 *이름·핵심 개념*에서 충돌. 이벤트 흐름 짜기 전 반드시 통일해야 함.

### 🟥 C1 — 인물 이름 3중 불일치 (가장 시급)
| 역할 | 사용자 캐논(메모리·원고) | story_design 가제 | 락 권장 |
|---|---|---|---|
| 멘토/가이드 | **윤아** | 선우 | **윤아** |
| 절친(decoy) | **다경** | 도경 | **다경** |
| 야심가(배신) | **세린**(야심→비상 이탈) | 재혁 | **세린** |
| 경계자 | 한별 | 한별 | 한별 ✅ |
| 온기 | 민서 | 민서 | 민서 ✅ |
| MC / 히로인 / 도시 | 하준 / 유리 / 여명시 | 동일 | ✅ |
- → **story_design·gen_lore 400번대의 선우·도경·재혁을 윤아·다경·세린으로 일괄 치환.**
- 부수 효과: 🔴 **재혁(남성형 이름) vs "캐스트 전원 여성·하준만 남성" 규칙 충돌** → 세린으로 치환하면 자동 해소(세린=여성).

### 🟥 C2 — "결정화"의 위치·무게가 정반대
- **원고:** MC가 **1막 끝(EP15)에 이미 결정화** → 2막은 "결정화 후" 이야기. 원고의 결정화 = "잃지 않고 단단해짐" 정도(여전히 평범한 고등학생·약소 전력).
- **설계/캐논:** 결정화 = **반신 승격 = Arc6 최종 게이트(엔딩).** 게임 전체의 종착점.
- → **같은 단어, 완전히 다른 위치(초반 vs 엔딩)와 무게(각성 안정 vs 반신화).** 🟥 정면 충돌.
- **권장 락:** 캐논(결정화=반신화=엔딩 게이트)을 채택. **원고의 1막-결정화는 폐기**(어차피 원고는 AI 초안이고 사용자가 흐름을 새로 짤 것). 원고가 1막에서 표현한 "자아 안정화"가 필요하면 → 별도 용어(예: *각성 정착 / 자아 정위*)로 분리, "결정화"는 엔딩 전용.

### 🟥 C3 — 사망 결과 캐논 드리프트
- **구 `../4_체계/세계관_설정.md` §7:** 능력자가 고립계서 죽으면 **시신이 현실로 이월 = '돌연사'**(시신 있음) / 끌려온 일반인만 증발.
- **신 `gen_lore.js`(락) doc 50·79:** **모든 고립계 사망 = 실종(증발), 시신 0.**
- → 🟥 충돌(시신 있음 vs 없음). 수사·미스터리 질감이 달라짐(돌연사 시신=포렌식 단서 / 증발=완전 무).
- **권장 락:** 신 캐논(전부 증발=실종, 시신 없음) 채택 — 더 깔끔하고 "흔적0%"와 일관. 구 §7의 '돌연사 시신 이월'은 폐기. (단, 미스터리에 시신 단서를 쓰고 싶으면 §7 nuance를 살리는 선택도 가능 → 사용자 결정 D5.)

### ⚠️ C4 — 원고 2막 후반 세력/사건이 캐논과 안 맞을 수 있음
- 원고 EP06~40(온실·균열의 밤 등)은 내가 쓴 초안. 사용자가 흐름을 새로 짤 거라 **참고용/폐기 대상.** 캐논과 충돌하는 디테일은 새 흐름에서 정리됨. (지금 고칠 필요 없음, 새로 짤 때 이 검토서 기준 적용.)

### 사용자 결정 (2026-06-19 회신 반영)
- **D5. 사망 결과: ✅락 = 전부 증발(실종), 시신 0.** ★실은 *이미 락돼 있던 캐논*(gen_lore doc50·79). C3은 "결정"이 아니라 **옛 파일 잔재 청소**가 맞았음 → `../4_체계/세계관_설정.md §7`의 구버전("능력자=돌연사 시신") **폐기·수정 완료.**
- **D6. M8 기습 취약성: ⏸파킹 = 단련 정도에 따라 개인차 + 흐름 따라 결정.** 단일 룰로 못 박지 않음. **개인의 단련도가 높을수록 기습에도 비자발 누출로 방어 가능** / 낮으면 기습·수면·독에 그냥 죽음. 구체 경계는 *이벤트 흐름 짤 때 사건별로* 확정. (스펙트럼만 락, 수치는 유보.)
- **D7. S4 노리빌 근거: ✅방향 락 = 시크릿 플랏(이면) 전용.** 유리의 모든 개입은 **게임 중 비노출** → 별도 *플랏별 이면 해설(시크릿 플랏 = L4)*에만 정리. 이면이 허점 없으려면 "MC 육감이 왜 유리를 못 느끼나"의 이유 1개 필요 → **제안:** *유리가 MC 육감을 길러준 존재라, MC에겐 유리 기척이 '이상한 것'이 아니라 '태어날 때부터의 정상 배경'으로 등록됨(자기 집 냄새 못 맡듯).* ← 게임 비노출, 이면 문서 전용. (사용자 OK 확인 대기.)

### ★시크릿 플랏(이면) 구조 — 사용자 방침 채택
모든 사건 = **표면(MC·플레이어가 보는 것) + 이면(시크릿 플랏 = 유리/L4가 실제로 한 일).** FA의 `content`/`spoilerNotes` 분리와 일치. 이벤트 흐름 짤 때 사건마다 두 층을 함께 적는다. 게임엔 표면만, 이면은 설계 문서에만.

### 11-4. ⚠️ 열림 — 힘의구조 §5.5 위험④ 문구 낡음 (②레인 검토)
- "만 년 전 은폐 6형태부터 현대 비닉·프런트까지, 이 세계 은폐 문화 전체" — 07-07 골격 재편(억지 은폐/착취 폐기) 후 에오라 만 년은 **공개 계약·감정 명부·왕좌 능력자**의 역사가 됨. 위험④(노출·현실무력)는 *현대 표피* 전용 서술로 좁혀 적는 게 정합. 에오라와 현대 사이 어디서 무엇이 갈렸는지는 열린 물음(정하지 말 것).

## 12. ✅종결 — 에오라의 위치: 사용자 답변 접수 (2026-07-10 · 전 인스턴스 필독)
> 구 §12는 "두 계층 우주론(표피/내부) = 서 있는 캐논"을 전제로 에오라의 자리를 물었다 — **전제가 틀렸다.** 사용자 원문(2026-07-10, 그대로):
> **"아닌데? 그거 현대물 초기 기획이고 없는건데? 아직 이면세계도 안만들었고, 원래 내 계획은 현실의 고대 능력자가 많을시절얘기야. 그래서 검은물로 싹다 죽고, 쌓아올린것도 다 녹아버린뒤 능력자수 줄고 대정화 이후의 현대를 쌓아올릴지, 아니면 이런얘기없이 갈지 너가 뭘할지 궁금해서 그냥 나뒀어. 이 대정화 검은물도 다 기본틀 만들때 썼던 구식 기획이니까."**

**정리(해석 최소화):**
- **두 계층(표피/이면세계) 우주론 = 현대물 초기 기획 = 캐논 아님.** 이면세계는 아직 만들지 않았음. 지위는 파수/비상/온실/사무실과 같음: 초기에 만든 참고 틀 — **폐기도 확정(캐논화)도 금지.**
- **대정화·검은물 = 기본틀 만들 때 쓴 구식 기획** — 같은 지위. 그 세부(반신전쟁·봉인·잠든 신 등)를 서 있는 사실처럼 인용하지 말 것.
- **에오라 = 본선 = "현실"의 고대, 능력자가 많던 시절 이야기.** (사용자 원래 계획.)
- **고대→현대 연결 = 사용자가 일부러 열어 둔 갈림:** ①검은물류 대절멸(싹 죽고·쌓은 것 다 녹고·능력자 수 줄고 → 그 위에 현대를 쌓음) ②그런 이야기 없이 감 ③제3의 길들(가능성은 무한 — 하나에 꽂히지 말 것). **아직 정하지 않음. "너가 뭘 할지 궁금해서 나뒀다"** — 탐사는 위임됐으나 캐논 확정은 아님.

**하위 문제 지위 변경:**
- §11-3(bt47 "쓰면 덜림" vs 힘의구조 §11 "몫은 타지 않음"): 판A의 근거였던 "고립계 흔적 0% 복구"가 구식 기획 소속이 됨 → **에오라 캐논(덜림·누렌·bt47)이 본선.** 단 힘의구조는 능력 매커니즘 정본(사용자 확정 07-03)이므로 무단 수정 금지 유지 — §11 문구는 갈림 결정과 함께 정리.
- §11-4("만 년 전 은폐" 문구): 같은 구식 소속 → 같이 정리.
- 실무 규율(강화): 에오라 문서가 두 계층·고립계·T티어·노리빌 등 현대물 초기 기획을 캐논 근거로 인용하지 않는다 — 이제 "판정 전 임시"가 아니라 **"구식 참고 틀이라서"**다.

### (이력) 구 §12 — 두 계층 우주론과의 미기록 관계 (④ 자율루프 9회차 · 아래 후보 판 3개는 "두 계층=캐논" 전제가 틀려 폐기, 과정 기록만 보존)
> §11의 충돌들(bt47 vs 힘의구조 §11 / "만 년 전 은폐" vs 공개 계약사)을 파다 닿은 공통 뿌리. **판정하지 않는다** — 세계 근간(gen_lore doc 10~30)은 사용자 확정 영역. 여기는 서 있는 사실과 후보 판들의 기록.

### 서 있는 사실 (전부 현행 정본에서 인용)
- **릴레이 헤더(사용자 확정 2026-07-03):** 에오라 능력자 = "세계맥에서 권능을 받고 태어남"·내림/두께 이원 — **현대 캐논과 같은 세계맥·같은 힘의 문법**을 명시적으로 공유.
- **골격 §0:** 에오라를 지구와 나란히 놓고 비교하는 표("지구 | 에오라") — **에오라 ≠ 지구**가 골격의 전제.
- **gen_lore doc 10:** 내부 세계 = "권능이 날것·마법이 자연법칙·**과학 미발달(고전 판타지 수준)**·밝은 고전 RPG. **전모는 미정**."
- **에오라 골격 제24기:** 지금(W.16,860) = 셈틀·빛 그림·실 끝 창 = **현대 상당** — doc 10의 "과학 미발달" 스케치와 안 맞음(단 doc 10은 6월 작·에오라 대확장은 7월 — 스케치가 낡았을 개연).
- **힘의구조 §5.5 위험④:** "만 년 전 은폐 6형태부터 현대 비닉·프런트까지" — 현대(표피) 능력자 극소수·은폐 문화. **에오라는 반대**: 쉰에 하나(2%)·공개 계약·감정 명부·왕좌 능력자(v2 재편, 사용자 격노 후 확정).
- **실무 현황:** 에오라 문서군(골격·릴레이·18켜·세계지도.html)과 현대 문서군(FA·gen_lore·세력전·현대종합)은 **지금까지 서로를 캐논으로 인용한 적이 없다**(세계맥·힘의 문법 공유 제외).

### 후보 판 (복수 — 정하지 말 것)
- **판1 — 에오라 = 내부(판타지) 세계의 전모:** doc 10의 스케치("고전 판타지 수준")가 낡았고 에오라 만 육천 년이 그 "미정이던 전모"다. 깔끔한 점: §11의 모든 충돌이 "두 무대 두 문법"으로 풀림(표피=고립계 발현·사용 무대가·은폐 / 내부=현실 직접 발현·bt47 덜림·공개). 걸리는 점: doc 10 갱신 필요=근간 수술=사용자 승인 영역, 그리고 내부="몸의 속"이라는 위상에 에오라의 지리(대륙·바다·별)가 어떻게 앉나 물음이 남음.
- **판2 — 에오라 = 같은 세계맥의 셋째 자리:** 표피도 내부도 아닌 딴 결(세계맥이 품은 여러 결 중 하나). 유연하나 근간에 없는 층위를 새로 세우는 것이라 역시 사용자 영역.
- **판3 — 연결을 정하지 않음(현 상태의 명문화):** 에오라는 세계맥·힘의 문법만 공유하는 병렬 세계고, 두 문서군의 관계는 캐논에 적지 않는다. 가장 보수적 — 지금까지의 실무가 사실상 이것.

### 실무 규율 제안 (②레인·사용자 판정 전까지)
1. **교차 인용 금지 유지** — 에오라 문서가 현대 캐논(고립계·T티어·노리빌)을, 현대 문서가 에오라 사건을 캐논 근거로 쓰지 않는다(힘의 문법 공유는 예외 — 이미 릴레이 헤더가 명시).
2. §11-3(bt47 vs §11)·§11-4(은폐 문구)는 이 관계가 정해지면 자동으로 풀리는 하위 문제 — 개별 수선보다 관계 판정이 먼저다.
