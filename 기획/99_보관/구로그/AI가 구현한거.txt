# 📖 이 게임에 구현된 기능 전체 목록

▎ "지금까지 뭘 만들었나"를 사람이 읽기 쉽게 정리. (기술 메모 아님)
▎ 전부 C++ 코드 완성 + 컴파일 통과. 에디터에서 위젯/데이터만 채우면 동작.
▎ A = 전투, B = 월드/시스템. 2026-06-02 협업 기준.

---
⚔️ 1부. 전투 시스템 (페르소나식 턴제)

기본 전투

- 턴제 전투 — 공격 / 스킬 / 방어 / 도망 4대 행동
- 다수 아군(파티) vs 다수 적 동시 전투
- HP/SP 자원, 실시간 상태창(아군·적 HP/SP/상태 표시)
- 승리/패배 처리, 도망(55% 확률)

속성·약점 시스템 (페르소나 핵심)

- 8속성: 물리/화염/빙결/전격/질풍/축복/저주/만능
- 상성: 약점(×1.75) / 내성(×0.5) / 무효(0) / 흡수(회복) / 반사(되받음)
- 약점·치명타 맞히면 "한 번 더(One More)" — 추가 행동
- 총공격(All-Out Attack) — 적 전원 다운 시 발동, 대형 데미지
- 약점 분석 — 때려서 발견한 적 약점을 화면에 표시 / "분석" 스킬로 즉시 공개

행동·스킬

- 차지 — 한 턴 모아 다음 공격 ×2.5
- 바톤 터치 — One More 때 동료에게 강화된 추가 행동 넘기기
- 스킬 타입: 단일공격 / 전체공격 / 자가·단일·전체 회복 / 공·방 버프 / 적 공·방 디버프 / 분석
- 연타 스킬(다단 히트)
- 전투 중 아이템 사용(가방 연동)

- 전투 중 아이템 사용(가방 연동)

상태이상·테크니컬

- 상태이상 6종: 독 / 수면 / 마비 / 화상 / 빙결 / 감전 (각각 효과 다름)
- 상태이상 면역(적·보스별 설정, 보스는 수면/빙결 자동면역)
- 테크니컬 — 상태이상 적 공격 시 보너스(빙결+물리=박살 ×2.0 등) + 다운
- 수면/빙결 대상은 회피 불가(반드시 명중)
- 치명타 / 빗나감 / 데미지 ±10% 변동

성장·보상

- 레벨/경험치/레벨업 (스탯 성장 + 풀 회복)
- 레벨업 시 새 스킬 습득
- 골드 보상(적이 떨굼)
- 처치 시 SP 회복 / 가드 시 SP 회복
- 버프·디버프(공/방 증감, 지속 턴)

적 AI·난이도

- 똑똑한 적: 가장 약한 아군 집중공격 / 위급 시 회복 / 가끔 차지 / 연타 / 스킬·속성 사용
- 보스 분노 페이즈 — HP 절반 이하 시 공격력↑ + 상태이상 해제
- 난이도 스케일링(옵트인) — 적을 파티 레벨에 맞춰 보정
- 밤 전투 강화(옵트인) — 저녁/밤에 적이 강해짐(시간 시스템 연동)

전투 UI·연출

- 전투 HUD: 상태창 / 스킬 메뉴 / 아이템 메뉴 / 적·아군 타겟 선택 / 턴 순서 미리보기 / SP부족 표시
- 연출 이벤트버스 — WEAK!/CRITICAL!/1 MORE!/총공격/승리 등 순간을 감지해 BP 연출로 연결(틀 완비)

🌍 2부. 월드 · 탐험 (B)

경제·아이템

- 인벤토리 + 소비아이템(HP회복약/고급회복약/SP회복약/해독제/엘릭서)
- 상점 — 골드로 스탯 영구강화·아이템 구매 / 상점 NPC / 밤엔 영업종료
- 소원의 샘 — 골드 넣고 확률로 아이템(골드 싱크)

탐험·상호작용

- 보물상자, 획득물 픽업
- 포탈(레벨 이동), 점프패드
- 채집물 — 하루 1회 재생, 야간 전용 가능, 골드/아이템
- 표지판/메모(LoreNote), 잠긴 문 + 열쇠 아이템
- 지역 트리거 — 진입 시 지역명 표시 + 최초 발견 기록 → 지역 도감

시간·진행

- 시간 시스템 — 일자/시간대(아침·낮·저녁·밤), 영구 저장
- 취침/휴식(세이브포인트) — 저장 + 다음날로
- 시간대별 NPC 대사
- NPC 영입 — 동료로 만들면 전투에도 합류

퀘스트

- 퀘스트 시스템 — 목표 종류: 대화 / 적 처치 / 상자 열기 / 특정
- 보상 + 영구 저장, 퀘스트 로그 UI
- 퀘스트 지급 NPC, 샘플 퀘스트(촌장 대화·현상금 사냥·사흘 생존 등)
