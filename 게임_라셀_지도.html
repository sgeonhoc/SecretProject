🧭 라셀 배치 지도 — 레벨이 실제로 어디에 있나

개념도가 아니라 실제 위치·방위. 원점 = L01 큰길. 강·위층 = 북(위) · 상류 옛도읍 = 서(왼) · 하구 바다 = 동(오). 데이터 정본 = 기획/02_게임설계/2_레벨/게임_라셀_배치정본.md. 실선 = 지은 문 · 점선 = 예정·이동수단.

지은 핵(조합식 6맵) A 아랫장터 B 학당·의원 C 신항·부두 D 위층 E 아래층 F 상류·물위 — 실선 = 지은 문 · ┄ 점선 = 예정·이동(다리·배·지하철·계단)

★A 아랫장터 배치로 잡은 모순 교정

  • 뒷골목(L03)을 큰길 북측 건물 뒤(북)로 옮겼다. 그러면 L02 골동상이 큰길(남)↔뒷골목(북)을 앞뒤로 관통해서 앞문·뒷문이 자연스러워진다. (지금 빌더는 골목이 큰길 남측이라 골동상 뒷문과 방위가 어긋났다.)
  • L04 흥신소는 큰길 북측 서쪽 이층 — 창이 남쪽 큰길을 내려다본다(정본 §12-3).
  • L05 밥집은 큰길 남측, 문이 북쪽 큰길로.
  • L22 요아 셋방은 장터 동편 옥상 — 창이 서쪽 장터 지붕·강을 본다. 낮엔 동쪽 부두(C) 창고로 통근.

아래층·상류로 이어지는 두 입구

  • L03 뒷골목 환기구 → L16 폐선 (아랫장터에서 내려가는 입구, 이미 지음).
  • L10 신항 갱 돌리는 벽 → L17 묻힌 도시 (신항에서 뚫린 입구).
  • 둘 다 아래층에서 만나고, L17에서 상류로 뻗은 통로 → L18 성문으로 옛 도읍과 이어진다.
★네가 정할 것 — 이 방위·배치가 네 라셀과 맞는지.
  • 강·위층 = 북(위) / 상류 = 서(왼) / 바다·부두 = 동(오). 뒤집을까?
  • A구역 뒷골목을 북측으로 옮기는 교정 — OK면 L01 빌더부터 고친다.
  • 학당가(B)를 아랫장터 동에 뒀는데, 강 쪽이면 더 북일 수도. 위치 조정할 데 있으면 짚어줘.
확정되면 이 좌표대로 ①L01 빌더 골목 교정 ②각 레벨 빌더 창밖·문 방향 ③포탈 배선을 다시 건다.
