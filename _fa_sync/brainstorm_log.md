## Iteration 1 (2026-06-18) — 관계 중심 설계 전개

### 1) 그녀가 "기존 세계에 끼워넣는" 구체 방법 — 후보
- **(가) 그녀 자신이 *입구*다.** 소꿉친구인 그녀가 실은 이미 숨은 세계와 연결, 그가 각성하면 "사실 나도…" 하며 자연스럽게 인도. → 곁 조종 용이. *위험: 그녀 노출 빨라짐.*
- **(나) 대리 멘토를 심는다.** 그녀의 하수인/포섭 각성자를 그의 멘토로 붙임. 그녀는 더 숨음.
- **(다) 사고로 위장한 진입.** 그가 우연(실은 그녀가 깐) 진짜 사건에 휘말려 세계를 발견. 가장 자연스러움.
- **잠정 채택:** (다)+(나) — 자연스러운 진입 + 숨은 가이드. (가)는 노출 위험으로 후순위.

### 2) 숙적(D) — 후보
- **(가) 대립 가치의 반신** — MC를 다른 목적으로 원함(죽이거나 다른 길로). 히로인의 직접 라이벌 = 신급 그림자(후반).
- **(나) 거울상 숙적** — MC와 비슷한 처지(자질 있었으나 다른 길 간)였던 각성자. 감정·테마 강함.
- **(다) 그녀가 만든/co-opt한 숙적이 통제를 벗어남(배신).** 그녀 계획에 균열 → 드라마.
- **잠정 채택:** (나) 거울상 숙적(중심) + 후반 (가) 반신.

### 3) 감정 시련(F) — 후보
- 또래의 실종(그가 못 지킴) / 신뢰한 세력의 배신 / 친구를 살리려면 적 편을 들어야 하는 선택 / 무심코 누군가를 실종시킴(죄책).
- 각 시련 = 자아 단련 + **히로인의 비극 심화**(사랑하는 그의 고통을 그녀가 설계).

### 허점 점검
- **홀:** "그녀가 입구·가이드"면 그가 *그녀를* 의심할 표면이 생기지 않나? → 가이드인 *척*하되 흑막은 숨김(가이드 ≠ 흑막으로 보이게). 노출 위험 관리 필요.
- **홀:** 조용한 진입(C/E)인데 후반 화약고(A)로 어떻게 전환? → 그가 커지며 *그의 행보 자체가* 주목을 끌어 자연 escalation. 그녀가 다이얼을 푸는 게 아니라 *그가 판을 키운다*(더 영웅의 길다움). ★강점.
- **강점 확인:** 관계 중심 + 그녀 능동 + 진짜 stakes + 순환(e) 제거. ✓ 논리 OK.

### C) 감정 시련 시퀀스 (잠정 순서)

- 허점: 비극 과다 = grimdark/붕괴 → *유대·온기*(관계·또래의 기쁨)로 비터스위트 유지.

### D) 화약고 후반 전환 트리거 — 후보

- **잠정: (a) 주 + 그녀가 (c)로 보조.** 화약고 = *전제*가 아니라 *결정화 직전 최종 도가니.*

## Iteration 5 (2026-06-18) — 반신 권능 / MC 속성 / 세력 색

### 1) 반신의 권능 (결정화와의 관계)

- **반신 권능 = 자기 시그니처(색)의 *신적 증폭* + *질적 도약.***
  - 능력자: *국소 편집*("여기 불").
  - 반신: *구조적 권한*(고립계 전체 재편·규칙 비틂·시간 조작 급). 더 큰 *권위*지 단순 더 센 화염구 아님.
- 고대로 갈수록(표류) 색을 잃고 *형태 없는 raw 권능*에 근접(=이질·코즈믹).
